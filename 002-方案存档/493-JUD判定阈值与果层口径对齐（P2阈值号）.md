### P2-b R:R 门禁（盈亏比硬过滤）

| | 内容 |
|---|---|

| **系统现状** | `advice_engine:493` / `advice_builder:142`：`if rr < 1.0 and state in ('enter','light')` → 降 wait；`status_engine.apply_advice_params(rr_gate=1.0)` → `rr < 1.0` 降 wait + 仓位减半；`dim6` 评级：`<1R 不值得/1R-2R 可考虑/2R-3R 较好/>3R 优质` |

| | 内容 |

**改动（3 文件；dim6 audit 无需改——其门槛早已是 ≥2.0）**：
1. `advice_engine.py`：新增模块常量 `RR_GATE = 2.0`（原 `< 1.0` 字面量）；门禁条件改 `_rr < RR_GATE and state in ('enter','light')` → `state='wait'`；原因文案带阈值。

**关键定位（本号核查新增）**：P2-b 的**生效位置** = `advice_engine.build_operation_advice`（经 `cross_validate:593` → **机会图谱弹窗** `operation_advice`），**不是** v390 的 `status_snapshot.opportunity_state`（后者的 wait/enter 由 `factor_arbiter` final_score 决定，不经 rr 门禁）。故 P2-b 影响面为「机会图谱操作建议 state」，非全市场判定分布。`advice_builder` 同名函数为死副本（被 advice_engine 取代）。

## 七、批次3 实施记录（P2-g，✅ 2026-09-27）

### 7.1 诊断（`scripts/_493_p2g_regime_probe.py`，300 只）
- `tags` 含 `status_bar` 的样本 = **0/300** → 原 `tags['status_bar']` 分支**恒不可达**（`status_bar` 是 `status_snapshot` 成品列，不回灌 tags）；
- `dims.emotion.state` 恒「正常」（存量 dim_results 缺 dim5 `status_phase`，见 7.3）；
- 实际 regime 仅 **ranging 65.3% / trending_down 34.7%**，**`trending_up`/`extreme_panic` 恒 0** → `MARKET_REGIME_WEIGHTS` 实为 2 档。

### 7.2 修正（用户拍板，依据 Wiki《市场状态感知因子》+《情绪周期-仓位联动》五阶段表）
`_detect_market_regime` 改以**市场级** `tags.market_emotion`（情绪周期六段论）为基准：

| `market_emotion` | regime |
|---|---|
| 萌芽 / 发酵 / 高潮（sprout/ferment/climax） | `trending_up` |
| 退潮（ebb） | `trending_down` |
| 冰点（ice） | `extreme_panic` |
| 回归 / 正常 / 未知 | → 回退 dim5 结论 → risk 维度 → 默认 `ranging` |

- 须用**市场级** `market_emotion`（≠ 个股 `stock_emotion`，后者恒 neutral）；仅用已存在 tags 键，符合「不额外引入大盘级数据源」。
- **语义更准**：原「退潮/高潮 → extreme_panic」为粗糙近似（491 R9 曾定），现按五阶段表细分（退潮→down、高潮→up、冰点→extreme）。`extreme_panic` 权重值不变（485-5 仍可经 yaml 调）。

### 7.3 实证（全市场 `market_emotion` 分布）
- `market_emotion` ≡ `sentiment_phase`（40/40、6/6 一致）→ 证实其为**正确的市场级信号**；
- **版本混杂**：6 只（8 股探针批）为 `ferment`→`trending_up`；40 只抽样为 `ebb`→`trending_down`（全市场 300 只 99.7% trending_down）。差异源于 pre_feat 陈旧（多数停留在 09-24 ebb）；
- **关键定性**：修复前 regime 由**个股 risk** 决定（逐股 ranging 65%/down 35%，与大盘无关）→ 修复后由**市场级情绪**决定（当前全市场同档）。这才是《市场状态依赖加权法》「先识别市场状态再调权」的本意；日终 RAW-2 重算后随市场阶段自然切换。

- 更新 `tests/test_491_emotion_direction_unified.py::test_r9_extreme_panic_weights_kept`（触发面按 7.2 细分；权重值断言不变）；
