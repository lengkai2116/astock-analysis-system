# 机会信号强度与时机识别体系（二维）

## 一、背景与归零决定

### 1.1 问题链（为什么 311/312 作废）

经 2026-08-02 核查（沟通纪要 020/021/022），机会强弱判定存在根本性方向错误：

```
signal_strength 基础分 = 主力阶段（7.0，碾压估值 1.5/趋势 1.0）
        ↓
主力阶段判定 = 5源/8维（7/8 是形态代理：技术形态 ≠ 主力行为）
        ↓
实证：主力真实证据（龙虎榜近30日）仅 761 只 = 13.6% 覆盖
       而 8 维判定 86% 股票处于"主力活跃阶段"
        ↓
结论：用小概率维度（主力，覆盖最窄）做全局核心指标 = 方向性错误
```

### 1.2 归零决定（2026-08-02）

- **311 作废**：三层评分结构建立在"主力为核心"前提上，整体废弃
- **312 作废**：8 维度中 7 个是形态代理，主力阶段判定不应是机会强弱核心；批次1 代码改造保留为参考
- **新起点（本方案）**：**二维识别体系**——大小=机会潜力强度（机会有多大）、颜色=时机信号（现在能不能动）

## 二、核心洞察：系统已有现成的多来源评估机制

**L4 共识投票（cross_validate.py VOTE_MAP，14 票源）已经是多来源评估框架**；同时**闸门体系（308/309号）已是时机信号的现成机制**：

| 现成机制 | 输出 | 状态 |
|---------|------|------|
| L4 14 票源（估值/资金/趋势/财务/事件/情绪/形态/主力/量价/位置） | 多来源方向共识 | ✅ 已实现 |
| 闸门2（`_check_right_side_confirm`） | right_side_confirm 四档（时机） | ✅ 已实现、已落库 |
| 闸门3（L4 共识率） | 方向可信度（≥55% 门禁） | ✅ 已实现（diagnose API） |

**关键认识**：signal_strength 是"用主力单维度替代现成多来源机制"的倒退设计；而"机会类型作为颜色"忽视了已就绪的时机机制。归零后的方向 = **潜力（多来源强度）+ 时机（闸门体系）双轨**。

## 三、二维识别体系总览

**设计目标（三硬性要求，沟通纪要 024）**：
1. **合理判定机会大小**——高分股确实有真实机会来源支撑（数据用真实值，不用形态代理）
2. **个股间差异性**——分数拉开梯度、不扎堆（截面百分位机制保证）
3. **可解释**——用户能理解"为什么这只高分"（分数=明确的机会来源组合，可展示明细）

```
┌─────────────────────────────────────────────────────────┐
│ 方块大小 = 机会信号强度（潜力）——"机会有多大"             │
│   7 个潜力维度（估值/业绩/板块/事件/资金/趋势/主力可选）   │
│   截面百分位 + IC 加权 + 关联修正 + 质量/风险调整         │
│   （慢变量：周月级变化，不含时机信号）                    │
├─────────────────────────────────────────────────────────┤
│ 方块颜色 = 时机信号——"现在能不能动"                      │
│   闸门2 右侧确认四档 × 闸门3 L4 共识率细分               │
│   蓝=可入场 / 黄=可轻仓 / 灰=等待 / 棕=回避               │
│   （快变量：日级变化，闸门2 否决不与强度联动）            │
└─────────────────────────────────────────────────────────┘
```

**正交原则**：潜力（大小）与时机（颜色）完全解耦——机会大 ≠ 现在入场；时机对 ≠ 机会强。

**边界**：本方案仅作用于机会地图 opportunity 模式；market/value 模式的面积与颜色逻辑不受影响。

## 四、方块大小：机会信号强度（潜力）设计

### 4.1 潜力维度（7 个，知识库支撑）

> **情绪定位**：市场情绪（sentiment_phase）是**全市场环境变量**，不进个股潜力维度——通过动态权重矩阵影响各维度得分（§4.2 关联修正），而非作为个股评分项。

| # | 维度 | 数据/标签 | 知识库依据 | 类型 |
|:-:|------|----------|-----------|------|
| 1 | 估值潜力 | valuation_deviation 深度、PE/PB/PS 分位、股息率 | 均值回归（极端低估修复空间） | 核心 |
| 2 | 业绩潜力 | fina_indicator（ROE 趋势/营收增速/利润率） | 成长驱动（基本面改善） | 核心 |
| 3 | 板块潜力 | sector_heat + 板块动量 | 行业景气（β 机会） | 核心 |
| 4 | 事件潜力 | catalyst_event 类型/强度 + forecast 业绩预告 | 催化剂引爆 | 辅助 |
| 5 | 资金潜力 | moneyflow 大单持续净流入（连续强度） | 资金持续进场推动 | 核心 |
| 6 | 趋势潜力 | trend_alignment / ma_alignment / 量价健康（不含突破确认） | 市场共识/动量（Fama-French 动量因子） | 核心 |
| 7 | 主力成本潜力（可选） | 龙虎榜/股东户数/融资异动 | 成本偏离因子 | 可选 |

> **剔除的时机型信号**（归颜色）：volume_price_fit 突破确认、buy_sell_point 买点、右侧确认、量价共振——避免"既拉大又变绿"双重计权。趋势潜力只用方向/斜率（慢变量），突破确认（快变量）归时机。

**机会类型分工说明**（沟通纪要 024 澄清）：方块颜色改为时机后，机会强度（大小）**统一按 7 维加权计算**（不再按机会类型差异化组合）；机会类型（低估型/景气型/事件型/趋势型等）退居详情面板，作为"这是什么机会"的说明，不参与强度计算。

### 4.2 评估方式（实现连续性差异、精准区隔）

**第一层：截面百分位标准化**（差异性的根本保证）
```
每维度：个股值在全市场（或同行业）截面上的百分位 → 0-1 连续分
估值：偏离度排全市场前 3% → 0.97；前 50% → 0.5；后 92% → 0.08
效果：总有 5-10% 股票在某维度高分，分布天然拉开，不依赖绝对阈值
```

**第二层：连续函数映射**（避免离散档位跳变）
- 阈值附近平滑过渡（不用"<40% 给 2 分"式一刀切）

**第三层：IC 加权**（科学定权）
```
维度权重 wᵢ ∝ ICᵢ（该维度对后续 10/20 日收益的截面相关性，滚动月度重估）
—— 知识库《多因子合成方法》打分法 + 因子有效性检验
```

**关联修正**：
| 关联 | 修正 |
|------|------|
| 估值 × 质量 | 低估 + fina_health=pass → ×1.0（真低估）；低估 + 财务差 → ×0.5（价值陷阱） |
| 估值 × 成长 | 生命周期校正（成长期高 PE 分位加权修正） |
| 资金 × 板块 | 板块热 + 板块内资金流入 → 共振加分 |
| 情绪 × 权重 | 复苏 1.0 / 冰点 0.8 / 高潮 0.5 / 退潮 0.3（动态权重矩阵） |

### 4.3 综合公式与综合方式选择

**综合方式：B 多源加权 + 共振奖励**（沟通纪要 023/024 三候选 A 取最强 / B 多源加权 / C 分层中选定 B）：
- 选 B 理由：①多源共振体现机会确认度（用户"1+1>2"偏好）；②与 L4 多来源框架同源；③打分法稳健、不易过拟合（知识库《多因子合成方法》推荐）
- 共振奖励：同向优势维度 ≥3 个时，强度 ×(1 + 0.05×(优势维度数-2))——多源确认加分

```
机会强度(0-100) = 质量系数 × Σ(wᵢ × 维度百分位分 × 关联修正 × 情绪权重) × 共振奖励

质量系数 = fina_health 映射（pass 1.0 / suspicious 0.6 / fail → 触发风险否决）
风险否决（慢变量，见 §六）：财务 fail → 封顶 0.2；极端泡沫（正偏离过大）→ ×0.3
共振奖励 = 优势维度（百分位 ≥0.7）数 ≥3 时 ×(1 + 0.05×(n-2))
```

## 五、方块颜色：时机信号设计

### 5.1 时机判定（闸门2 + 闸门3）

```
闸门2（_check_right_side_confirm）→ right_side_confirm 四档：
  否决（缠论卖点/量价背离/预跌形态）
  未确认 / 基础确认 / 强确认（STEP2 类型确认 + STEP3 增强确认）
闸门3（L4 共识率）→ 方向可信度（≥55% 才可入场）

时机 = f(闸门2, 闸门3)：强确认 + 共识≥55% → 可入场
```

### 5.2 色板（避开 A 股红绿，防混淆）

> A 股惯例红涨绿跌——时机色若用"绿=可买/红=回避"会与涨跌色冲突（002 已确认）。主色用蓝/黄/灰/棕，与涨跌红绿完全无冲突。

| 时机状态 | 颜色 | 判定 | 语义 |
|---------|------|------|------|
| **可入场** | 🟦 蓝 | 强确认 + 共识≥55% | 右侧信号明确，可以行动 |
| **可轻仓** | 🟨 黄 | 基础确认 | 初步信号，小仓位关注 |
| **等待** | ⬜ 灰 | 未确认 | 蓄势中，等放量突破 |
| **回避** | 🟫 棕 | 否决 | 出货/背离/预跌，别碰 |

**闸门3 共识细分**：用饱和度/深度表达——高共识（≥70%）= 深饱和蓝；低共识（55-70%）= 浅蓝 + 边框提示"方向可信度待确认"。不新增色相。

### 5.3 与大小的正交语义（用户识别体系）

| 大小 \ 颜色 | 🟦 可入场 | 🟨 轻仓 | ⬜ 等待 | 🟫 回避 |
|------------|----------|---------|--------|---------|
| **大**（潜力强） | **重点标的** | 先小仓 | 重点跟踪等右侧 | 潜力存疑，暂不碰 |
| **小**（潜力弱） | 可做小仓 | 谨慎 | 略过 | 略过 |

## 六、正交性边界与冲突缓解（v3 新增）

> 潜力和时机是两个独立体系，但**正交性有边界**——单方块时机互斥不会同时出现两种时机，却存在数据源重叠、统计相关、视觉矛盾等真实冲突（基于 5578 只真实数据交叉验证，沟通纪要 028）。本节明确边界并给出缓解方案。

### 6.1 正交性边界（三个事实）

| 边界 | 事实 | 影响 |
|------|------|------|
| **时机互斥** | 强确认/基础确认/未确认/否决四档互斥，一方块一色 | 单方块不会同时显示"等待"与"可入场" |
| **共享输入耦合** | 闸门3 共识率 = L4 14 票源（含估值/资金/趋势等潜力维度） | "完全独立"是设计意图，实现上有正相关耦合（低估+资金流入 → 潜力高且共识高） |
| **统计负相关** | 低估股（潜力高）多在下跌后段（时机未确认/否决） | 实测"大潜力+可入场"仅 1.3%（73/5578），重点标的天然稀缺 |

### 6.2 闸门2 否决可逆性与解耦（v2 保留）

| 否决因素 | 判定依据 | 可逆性 |
|---------|---------|--------|
| 缠论卖点 | buy_sell_point = first/second/third_sell | **中等**（卖点随走势演化，一卖后可能二买） |
| 量价背离 | volume_price_fit = diverging | **强**（放量修复即解除） |
| 预跌形态 | pattern_signal 含"预跌" | **强**（随 K 线演化消失） |

**结论**：三个否决因素可逆性均较强（快变量）——**闸门2 否决不与机会强度联动**，避免"今天否决明天修复"的强度抖动。
- 时机否决（闸门2）：只影响颜色（棕/灰），不影响大小
- 潜力风险否决：只基于慢变量（财务 fail/极端泡沫/主力出货行为证据）

### 6.3 冲突清单与缓解方案（真实数据交叉验证，沟通纪要 028）

| # | 冲突 | 实测/性质 | 缓解方案 |
|:-:|------|----------|---------|
| **C1** | **数据源重叠/泄漏**：volume_price_fit（潜力趋势 vs 闸门2 否决）、资金（潜力 vs 确认）、buy_sell_point（闸门）——同标签两边用可方向矛盾 | 结构性问题 | **数据源唯一归属表**（见 6.4）——每个标签明确"潜力角色/时机角色"唯一归属 |
| **C2** | **统计负相关 → 重点稀缺**：大潜力+可入场仅 1.3% | 实测 | 接受真实市场 + **默认视图引导**（"潜力前 20% + 非回避"筛选视图）；潜力百分位可选同行业口径（行业内科内区分度更高） |
| **C3** | **"独立"不成立**：闸门3 共识含潜力维度（共享输入） | 结构性问题 | 认知管理：方案明确"潜力与时机部分共振是特性"；文档/图例说明二者关系 |
| **C4** | **大潜力+回避视觉矛盾**（13.2%，736 只"大棕块"） | 实测 | **UI 弱化**——回避股去饱和/暗角（视觉"不可操作"）；或作为"高风险潜力"警示（潜力大+否决=风险信号强）；悬停解释"潜力（长期）≠时机（短期）：当前出货/背离，等待右侧修复" |
| **C5** | **时间尺度错位**：潜力周月级 vs 时机日级 | 结构性 | 潜力放快照（日更）、时机每日刷新；前端合并展示标注各自更新时间（"潜力基于 X 日快照，时机截至 Y 日"） |
| **C6** | **机会类型退居详情后的认知混淆**：颜色不再=类型但详情有类型 | 结构性 | 详情面板分层展示（"机会类型（这是什么）+ 时机状态（现在能不能动）"）；悬停第一行解释"大小=机会潜力、颜色=入场时机" |

### 6.5 半可入场中间态（矛盾感知③的解决）

- **强确认 + 共识 55-70%**：浅蓝 + 边框提示"方向可信度待确认"（闸门3 细分已定义）
- **强确认 + 共识 <55%**：黄蓝渐变（"信号好但方向未确认"，降为轻仓语义），避免用户误判为完全可入场

## 七、前端交互（大小 × 颜色）

1. **大 + 蓝 = 重点标的**：默认排序置顶，一眼定位
2. **颜色过滤**：图例可点击过滤（只看"可入场"/"等待"等）
3. **组合筛选**：大小阈值 × 颜色状态（如"潜力前 20% + 可入场"）
4. **默认视图引导（C2）**：默认提供"潜力前 20% + 非回避"筛选视图，缓解重点稀缺的感知
5. **矛盾组合弱化（C4）**：回避股（棕）去饱和/暗角——视觉上"不可操作"；大潜力+回避加"风险警示"角标

## 九、验证思路

1. **来源覆盖度**：7 个潜力维度各自有数据的股票占比（确认机会不是小概率，也不是 86% 虚高）
2. **分布**：全市场分数直方图——目标梯度分布（高分 5-10%、中分 40-60%、低分 30-40%）、无 0 分扎堆
3. **差异性**：同行业股票分数分布拉开（截面百分位机制验证）
4. **样本验证**：典型机会股（低估+财务好、板块景气+资金共振、事件+确认）分数高且来源可解释
5. **时机分布**：right_side_confirm 四档 × 大小交叉表（大蓝重点占比合理，参考实测 1.3% 基线）
6. **组合矛盾验证（C2/C4）**：大潜力+回避占比（参考实测 13.2%）、小潜力+可入场占比——确认 UI 弱化与默认视图生效
7. **与 L4 对照**：机会强度 vs L4 共识率的相关性（方向一致但强度区分；确认 C3 共享输入的耦合度）
