## 三、整体核查发现（死代码 / 口径 / 边界，2026-09-22）

> 按严重度分级：**A 死代码 / B 口径 / C 边界 / D 展示层**。均为**只读核查发现**，未改代码；判定类须用户拍板后开实施号。

### A1. framework `BociasiQuickLine` / `BociasiSlowLine` 双类 = 疑似零引用死代码【死代码】
- **位置**：`backend/app/engine/framework/bociasi_quickline.py`（`BociasiQuickLine`）、`bociasi_slowline.py`（`BociasiSlowLine`）。
- **实证**：全仓 grep——**0 处 import/实例化调用**（`from bociasi_quickline` / `BociasiQuickLine(` 均无）；仅在 dim5 `dim5_emotion_engine.py:7-8` 与 dim6 `dim6_risk_engine.py:799-800`、`eagle_sword_resonance.py:150-151` 的 **docstring 注释**中被提及。
- **实际生产**：dim5 用**内嵌** `_bociasi_quickline`/`_bociasi_slowline`（dim5 文件内函数，L104/L162）；`BociasiQuadrantAnalyzer`（framework 另一文件）是活跃。
- **分类**：死代码（445 边界内，464-11/批次3「死代码清理」先例）。**须先确认无动态导入（`importlib`/反射）再删**。
- **建议**：grep 确认后删除 framework 双类；若删除，须同步清理 docstring 提及（dim6/eagle_sword）。

### B1. dim5 内嵌慢线国债利率硬编码 `2.85`，与全系统 `1.7` 不一致【口径不一致——确定性】
- **位置**：`dim5_emotion_engine.py:162` `def _bociasi_slowline(df, bond_yield: float = 2.85, ...)`；evaluate L374 `_bociasi_slowline(df_basic)` **不传 bond_yield → 恒 2.85**。
- **对比**：同一系统 ERP 国债利率其他使用方全部统一 `CN_10Y_BOND_YIELD_PCT=1.7`（env 可配，`valuation_estimator.py:27`）：dim7 L31/501/676、framework 四象限慢线 `_compute_erp_percentile/_compute_dv_bond_diff`（447 后）。
- **影响**：dim5 `status_description['bociasi_slow']` 用 `1/PE_ttm*100 − 2.85`，四象限慢线用 `1/PE_avg − 1.7`——**同"ERP"两套国债利率并存**，447 只改了四象限侧，漏改 dim5 输出侧。
- **分类**：口径/数据层常量（445 边界内可改，444 事实层）。
- **建议**：**改**：`_bociasi_slowline` 默认 `bond_yield` 改从 `CN_10Y_BOND_YIELD_PCT` 取（或 evaluate 传参），与全系统统一。

### B2. dim5 慢线 `index_df`（股债位置差）从未传入 → sb 段恒死【死分支】
- **位置**：`_bociasi_slowline(df, bond_yield=2.85, index_df=None)`；evaluate L374 只调 `_bociasi_slowline(df_basic)`，`index_df` 恒 None → `sb_signal` 恒 `NEUTRAL`，相对强弱判定段永不执行。
- **连带**：sb 段 `idx_ret` 用 `idx_close.iloc[-20]`（19 日）、`stock_ret` 用 `iloc[-21]`（20 日）——**窗口错 1 日**（潜在口径瑕疵，但因 index_df 未传而不执行）。
- **分类**：死分支 + 潜在口径瑕疵。
- **建议**：要么（a）确认"慢线=纯个股 ERP"语义，删 sb 死分支 + 备注；要么（b）接线 index_df（需 data_context 提供指数 close）真实计算股债位置差（对齐知识库慢线 4 项意图）。

### B3. dim5 慢线用**绝对阈值**判信号，与四象限慢线**历史分位**口径并存【口径并存——需拍板】
- **位置**：`_bociasi_slowline` 用绝对 ERP 阈值（`>5/>3/<0.5/<1.5`）判 BULLISH/BEARISH；框架四象限慢线用 `erp_percentile`（**历史绝对分位**，447 归一化）。
- **语义**：本可分两层——个股级（dim5 `bociasi_slow_signal`）vs 全市场级（quadrant.slow_score）。但现状**未作区分说明**，二者可能对同一市场给出方向矛盾（如个股 PE 低→慢线 BULLISH、全市场 ERP 分位低→quadrant HL）。
- **分类**：口径/边界（须拍板：保留双语义+声明说明，或对齐）。
- **建议**：确认分层意图；若保留，在 dim8 话术区分"个股慢线"vs"大市四象限"；若对齐，dim5 慢线也改历史分位（数据源=个股 PE 历史序列）。

### B4. dim5 慢线 `len(df)<60` 门槛依赖基本面日频积累
- **位置**：`_bociasi_slowline` 开头 `if df is None or df.empty or len(df) < 60: return 数据不足`。
- **影响**：`daily_basic_df`（dim1 注入）日频积累 <60 日（次新/新股）→ 慢线恒 NEUTRAL 且置信 0.0。
- **分类**：边界/可接受（应标注，不误读）——与四象限慢线（全市场 252 日序列）门槛不同。
- **建议**：标注"慢线数据不足=个股 pe_ttm 序列<60 日"，避免与"无数据"混淆。

### C1. daemon RAW 全局阶段 fallback 与主源 MarketSentimentService：残留收敛（447 T2a 未完全闭合）【边界】
- **主源** `market_sentiment_service.py`：完整六段论（ice/sprout/ferment/climax/ebb/regression），依赖 `max_board_height`（连板数）+ `sealing_rate`。
- **fallback** `data_daemon.py:3270-3277`（447 T2a 后）：只产 climax/ebb/ice/ferment（**sprout/regression 兜底→ferment**），无 max_board_height（无法取连板数）。
- **残留差异**：447 只对齐 climax 门槛；**ice 判定仍不同**——主源 `limit_up<20 & max_board_height<3 & sealing<40`，fallback 仅 `limit_up<20 & sealing<40`。主源不可用（缺 sentiment_pool）时，sprout/regression 场景被归入 ferment，粒度损失。
- **分类**：边界（降级可接受）。**确认**：是否接受"主源不可用→六段论退化为四档（climax/ebb/ice/ferment）"，接受则标注；不接受需补连板数据源。

### C2. `PHASE_MAP`（dim5）无 `neutral` 键，与 daemon neutral 语义/温度 SSOT 不一致【观察】
- daemon 数据不足时产 `sentiment_phase='neutral'`（`data_daemon:3236/3350`）；`_assess_market_emotion` 的 PHASE_MAP 六段论键**无 neutral** → 落兜底 `{'phase':'正常','detail':'情绪数据不足','light':'yellow'}`。
- 温度 SSOT `PHASE_BASE_TEMP` 有 `neutral:50`——market 层与温度层对 neutral 处理不一致（market 输出非六段档位、温度用 50 分）。
- **分类**：观察（轻微语义不一致）。建议：可加 `'neutral': ('正常','数据不足','yellow')` 键或维持兜底。

### D1. 温度 `breadth` 入参语义错配【口径/已知近似】
- SSOT docstring：`breadth = 市场广度（上涨家数/总家数，0-1）`。
- dim5 evaluate（L453-457）实际传 `market_stats['ma20_ratio']`（收盘>MA20 股票占比）当 breadth。
- **影响**：上涨家数占比 ≠ MA20 强势占比，447 T1a 用 ma20_ratio 作 breadth 近似，SSOT docstring 与实际数据源未对齐。
- **分类**：口径/已知近似。建议：订正 SSOT docstring 或明确标注"用 ma20_ratio 近似"。
