# 基础设施改造：Factor/Vibe/前置过滤/现有引擎标签化

## 一、前置过滤层改造

### 1.1 改造内容

将现有 `DarwinRiskFilter` 替换为窄口径前置过滤，不再剔除 PE/换手率/市值等，仅保留三条规则：

| 规则 | 标准 | 数据源 |
|------|------|--------|
| R1: ST/*ST/退市 | 名称含 `*ST`/`ST`/`退市`/`SST` | Stock ORM / stock_list |
| R2: 面值退市 | 连续 10 日收盘价 < 1 元 | daily_cache |
| R3: 市值退市 | 连续 10 日市值 < 3 亿 | daily_cache × 总股本 |

**剔除约 200 只，剩余约 4800 只进入 L2。**

### 1.2 改动文件

- `backend/app/engine/framework/screener.py` 中 `DarwinRiskFilter` → 保留逻辑改为标签化（不改功能，改输出方式）
- 新增 `backend/app/opportunity_atlas/pre_filter.py`

## 二、FactorRegistry 新增因子

在现有 FactorRegistry 中新增以下因子，需要新增因子计算逻辑：

| 因子名 | 类别 | 数据源 | 管线归属 |
|--------|------|--------|---------|
| `PE_PERCENTILE_5Y` | 估值 | daily_basic.pe_ttm | value |
| `PB_PERCENTILE_5Y` | 估值 | daily_basic.pb | value |
| `PS_PERCENTILE_5Y` | 估值 | daily_basic.ps | value |
| `DIVIDEND_YIELD` | 估值 | 分红数据 | value |
| `ROE` | 质量 | fina_indicator.roe | value |
| `DEBT_RATIO` | 质量 | fina_indicator | value |
| `REVENUE_GROWTH` | 质量 | income | value |
| `PROFIT_GROWTH` | 质量 | income | value |
| `EMOTION_EXTREME` | 情绪 | BOCIASI | event, technical |

改动文件：`backend/app/factors/` 下新建因子计算类，在 `FactorRegistry` 注册。

## 三、Vibe 策略分级管理

### 3.1 三级管理

| 级别 | 含义 | 是否自动参与评分 | 条件 |
|------|------|----------------|------|
| `trusted` | 已验证可靠 | 是，正常权重 | 回测通过 + 实盘观察 > 20 日 + 胜率 > 55% |
| `trial` | 试用中 | 否（用户手动启用） | 沙箱回测通过 |
| `sandbox` | 刚生成 | 否（仅预览） | LLM 刚生成 |

### 3.2 改动文件

- `backend/app/models/strategy.py` 中 `StrategyTemplateV2` 增加 `level` 字段
- `backend/app/engine/unified_core.py` 中 Vibe 计算增加分级判断

## 四、现有引擎标签化改造清单

| 引擎 | 文件 | 改造方式 | 新增标签 |
|------|------|---------|---------|
| `VolumePriceStrategy` | `volume_price_strategy.py` | 在 `analyze()` 输出中附加标签字段 | `ma_alignment`, `volume_price_fit`, `volatility_level`, `volume_ratio` |
| `ChanlunAnalyzer` | `chanlun_strategy.py` | 在分析结果中附加标签 | `buy_sell_point` |
| `MainForceScorer` | `chip_strategy.py` | 保留各维度独立计算，移除总分逻辑 | `fund_flow`, `capital_nature` |
| `ChipDistributionService` | `chip_distribution_service.py` | 在筹码结果中附加标签 | `chip_position`, `chip_concentration` |
| `Bociasi` | `bociasi_*.py` | 在情绪输出中附加标签 | `sentiment_phase` |
| `SectorRotationModel` | `sector_rotation_model.py` | 在板块输出中附加标签 | `sector_heat` |
| `EnhancedPatternDetector` | `volume_price_strategy.py` | 抽离形态识别为独立标签 | `pattern_signal` |

**改造原则**：不重写现有引擎逻辑。在现有输出结果的基础上增加 `tags` 字段，原有输出结构不变。这样不影响现有系统对引擎输出的使用。
