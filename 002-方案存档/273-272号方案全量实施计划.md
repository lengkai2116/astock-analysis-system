# 272号方案全量实施计划

## 概述

本计划从 272 号方案文档中提取**全部**可执行任务，按依赖关系排入 4 个阶段，确保整体执行无偏差且全量覆盖。

### 总目标

将 `trend_renderer.py` 的模板 NLG 替换为 DeepSeek 按九层框架生成的股票现状描述，同时保持选股系统零影响，个股策略分析渐进切换。

### 实施原则

1. **不改 `status_recognition` 结构**——所有消费模块不受影响
2. **旁路而非替代**——DeepSeek 输出与现有 `status_text` 并行运行，成熟后再切换
3. **数据就绪优先**——已有数据的维度先做，需要新数据源的维度排后
4. **每个阶段可回滚**——不做任何不可逆的变更

---

## 阶段总览

```
Phase 0 ─── 基础建设（立即执行）
  G5 + G2 + Schema文档

Phase 1 ─── 数据完善（现有数据优化）
  C1 + C2 + C3 + 走势结构/筹码/环境暴露优化

Phase 2 ─── 管道集成（核心开发）
  G3-a SnapshotAssembler + G1 Prompt + G3-b 集成
  + 量价/价格/资金/时间 计算逻辑 + C4/V1/V2/V3/V4

Phase 3 ─── 切换默认（前端改造）
  前端适配 + Phase 3 切换默认 + 旧代码清理
  + 第三阶段新数据源规划
```
