# 446 号 D9 — dim2 一买/一卖 0 轴绝对位置校验

## 一、问题确认（445 §6.1 dim2 偏差 D9，代码级已核）

**知识库权威**（外部 wiki，独立章节，非指南正文）：
- `concepts/第一类买点.md` L20："第一类买点都在 **0 轴之下**背驰形成（[[缠中说禅MACD定律]]）"
- `concepts/缠中说禅MACD定律.md` L16/L20-22："第一类买点都在 **0 轴之下**背驰形成，第二类买点都是第一次**上0轴**后回抽确认形成；第三类买点：MACD黄白线在 **0 轴上方**，回抽不破0轴后形成"

**引擎现状缺陷**（`chanlun_strategy.py:BuySellPointDetector.find`，修复前）：
- 生成 first_buy/first_sell **纯粹依据背驰 direction**：底背驰（direction down）→ first_buy、顶背驰（direction up）→ first_sell（342号已修方向语义）。
- 背驰力度虽用 MACD area/peak 做了**相对比值**确认（面积比/力度比 < 0.8x），但**完全无 0 轴绝对位置校验**——不检查背驰点 DIF 是否确实在 0 轴之下（买）/之上（卖）。
- 后果：0 轴之上仍处多头强势区，底背驰也可能产 first_buy（水下抄底信号语义失真）；0 轴之下的顶背驰同理。

## 二、修复方案（用户拍板 2026-09-17：buy_sell 层注入校验）

在 `BuySellPointDetector.find` 的**一买/一卖创建处**加 0 轴绝对位置闸门（最贴 D9 语义，只约束买卖点、不误伤背驰本体）：

```python
def _diff_at_idx(self, div_idx, closes) -> Optional[float]:
    """取背驰点 position.idx 处 DIF 值。无 closes/DIF 返回 None。"""
    dif, _, _ = calc_macd(np.asarray(closes, dtype=float), self._precomputed)
    ...（越界保护）
    return float(dif[div_idx])

def _check_first_0axis(self, is_buy, divergence, closes) -> bool:
    """缠中说禅MACD定律：一买须 DIF<0（水下）、一卖须 DIF>0（水上）。
    无 closes/DIF 数据时放行（向后兼容）。"""
    dif_val = self._diff_at_idx((divergence.position or {}).get('idx', -1), closes)
    if dif_val is None:
        return True
    return dif_val < 0 if is_buy else dif_val > 0
```

- `find` 增 `closes=None` 入参（**可选、向后兼容**）。
- 主分支 + only_last 快速分支的一买/一卖创建处均套 `_check_first_0axis` 闸门。
- `ChanlunAnalyzer.analyze` 调用 find 时传 `closes=df['close'].values`，并同步 `buy_sell_detector._precomputed = _precomputed_macd`（复用 411 号预计算 MACD，避免重复 raw 计算）。
- **对称性**：一卖（顶背驰）对称要求 DIF>0（0 轴之上）。

## 三、影响评估（445 约束：不破坏分析引擎判定逻辑/阈值/窗口）

- **判定语义变化**：仅约束 first_buy/first_sell 的**0 轴绝对位置**——背驰本体仍在（divergence 不变），只是不在 0 轴之下/之上的背驰不再映射为一买/一卖信号。
- **向下兼容**：`find` 的 closes 为可选参数；不传 closes（无 DIF 数据）时闸门放行，行为不变。测试/旧调用不传 closes 仍通过。
- **阈值/计数/算法不变**：背驰 area/peak 比值逻辑、`min_confidence`、bs_type 均不动。
- **消费链**：一买/一卖是 data_daemon 一票否决 + get_chanlun_tags 观察信号。0 轴闸门使信号更贴合缠论定律（水下抄底），不改变右侧优先排序。
