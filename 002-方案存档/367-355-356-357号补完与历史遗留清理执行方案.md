## 二、待评估项分析

### 2.1 phase_detector.py 的 `_last_chip_indicators`

**现状**：
- `_last_chip_indicators` 在 `phase_detector.py:364` 被填充
- 主要用于 `_dim_ssrp()` 函数（line 236）获取 SSRP（市场平均成本）
- SSRP 是7个维度中的第6个（主力成本锚定），权重2.5

**数据流分析**：
```
ChipDistributionEstimator.calculate_all_indicators()
  → _last_chip_indicators = indicators  (phase_detector.py:364)
  → _dim_ssrp() 读取 ssrp  (phase_detector.py:236)
```

**现有数据通道**：
- `tag_extractor.py:155` 已将 `ssrp` 写入 `pre_feat_cache` 的 `chip_deep` 组
- `pre_feat_cache` 存储在 `compute_cache.db`

**结论**：✅ **可以通过数据重新排布解决**

**方案**：
1. `phase_detector.py` 的 `_dim_ssrp()` 改为从 `tags`（pre_feat_cache扁平化）读取 `ssrp`
2. 删除 `_last_chip_indicators` 的定义和填充逻辑
3. 保留 `ssrp` 字段在 `pre_feat_cache` 中的写入

**影响范围**：
- `phase_detector.py`: 删除 `_last_chip_indicators` 相关代码
- `data_daemon.py:2175-2189`: 删除残留引用
- `chip_strategy_impl.py`: 多处读取 `indicators.get('ssrp')`，需改为从 `tags` 读取

### 2.2 opportunity_atlas.py 的 `_fallback_legacy_treemap`

**现状**：
- `_fallback_legacy_treemap()` 是 treemap 端点的回退路径
- 当 `treemap_snapshot` 表数据不可用时，从 `daily_cache`、`daily_basic_cache`、`tags` 逐表读取
- 在 `opportunity_atlas.py:286` 被调用

**数据流分析**：
```
treemap端点
  → 尝试从 treemap_snapshot 读取 (line 269)
  → 失败时回退到 _fallback_legacy_treemap (line 286)
    → 从 daily_cache / daily_basic_cache / tags 读取
```

**现有数据通道**：
- `treemap_snapshot` 表已定义在 `snapshot_cache.db`（356号方案）
- `treemap_snapshot` 由日终批量生成（353号方案 环节6 OUT）

**结论**：✅ **可以通过数据重新排布解决**

**方案**：
1. 确保 `treemap_snapshot` 表数据完整（日终批量正常运行）
2. 保留 `_fallback_legacy_treemap` 作为降级路径，但添加日志警告
3. 长期目标：当 `treemap_snapshot` 数据稳定后，移除回退路径

**影响范围**：
- `opportunity_atlas.py:286`: 保留调用，添加警告日志
- `enhanced_cache_manager.py`: 确保 `treemap_snapshot` 写入逻辑正确

def get_cached_minute_kline(self, ts_code, trade_date=None, freq='5min'):
    # 356号方案：优先从分库读取
    try:
        from app.data.sharding_manager import sharding_manager
        if sharding_manager.table_exists('minute_kline_cache'):
            query = "SELECT * FROM minute_kline_cache WHERE ts_code = ?"
            params = [ts_code]
            if trade_date:
                query += " AND trade_date = ?"
                params.append(trade_date)
            query += " AND freq = ?"
            params.append(freq)
            query += " ORDER BY trade_time"
            df = sharding_manager.execute_query('minute_kline_cache', query, params)
            if df is not None and not df.empty:
                import pandas as pd
                return pd.DataFrame(df)
    except Exception as e:
        logger.debug(f"分库读取失败，降级到ECM: {e}")
    
    # 降级到ECM读取
    query = "SELECT * FROM minute_kline_cache WHERE ts_code = ?"
    params = [ts_code]
    if trade_date:
        query += " AND trade_date = ?"
        params.append(trade_date)
    query += " AND freq = ?"
    params.append(freq)
    query += " ORDER BY trade_time"
    return self._query_df(query, params)
