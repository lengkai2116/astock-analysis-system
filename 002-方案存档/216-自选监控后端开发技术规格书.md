## 1. 页面概述

### 1.1 布局结构

```
┌─ page-header ──────────────────────────────────────────────────────┐
│ ⭐ 自选监控 · 共 8 只        [WebSocket 已连接 ●]                  │
├─ toolbar ──────────────────────────────────────────────────────────┤
│ [＋添加股票] [🔄策略刷新] [评级筛选▼] [⚙️列配置]      最近更新:刚刚│
├─ table (可水平滚动, 列可拖拽配置) ──────────────────────────────────┤
│ ☐ │ 代码  │ 名称   │ 现价    │ 涨跌幅 │ 综合评分 │ 缠论评分 │ ... │
│ ☐ │ 000762│西藏矿业│ ¥12.34 │ -2.10%│ 72      │ 78      │ ... │
│ ☐ │ 600036│招商银行│ ¥42.15 │ +0.65%│ ⚡策略评估│         │ ... │
└────────────────────────────────────────────────────────────────────┘
```

### 1.2 数据加载流程

```
页面加载
  │
  ├─ GET /api/v3/watchlist ─→ 获取自选股列表（代码+名称）→ 渲染表行
  │                           (proto: stockData[] 8只硬编码, 无需加载直接渲染)
  │
  └─ 页面无自动行情加载，等待用户操作
       │
       ├─ ⚡策略评估 → POST /api/v3/screener/evaluate  → 单只评分
       │               (proto: Math.random() 模拟，全Mock)
       │
       ├─ 🔄策略刷新 → POST /api/v3/screener/evaluate-batch → 全部评分
       │               (proto: Math.random() 全量，全Mock)
       │
       ├─ ＋添加股票 → GET /api/v3/symbols/search?keyword= → 搜索下拉
       │               (proto: 5只静态Mock结果, stock-list已就绪但未接入)
       │
       ├─ ⚙️列配置  → 前端ALL_COLUMNS定义（50列，不需要后端调用）
       │
       ├─ 行点击    → 跳转 indicator-ide.html?code={ts_code}
       │
       └─ WebSocket 实时行情 → watchlist_update 事件（当前Mock: "已连接"状态标签）
```

### 1.3 数据状态总览

| 区块 | 当前状态 | 数据项概览 | Mock占比 |

| 资金流向（14列） | ❌ 硬编码 `stockData[*].fund_net/...` | 8×14=112字段 | ~100% |
| 基本面（16列） | ❌ 硬编码 `stockData[*].pe_ttm/...` | 8×16=128字段 | ~100% |

**总计：约 488 个数据字段全硬编码 Mock，≥ 99% 页面数据无后端服务。**

## 3. API 端点规格

### 3.1 已就绪 CRUD 端点（4路由）

| # | 端点 | 方法 | 原型引用 | 说明 |
|:-:|:-----|:-----|:---------|:-----|
| W1 | `GET /api/v3/watchlist` | GET | `stockData[]` 初始加载 | 返回 `[{id, ts_code, name, sort_order}]` |
