# 446 号 D10 — dim2 7 契约键补产出（真实接线）

## 一、问题确认（445 §6.1 dim2 偏差，代码级已核）

**缺失 7 契约键**（445 §6.1 dim2 输出项）：
> `level_cross_score / chanlun_phase / trend_structure_signal / ts_strength / buy_sell_points_detail / stage_name / divergence → dim_adapter/conflict_matrix 增强静默失效`

**消费端（已在代码核实均读这些键，但引擎从未产出）**：
| 消费方 | 读取键 | 原行为 |
|---|---|---|
| dim_adapter.convert_to_factors L526-553 | `level_cross_score` | strength = 0.4·chanlun_strength + **0.4·level_cross_score** + 0.2·continuous_value（死读 0.5） |
| 同上 | `trend_structure_signal` + `ts_strength` | `123_buy_breakout` 且看多 → `_dim2_str += _ts_strength + 0.05`（ts_strength 死读 0） |
| 同上 | `chanlun_phase` | 含 '欲病' → `_dim2_str *= 0.7`（死读 ''，从不触发） |
| 同上 | `buy_sell_points_detail` | 确认买/卖点 → direction 增强（死读 []，从不触发） |
| 同上 L553 | `stage_name` / `divergence` | `_dim2_extras['stage_name'/'divergence']` = 空串 |
| conflict_matrix L88-96 | `chanlun_phase` / `divergence_type` / `divergence_strength` / `trend_structure_signal` | C1 欲病/ C2 stage_name / C6·C10 趋势背驰 / C6 123突破 全部静默死读 |
| reliability_assessor L81 | `level_cross_score` | 0.5·level_cross_score（死读 0.5） |

**根因**：`Dim2StructureEngine.evaluate` 的 `status_description` 只产出 vs_* / chanlun_direction / chanlun_strength / buy_sell_points / plain 五类，**7 契约键从未写入手册**；而 `ChanlunLevelValidator`/`TrendStructureDetector` 早已 import（dim2_structure_engine.py L37-41/L71）却是**死 import**，从未实例化调用（445：「多级别未接线（死 import）」）。

## 二、修复方案（用户拍板：7 键全量 + 真实接线）

### 2.1 引擎真实接线（dim2_structure_engine.py）

在 `evaluate()` 中新增 7 键真实产出：

| 契约键 | 数据源（真实接线） | 说明 |
|---|---|---|
| `divergence` | `chanlun_result['divergence']` | 背驰对象存在 → `'底背驰'`（direction==up）/ `'顶背驰'`；无 → `''` |
| `divergence_type` | 同上 `.type` 映射 | 'trend'→'趋势背驰' / 'consolidation'→'盘整背驰' / 'zhongshu'→'中枢背驰'（conflict_matrix C6/C10 读中文） |
| `divergence_strength` | 同上 `.confidence` | 浮点 [0,1]，round 4 位 |
| `buy_sell_points_detail` | `buy_points` + `sell_points` 序列化 | 每项 dict：`type`('buy'/'sell') / `point_type` / `confirmed`(confidence≥0.6) / `confidence` / `price` / `date` / `index` / `reason`（consumer 只读 type+confirmed） |
| `chanlun_phase` | `chanlun_result['theorem_check'].summary.overall_score` | ≥0.6 → '健康'，否则 '欲病'（dim_adapter 用子串 '欲病' 匹配） |
| `stage_name` | `struct_state`（已产） | 上升/下降/盘整，与 judgment.structure 同源 |
| `level_cross_score` | **`ChanlunLevelValidator().validate(df)['cross_score']`**（死 import 复活） | try/except 守护 → 失败或 <30 行回退 0.5 |
| `trend_structure_signal` | **`TrendStructureDetector().detect(df)['signal']`** | try/except 守护 → 无数据 '' |
| `ts_strength` | 同上 `.strength`（字符串→float 映射） | 'strong'→0.3 / 'basic'→0.1（**修复格式不匹配**：consumer `_safe_float` 读 float，detector 原返回字符串） |

### 2.2 修复 ChanlunLevelValidator 级别趋势读取 bug（随接线发现）

`chanlun_level_validator.py:_analyze_level`：
```python
"trend": result.get('trend', {}).get('direction', 'unknown'),  # ✗ trend 是标量字符串，非 dict
```
`chanlun_result['trend']` 为 `'up'/'down'/'unknown'` 字符串；原 `.get('direction')` 在字符串上调用直接抛异常 → 各级别 `_analyze_level` 落空 → `_cross_validate` 中 `monthly_trend=='up'` 级别定理分支**从未生效**。修复为：
```python
"trend": result.get('trend', 'unknown'),  # ✓ 标量字符串
```
