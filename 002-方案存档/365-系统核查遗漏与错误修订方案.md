| 高潮 | climax | 涨停>80家 + 炸板率<20% + 全面赚钱效应 |
| 退潮 | ebb | 涨停持续下降 + 龙头断板 + 炸板率上升 |
| 回归 | regression | 涨停回归常态 + 连板高度≤2 + 市场广度收敛 |

#### C1：evaluate() 重构 — 调用6维度引擎（8h）

**文件**：`backend/app/opportunity_atlas/status_engine.py`

**变更**：重构 `evaluate()` 方法，从内联10维改为调用6个维度引擎 + 兼容层

```python
def evaluate(self, ts_code: str) -> dict:
    tags = self._load_tags(ts_code)
    signals = self._load_signals(ts_code)
    lifecycle = self._signal_lifecycle(signals)
    
    # 新增：调用6维度引擎
    dim_results = {}
    for dim_name, engine_cls in DIMENSION_ENGINES.items():
        engine = engine_cls()
        dim_results[dim_name] = engine.evaluate(tags, signals)
    
    # 兼容层：将dim_results转换为旧dims格式（供arbiter/cross_validate消费）
    legacy_dims = self._convert_to_legacy_dims(dim_results)
    
    l0 = self._apply_l0(tags, signals)
    l2 = self._aggregate(legacy_dims, l0)
    hits = self._detect_registered_signals(signals, tags)
    
    return self._assemble(lifecycle, legacy_dims, l0, l2, hits, dim_results)
```

**DIMENSION_ENGINES 注册表**：

```python

    'emotion': Dim5EmotionEngine,

}
```

## 十一、风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| evaluate()重构导致判定结果变化 | 用户可见的股票排序变化 | 新旧路径并行运行，diff验证一致性后再切换 |
| vol_ratio基准统一后放量判定标准变化 | 部分股票的BUY/SELL信号可能变化 | 统一前记录各模块当前基准和阈值，统一后做全量回归 |
| 六段论替换四阶段后情绪判定变化 | 情绪维度light可能翻转 | 分阶段切换：先并行运行，对比结果后再替换 |
| pre_feat_cache字段增加导致预计算耗时增加 | 全市场预计算时间可能超过5分钟 | 监控预计算耗时，必要时异步化或分批计算 |
