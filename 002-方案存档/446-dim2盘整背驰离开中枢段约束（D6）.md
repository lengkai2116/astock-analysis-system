# 446 号 D6 — dim2 盘整背驰"离开中枢段"约束修复

## 一、问题确认（445 §6.1 dim2 偏差 D6，代码级已核）

**知识库权威**（外部 wiki《缠论走势结构量化系统配置指南》L92）：
> "盘整中的假背驰：**只有在离开中枢的段中出现的背驰才计入信号**"

**引擎现状**（`chanlun_strategy.py:_detect_consolidation_divergence` L1664-1718）：
```python
def _detect_consolidation_divergence(self, strokes):
    ...
    # 仅凭最后两笔方向交替 + 幅度放大 1.1× 判背驰，完全不参考中枢
    if last_stroke.direction != prev_stroke.direction:
        if last_stroke.direction == 'down':
            down_amp = abs(...)
            if down_amp > up_amp * 1.1:
                return Divergence(type='consolidation', direction='up', ...)  # 底背驰
        elif last_stroke.direction == 'up':
            if up_amp > down_amp * 1.1:
                return Divergence(type='consolidation', direction='down', ...)  # 顶背驰
```

**矛盾机制（实证）**：盘整走势（中枢内反复 high-low 震荡）中，任一"回调/反弹幅度 > 前笔 × 1.1"的波动即被判为盘整背驰，产生 `consolidation` → `BuySellPointDetector` 转 `first_buy_p`/`first_sell_p`（L1835/1843）→ 下游一票否决（data_daemon:4252）、phase_detector / arbiter / cross_validate 全部消费 `first_buy_p`/`first_sell_p` 方向信号。**这些假背驰段从未离开中枢**，却触发强买/强卖信号——正是知识库 L92 禁止的"盘整内假背驰"。（对比 342 号已为**趋势背驰**加"须处上涨/下跌结构"校验，盘整背驰这一支始终裸奔。）

**影响面（消费链）**：
| 消费方 | 位置 | 影响 |
|---|---|---|
| BuySellPointDetector.find | chanlun_strategy.py:1835/1843 | consolidation→first_buy_p/first_sell_p（本号源头过滤） |
| get_chanlun_tags | chanlun_strategy.py:2551 | buy_sell_point 标签含 first_buy_p/first_sell_p |
| data_daemon RAW + SIG | data_daemon.py:3340/4243/4252 | RAW 缠论特征 + 右侧确认一票否决 |
| dim2_structure_engine | dim2_structure_engine.py:137/159 | buy_sell_points 现状描述 |
| phase_detector/arbiter/cross_validate | 各 :269/:44/:337 | first_buy_p 方向信号权重 |

## 二、修复方案（用户拍板：约束 + 补 detail 输出）

### 2.1 `_detect_consolidation_divergence` 增加"离开中枢段"约束

- 函数新增参数 `zhongshu_list`（可选，默认 None，向后兼容）。
- 存在最近中枢 `zhongshu_list[-1]` 时，产生背驰的**最后笔终点必需已离开中枢**：
  - **底背驰**（最后笔 down）：终点须 `is_below(zs.low)`（跌破中枢下沿）；仍在中枢内的回调放大 = 假背驰，过滤。
  - **顶背驰**（最后笔 up）：终点须 `is_above(zs.high)`（突破中枢上沿）；仍在中枢内的反弹放大 = 假背驰，过滤。
- **无中枢**（`not zhongshu_list`）= 无约束，保留原幅度逻辑兜底（不退化，兼容历史行为）。

### 2.2 新增辅助 `_consolidation_exited_zhongshu`

返回 `(离开的中枢 zs, 方向 'up'/'down')`；未离开或无中枢返回 `(None, None)`。由主函数在幅度条件满足后调用来做离开约束判断。

### 2.3 `Divergence.details` 补 `exited_zhongshu` / `zhongshu`

- `details['exited_zhongshu']`：布尔，本背驰是否来自离开中枢的段。
- `details['zhongshu']`：离开的中枢 repr 字符串（供 dim8/444 现状"因"引用趋势/位置关系），未离开或无中枢为 None。

### 2.4 `detect` 调用处透传 `zhongshu_list`

`DivergenceDetector.detect` 中 `_detect_consolidation_divergence(strokes)` → `(strokes, zhongshu_list)`。`detect` 已持有 `zhongshu_list`（自 `analyze` 传入），无需额外接线。

> 注：中枢背驰 `_detect_zhongshu_divergence`（L1721）本已用 zs 判断"离开上方""回调回中枢"，与 D6 目标一致；本号仅对齐**盘整背驰**这一支未约束裸奔路径。

## 三、影响评估（445 约束：不破坏分析引擎判定逻辑/阈值/窗口）

- **判定语义变化**：盘整背驰由"任意幅度放大"改为"仅离开中枢段的幅度放大"——这是**有意修正**（对齐知识库 L92），使假背驰不再产 first_buy_p/first_sell_p 强信号。
- **阈值/算法不变**：`down_amp > up_amp * 1.1` 幅度阈值、MACD 面积/力度法定标、confidence 等均不动；仅在其外层加"离开中枢"闸门。
- **无中枢兜底**：无中枢股票（笔/段不足）行为与修复前完全一致，不退化。
- **趋势背驰/中枢背驰**：完全不受影响（走独立分支）。
