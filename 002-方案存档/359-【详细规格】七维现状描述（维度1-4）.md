## 第1维：信号确认状态（已确认）

### 1.1 维度定位

- **性质**：派生维度（非独立引擎），由其他6个维度的输出组合派生
- **覆盖范围**：全量股票（每只都有属性分类）
- **独特价值**：其他维度描述"状态"（持续性的），本维度描述"事件+性质+时效"
- **核心问题**："这只股票处于什么性质的状态、信号有多强、还能持续多久"

### 1.2 三个核心方面

| 方面 | 核心问题 | 输出内容 |
|------|---------|---------|
| **信号属性** | "这只股票处于什么性质的状态" | 7类全量分类（右侧确认/左侧试探/风险警示等） |
| **信号强度** | "这个信号有多强" | 共振评分(0-100) + 置信度 + 共振维度数 |
| **信号维持** | "信号还能持续多久" | 生命周期 + 多维度衰减检测(0-100衰减分) |

### 1.3 信号属性（7类全量分类）

#### 属性清单

| 属性 | 代码 | 定义 | 判断优先级 |
|------|------|------|:---------:|
| **风险警示** | risk_warning | 风险因素触发，需警惕 | 1（最高） |
| **右侧确认** | right_confirmed | 趋势已被确认，多信号共振 | 2 |
| **右侧初现** | right_emerging | 趋势信号刚出现，尚未验证 | 3 |
| **左侧试探** | left_probing | 下跌中出现反转迹象，未确认 | 4 |
| **趋势运行中** | trend_running | 已有趋势在运行，无新信号 | 5 |
| **盘整待变** | consolidating | 无明确方向，等待突破 | 6 |
| **中性观望** | neutral | 无明显特征 | 7（默认） |

#### 数据驱动的判断依据

**右侧确认**：
```
signal_registry匹配到≥1个右侧信号
AND 信号已通过验证期（3-5日不破信号价）
AND 共振维度≥2（结构+量价/筹码中至少2个score>0.5）
AND 风险等级<高
```

**右侧初现**：
```
signal_registry匹配到≥1个右侧信号
AND 信号未通过验证期（触发<3日或已破信号价）
AND 共振维度≥1
```

**左侧试探**（5个条件全部必须满足）：
```
缠论趋势=下降（结构维度）
AND 筹码流入强度>0.5（moneyflow 5日净流入，筹码维度）
AND 量价健康度>60（volume_price health_score，量价维度）
AND 估值=低估/极度低估（valuation_level，估值维度）
AND 风险等级<高（风险维度）
```

**趋势运行中**：
```
结构强度>0.6（趋势明确）
AND 无新信号触发（signal_registry未匹配）
AND 量价健康度>50
AND 风险等级<中
```

**盘整待变**：
```
结构方向=盘整（中枢内震荡）
AND 量价健康度在40-60之间
AND 筹码无明显流入/流出（flow_strength<0.3）
AND 无信号触发
```

**风险警示**：
```
风险三维评估等级≥高（无论其他维度状态如何）
```

**中性观望**：以上条件均不满足

#### 判断优先级（冲突处理）

```
风险优先 → 右侧优先 → 左侧次之 → 趋势再次 → 盘整兜底 → 中性默认
```

#### 属性输出

```json
{
  "attribute": {
    "code": "right_confirmed",
    "name": "右侧确认",
    "confidence": 0.85,
    "evidence": "3信号共振（放量突破+均线多头+缠论三买），最早信号已验证5天",

  }
}
```

### 1.4 信号强度（共振评分）

#### 评分公式

```
strength_score = structure_score × 0.25    # 结构确认度（缠论）
              + volume_score × 0.30        # 量价配合度（量价引擎）
              + chip_score × 0.25          # 筹码支持度（筹码引擎）
              + factor_score × 0.20        # 因子支撑度（因子引擎）
```

#### 共振检测

```
resonance_count = 各维度中 score > 0.5 的数量
resonance_dims = score > 0.5 的维度名称列表
```

#### 强度等级

| 分数区间 | 等级 | 含义 |
|---------|------|------|
| 80-100 | 极强 | 多维度高度共振，信号非常明确 |
| 60-79 | 强 | 多维度共振，信号明确 |
| 40-59 | 中等 | 部分维度支持，信号一般 |
| 20-39 | 弱 | 仅个别维度支持 |
| 0-19 | 极弱 | 无明确支撑 |

#### 强度输出

```json

    "confidence": 0.82,

    "resonance_dims": ["structure", "volume_price", "chip"],

  }

```

### 1.5 信号维持（多维度联合衰减检测）

#### 五个检测维度

| 维度 | 数据源 | 检测指标 | 衰减信号 | 权重 |
|------|--------|---------|---------|:----:|
| **走势变化** | daily_cache | 价格vs信号价距离变化（3日趋势） | 距离连续缩小 | 30% |
| **量价关系** | daily_cache + daily_basic | 量比变化+量价配合度 | 放量后持续缩量+背离 | 25% |
| **量能变化** | daily_cache | 成交量vs20日均量比值 | 连续3日低于均量 | 20% |
| **筹码变化** | moneyflow + stk_holder | 主力资金流向+筹码集中度变化 | 主力净流出+筹码分散 | 15% |
| **主力行为** | lhb_cache + margin | 龙虎榜席位+融资余额变化 | 机构卖出+融资下降 | 10% |

#### 量价状态分类（基于[[动态量价状态感知策略]]）

| 量价状态 | 定义 | 衰减信号 |
|---------|------|---------|
| **健康动量** | 价涨量增/价跌量缩 | 无 |
| **背离预警** | 价涨量缩/价跌量增 | 严重衰减 |
| **极端信号** | 天量天价/地量地价 | 可能反转 |
| **筹码转换** | 放量突破/缩量回踩 | 无（健康） |

#### 筹码变化检测（基于[[筹码分布]]+[[主力行为分析]]）

```
筹码集中度变化 = 当前集中度 - 信号触发时集中度
  < -0.1 → 筹码分散（衰减）

主力资金流向 = moneyflow 5日净流入
  < 0 → 资金净流出（衰减）

主力阶段判定 = 建仓/洗盘/拉升/出货
  出货 → 严重衰减
  洗盘 → 短期扰动（可能恢复）
```

#### 衰减评分（0-100连续值）

```
decay_score = price_trend_score × 0.30    # 走势
            + vp_relation_score × 0.25    # 量价
            + volume_energy_score × 0.20   # 量能
            + chip_change_score × 0.15     # 筹码
            + main_force_score × 0.10      # 主力
```

| 衰减分 | 状态 | 含义 |
|:------:|------|------|
| 0-39 | **healthy** | 信号健康，无需担忧 |
| 40-69 | **fading** | 信号衰减，需关注 |
| 70-100 | **broken** | 信号失效 |

### 1.6 风险三维模型（信号属性中"风险警示"的细化）

#### 三个维度

| 维度 | 分级 | 说明 |
|------|------|------|
| **严重度** | 极端/高/中/低/可忽略 | 风险的大小程度 |
| **时间性** | 即将(1-5日)/中期(1-3月)/远期(3月+)/持续 | 风险的兑现时间 |
| **可逆性** | 不可逆/部分可逆/可逆 | 风险发生后能否挽回 |

#### 严重度分级

| 等级 | 示例 | 响应 |
|------|------|------|
| **极端** | 财务造假/退市/监管立案 | avoid（硬否决） |
| **高** | 商誉减值/质押爆仓/基本面恶化 | 限仓+限时 |
| **中** | 行业周期下行/高管减持/估值偏高 | 限仓 |
| **低** | 短期超买/技术背离 | 提示 |
| **可忽略** | 正常波动 | 无 |

#### 组合判断逻辑

```
不可逆 + 极端 → avoid（硬否决）
高 + 即将 → 限仓≤10% + 持有≤5天
高 + 中/远期 → 限仓≤20% + 必须止损
中 → 限仓≤30% + 持有≤20天
低 → 仅提示
可忽略 → 无
```

#### 关键场景："高风险+远期+可逆 + 强信号"

```
风险属性：high/long/reversible → 不否决，但限制
信号属性：right_confirmed + strength=75 → 可操作

组合决策：
  短线（≤5天）：✅ 允许（风险尚未兑现）
  中线（5-20天）：⚠️ 需设严格止损
  长线（>20天）：🚫 不建议（风险兑现期接近）
```

## 第2维：结构位置状态（已确认）

### 2.1 维度定位

- **核心问题**："价格站在哪"
- **主责引擎**：缠论引擎
- **辅助引擎**：量价引擎（均线排列）、advice_builder（几何化距离）
- **数据来源**：daily_cache + minute_kline + pre_feat_cache
- **独特价值**：回答价格在空间中的位置——"刚脱离成本区"还是"远离成本区"，决定介入的贵贱
- **设计原则**：基于[[三层分析框架]]（结构先行→位置确认→时间验证），5维度交叉验证，几何化指标优先

## 第3维：量价健康度（已确认）

### 3.1 维度定位

- **核心问题**："涨得结不结实"
- **主责引擎**：量价引擎（VolumePriceStrategy）
- **辅助引擎**：缠论（背驰检测）、factor_cache（指标验证）
- **数据来源**：daily_cache + daily_basic_cache + minute_kline_cache
- **独特价值**：描述价格变化背后的"参与热度"和"供需动力"——成交量反映多空博弈的强度，价格反映博弈的结果
- **设计原则**：基于[[动态量价状态感知策略]]（从静态形态匹配→动态状态感知），8个子维度交叉验证

### 3.2 核心设计理念

**量价关系的本质**：成交量反映市场参与热度（非严格"动能"），价格反映多空博弈结果。K线实体和影线需要**结合成交量**才能判断多空对抗的强度——长上影线+高量=多空激烈争夺，长上影线+低量=抛压轻。

[[量价关系]]明确："成交量是先行指标，价格是滞后指标"。量价分析的核心是识别"多空在不同量价组合下的力量对比"。

### 4.3 主力定义与判定框架

#### 4.3.1 "主力"的定义

#### 子维度3：成本分布结构

##### 维度定位

| **trapped_ratio** | 套牢盘比例(1-profit_ratio) | — | 套牢盘=上方卖压 |

##### 成本偏离与趋势关系（基于LLM Wiki多文档整合）

| 筹码状态 | 现价位置 | 持仓者心理 | 卖压分布 | 风险评估 |
|---------|---------|-----------|---------|---------|
| 单峰密集+现价在峰上方 | 突破筹码密集区 | 大部分盈利，信心足 | 卖压小 | 低风险：趋势延续概率高 |
| 单峰密集+现价在峰下方 | 跌破筹码密集区 | 大部分套牢 | 反弹到密集区卖压重 | 高风险：反弹空间有限 |
| 单峰密集+现价在峰附近 | 成本区震荡 | 多空分歧大 | 突破方向决定后续 | 不确定：方向选择期 |
| ASR从>90回落到<50 | 突破确认 | 筹码从集中到扩散 | 套牢盘被消化 | 低风险：突破有效 |
| 双峰/多峰+现价在两峰之间 | 套牢盘+获利盘共存 | 上下夹击 | 上有压力下有支撑 | 中等风险：波动加大 |

##### 筹码转移检测（基于《筹码转移》+技术说明书）

| 转移类型 | 量化条件 | 含义 | 转移速度 |

| **稳定** | 变化均<5% | 筹码未明显移动 | — |

##### 风险评估框架（不是预测，是差异风险评估）

```

获利盘40-60% + 筹码密集 → 中等风险：方向选择期

```
