# 384 — 维度5（情绪环境）策略引擎升级方案

> **背景**：基于377号SOP阶段〇深度审查，对dim5情绪环境引擎（1096行）进行全面代码阅读、Bug识别、输出规则审查、知识库对标和外部项目对标，编制系统性升级路径。
>
> **核心原则**（358号§1.1 + 360号§5.1）：
> - **纯描述维度**：只描述情绪现状，不生成买卖信号（信号由dim1负责）
> - **三层面架构**：市场情绪（全局）→ 板块情绪（行业级）→ 个股情绪（个股级）
> - **双轨输出**：现状描述轨（面向用户）+ 灯色判定轨（面向JUD）
> - **数据消费原则**：SIG环节消费RAW预计算数据，不自行重复计算

## 一、引擎架构概览

### 1.1 引擎文件

| 项目 | 内容 |
|------|------|
| 引擎文件 | `dim5_emotion_engine.py`（1096行） |
| 整合源文件 | emotion_builder.py(182行) + bociasi_quickline.py(131行) + bociasi_slowline.py(171行) + bociasi_quadrant.py(347行) + emotion_temperature.py(103行) + sector_rotation_model.py(144行) + time_rhythm_engine.py(103行) |
| 核心组件 | Dim5EmotionEngine / BociasiQuadrantAnalyzer / SectorRotationModel |
| 顶层函数 | `_bociasi_quickline()` / `_bociasi_slowline()` / `_bociasi_quadrant()` / `calc_emotion_temperature()` / `_time_rhythm()` / `_assess_market_emotion()` / `_assess_sector_emotion()` / `_assess_stock_emotion()` / `_overall_light()` / `_emotion_plain()` |
| 分析框架 | BOCIASI快慢线四象限 + 六段论情绪周期 + 情绪温度(0-100) + 板块轮动 + 三层面情绪评估 |
| 数据来源 | daily_cache(OHLCV) + daily_basic_cache(PE_TTM) + pre_feat_cache(tags) + sentiment_pool_cache(涨跌停) + margin_cache(融资) + indicator_other(RSI) + compute_cache.db分库 |
| 输出对象 | status_description（现状描述）+ judgment（灯色判定）+ audit（条件稽核） |

### 1.2 组件调用链

```
Dim5EmotionEngine.evaluate(dims, tags, lifecycle)
  ├─ _bociasi_quickline(df)                 ← 日线OHLCV → 快线4指标
  ├─ _bociasi_slowline(df_basic)            ← daily_basic → ERP+股债位置差  ⚠️ 数据源问题
  ├─ BociasiQuadrantAnalyzer.analyze()      ← 全市场DB查询 → 快慢线四象限
  ├─ _assess_market_emotion(tags, dims)     ← tags.sentiment_phase → 六段论阶段
  ├─ _assess_sector_emotion(tags, dims)     ← tags.sector_heat → 板块热度
  ├─ _assess_stock_emotion(tags, dims)      ← dims.vp → 个股情绪
  ├─ SectorRotationModel.evaluate(ts_code)  ← 全市场行业排名 → 板块热度  ⚠️ 缓存未预热
  ├─ calc_emotion_temperature(...)          ← 7维度加权 → 温度0-100  ⚠️ 参数缺失
  ├─ _overall_light(...)                    ← market+sector+stock → 灯色
  └─ _emotion_plain(...)                    ← 综合 → 白话描述
```

### 3.1 B1修复：`_bociasi_slowline`数据源修正

**目标**：慢线获得正确的数据源，使股债位置差功能恢复。

**当前代码**（evaluate() L948-951）：
```python
df_basic = ecm.get_cached_daily_basic(ts_code)
if df_basic is not None and not df_basic.empty:
    slow_result = _bociasi_slowline(df_basic)
```

**问题**：`get_cached_daily_basic`返回daily_basic_cache表数据（pe_ttm/turnover_rate/circ_mv等），但`_bociasi_slowline()`内部L188访问`df['close']`计算股债位置差 → KeyError。

**修复方案**：
```python
# 方案A：传入正确数据源（推荐）
# slowline需要：①close列（从daily_cache）②pe_ttm（从daily_basic_cache）
df_daily = ecm.get_cached_daily(ts_code)  # 含close
df_basic = ecm.get_cached_daily_basic(ts_code)  # 含pe_ttm
# 合并：将pe_ttm注入daily数据
if df_daily is not None and df_basic is not None and not df_basic.empty:
    merged = df_daily.copy()
    merged['pe_ttm'] = df_basic['pe_ttm'].values[:len(merged)] if 'pe_ttm' in df_basic.columns else None
    slow_result = _bociasi_slowline(merged)
```

**影响范围**：evaluate() L948-951，~5行修改
**验证方式**：3只股票测试，确认慢线不再是NEUTRAL(0.3)，details中sb_signal有值

```python
def _build_market_evidence(market, quadrant, quick, slow, temp):
    parts = []
    parts.append(f"情绪阶段={market['phase']}")
    parts.append(f"四象限={quadrant['quadrant']}({quadrant['description']})")
    parts.append(f"快线={quick['signal']}(置信度{quick['confidence']})")
    parts.append(f"慢线={slow['signal']}(置信度{slow['confidence']})")
    parts.append(f"温度={temp}/100")
    return '；'.join(parts)
```

### 3.6 B9修复：个股情绪数据源修正

**目标**：`_assess_stock_emotion()`从正确的数据源读取。

**当前问题**：从`dims.get('vp', {}).get('state', '')`读取，但dims['vp']是旧格式。

```python
def _assess_stock_emotion(tags: dict, dims: dict) -> dict:
    # 优先读emotion_ext.stock_emotion（data_daemon预计算）
    stock_emo = tags.get('stock_emotion', '')
    if stock_emo == 'positive':
        return {'emotion': '积极', 'detail': '量价配合良好，个股情绪积极', 'light': 'green'}
    elif stock_emo == 'negative':
        return {'emotion': '消极', 'detail': '量价背离，个股情绪需警惕', 'light': 'red'}

    # 降级：从dim3引擎结果读取
    vp_result = dims.get('volume_price', {})
    if isinstance(vp_result, dict):
        sd = vp_result.get('status_description', {})
        direction = sd.get('state_machine_direction', '')
        if direction == 'BUY':
            return {'emotion': '积极', 'detail': f"量价建议买入", 'light': 'green'}
        elif direction == 'SELL':
            return {'emotion': '消极', 'detail': f"量价建议卖出", 'light': 'red'}

    return {'emotion': '中性', 'detail': '个股情绪数据不足', 'light': 'yellow'}
```
