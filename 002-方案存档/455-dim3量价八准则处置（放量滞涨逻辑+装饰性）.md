# 455 号 — dim3 量价八准则处置（放量滞涨逻辑缺陷 + 八准则装饰性）

## 一、问题确认（445 §6.3 dim3，代码级已核）

445 评估登记 dim3 两条独立偏差（450 未覆盖）：

**偏差① 放量滞涨（heavy_pressure）逻辑缺陷** `_classify_granville`：
- 原判据 `abs(price_chg)<1.5 and vr>20`
  - `vr` 取 **5日/20日均量平滑均值**（`(vol5/vol20-1)*100`），单日放量即可拉高均值触发，**不保证「连续数日放大」**；
  - `abs()` 允许 **−1.5%~0 实质下跌**入选（放量下跌应为 selling_pressure，却误归 heavy_pressure）；
- 与 framework 权威 `_is_fangliang_zhizhang`（`volume_price_strategy.py:604-614`，已注册预跌型放量滞涨）+ wiki 冲突：
  - framework：近3日**每根**量 `>20日均量×1.5`（逐日口径，非平滑均值）且 **3日涨幅和 `<0.01`**（价格无法加速）；
  - wiki《量价关系八准则》：放量滞涨=「成交量**连续数日明显放大** + 价格**横向振荡/整理、无法加速**」。

**偏差② 八准则装饰性输出**：
- `_classify_granville` 结果仅进 `status_description['granville']` 文案（`dim3_vp_engine.py:222`），**不进 `audit.conditions`/`judgment`**——分类结论对 SIG 稽核（audit.confidence）零影响；
- 450 曾主动保持此取舍（只改展示），445 登记为独立缺陷：八准则本应作为量价形态证据参与 SIG 条件稽核。

## 二、修复方案（用户拍板：双缺陷都修 + audit新增条件）

### 2.1 偏差①：heavy_pressure 判据对齐 framework/wiki
`_classify_granville` heavy_pressure 分支重写：

```python
avg20 = vs.iloc[-20:].mean() if len(vs) >= 20 else None
recent3_vol = vs.iloc[-4:-1] if len(vs) >= 4 else None
consec_expand = (
    avg20 is not None and recent3_vol is not None and avg20 > 0
    and all(v > avg20 * 1.5 for v in recent3_vol)
)
_n = len(close)
gains3 = [(close.iloc[i] - close.iloc[i - 1]) / close.iloc[i - 1]
          for i in range(_n - 3, _n)]
stall_sum = sum(gains3)
...
elif consec_expand and stall_sum < 0.01:
    result = {'rule': 'heavy_pressure', 'name': '放量滞涨',
              'description': '连续数日量能显著放大但价格无法加速，上方压力沉重'}
```

- **连续数日放大**：近3日**每根**量 `> 前20日均量×1.5`（逐日口径，对齐 framework `all(v>avg_vol*1.5)`与 wiki「连续数日明显放大」）；
- **价格无法加速**：近3日价格涨幅和 `< 1%`（对齐 framework `<0.01`，含微涨/微跌/横盘，消除原 abs 允许实质下跌入选）；
- df 不足 20 日时 `consec_expand=False` 安全回退（不抛异常，落其它分支）。

### 2.2 偏差②：八准则接入 audit（消除装饰性）
`evaluate()` audit.conditions 新增第 6 条 **`量价八准则`**：

```python
{'name': '量价八准则', 'satisfied': granville['rule'] not in (
    'heavy_pressure', 'weakening', 'selling_pressure', 'breakdown', 'diverging'),
 'actual': granville['name'],
 'threshold': '非负面量价形态（放量滞涨/量减/放量跌/背离/破均线）'},
```

- 负面形态（放量滞涨/价升量减/放量下跌/量价背离/放量破均线）→ `satisfied=False`，拉低 `audit.confidence`，**真正参与 SIG 条件稽核**；
- 中性/健康类（量价齐升/井喷/回探缩量/中性）→ 满足；
- `status_description['granville']` 文案**保留**（展示不丢失）；
- **SIG/JUD 边界**：仅接入 `audit.conditions`（SIG 证据/条件），不触碰 `judgment`/灯色（仍归 JUD，不越界）。
