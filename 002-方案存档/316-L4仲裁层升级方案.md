# L4 仲裁层升级方案

## 一、背景与问题链

### 1.1 触发问题（招金黄金矛盾）

机会地图弹窗显示"蓝色可入"（闸门2 强确认 + 共识 57%）但操作建议"不推荐"（L4 估值门禁：valuation_level=high 直接硬否决）。矛盾率实测：蓝色（强确认）∩ 门禁不推荐 = 73.5%（估值修正前）→ 33.3%（估值修正后）。本质是**两个独立体系冲突**：方块颜色=时机（闸门2 技术面），L4 建议=估值门禁（投票前硬截断）。

### 1.2 三闸门梳理结论（2026-08-05）

| 闸门 | 定位 | 是否需调整 |
|------|------|-----------|
| 闸门1（机会监控） | L4 daily_change_summary 8 维度 | 无需（估值修正后语义自动改善：extreme_high=真高估→urgent 合理） |
| 闸门2（右侧确认） | 纯技术面四档 | 无需（与估值正交；输入 bug 已修复） |
| 闸门3（L4 仲裁） | 共识投票 + 估值门禁 | **本次升级对象** |

### 1.3 估值修正衔接（315 号已实施）

- valuation_level 改 composite 截面百分位分档（5/20/80/95）→ high=11.1%（PE 分位 51.6%，真高估）
- 门禁范围 55%→15.6%，但**门禁位置（投票前截断）与一刀切问题未解决**——本方案承接

## 二、升级目标与原则

1. **判定有效性**：门禁只拦截真实风险（深度高估/重大风险），不误伤合理波动
2. **判定准确性**：票源投票反映真实方向（去除系统性偏向票源），共识率可解释
3. **建议可执行性**：操作建议从"机械标签"升级为"入场/仓位/止损/止盈"结构化可执行输出
4. **原则**：门禁不否决时机（闸门2×闸门3 合成后做风险约束）；情绪为环境变量（不参与个股投票）；估值为风险标注（非机会否决）

## 三、Step A 估值门禁升级

### 3.1 现状（实证）

```
cross_validate.py:231-235
valuation_level ∈ {high, extreme_high} → 直接 return _build_gate_denied（不推荐，不走投票）
```
- 一刀切：high=截面 15%（PE 分位 51.6%，"相对偏贵"非极端泡沫）也被否决
- 位置错误：投票前截断，强确认+高共识被吞（招金黄金案例）
- 维度单一：无财务/事件/流动性等强风险项否决

### 3.2 估值门禁分级设计（替代 5 档硬切）

用**连续偏离度**（PE 历史分位 + deviation）分级：

| 等级 | 判定条件 | 处理 |
|------|---------|------|
| 轻度偏高 | PE 分位 60-80% 或 deviation -6~-12 | 风险标注 + 仓位上限压缩一档，**不否决** |
| 中度偏高 | PE 分位 80-90% 或 deviation -12~-20 | 风险标注 + 仓位上限减半 + 用户清单警示 |
| **深度高估** | PE 分位 >90% 或 deviation < -20 | 触发"仅观察/不推荐" |

依据：主流工具（理杏仁）高估=历史分位 >90%；业界泡沫判定=偏离合理值 30-50%+。

### 3.3 门禁位置后移

```
原：投票前截断（gate_denied 直接 return）
改：① 门禁分级计算 → ② 正常跑 Step B/C/D 共识投票 → ③ 操作建议合成后：
    深度高估 → action 强制降为 not_recommended/仅观察
    中/轻度 → 仓位上限按级压缩 + 风险标注
```
- 深度高估仍不推荐（保留硬否决的尾部），但**强确认+高共识的合理偏贵股**可正常获得建议（矛盾消除）
- 与 313 号"估值为风险标注"知识库原则一致

### 3.4 风险项扩展（门禁从单维→多风险项综合）

| 风险项 | 数据源 | 级别 | 处理 |
|--------|--------|------|------|
| 财务 fail | fina_health | 强 | 仓位上限压缩 50% |
| 事件欺诈/监管 | catalyst_event fraud_sign/regulatory | 强 | 不推荐（负面事件硬否决） |
| 主力出货 | main_force_phase distributing | 中 | 仓位上限压缩 + 警示 |
| 情绪追高 | sentiment_phase climax（短线标签） | 中 | SHORT_TERM_TAGS 看多票降权（已有 0.7，可强化） |
| **流动性风险** | 换手率 <1% / 20 日成交额 <500 万 | 中 | **新增**：仓位上限压缩 + 警示 |
| 质押/解禁 | catalyst pledge/float | 中 | 警示 |

风险等级综合：多风险项加权 → risk_level（当前仅按条数 1-3 档，升级为风险分累计）

## 四、票源体系调整

### 4.1 现状实证（全市场 5560 只 14 票源投票分布，2026-08-05）

| 票源 | 看多 | 看空 | 中性 | 诊断 |
|------|-----:|-----:|-----:|------|
| sentiment_phase | 0 | 5560 | 0 | **全市场同向 -1（climax）——环境变量误作个股票源** ❌ |
| fina_health | 1153 | 4425(80%) | 0 | suspicious→-1 过严（033 期确认"存疑≠有风险"）❌ |
| sector_heat | 141 | 4859(87%) | 560 | none→-1 过严（无热度≠看空）❌ |
| pattern_signal | 74 | 312 | 5174(93%) | 形态覆盖不足（数据退化，需排查）⚠️ |
| ma_alignment | 293 | 826 | 3890(80%) | 均线多数 mixed，中性合理 ⚠️ |
| valuation_level | 1120 | 868 | 3572(64%) | fair 占多数，中性合理 ✅ |
| 主力/资金/买卖点/位置/确认 | — | — | — | 方向基本均衡 ✅ |

**根因**：三大系统性看空票源（sentiment 全 -1 + fina 80% -1 + sector 87% -1）把 consensus_rate 整体压低 → **72.8% 股票 <55%**（闸门3 几乎不放行）。属**配置偏向问题**，非数据缺失。

### 4.2 票源调整项

| # | 调整 | 说明 |
|:-:|------|------|
| 1 | **sentiment_phase 移出个股票源** | 313 §4.1 明确"情绪是环境变量不进个股维度"；情绪由环境权重矩阵处理（Step B），不投票 |
| 2 | **fina_health 校准**：suspicious→0、fail→-1 | 对齐 033 期标尺（suspicious=未达高质量标准，非有风险） |
| 3 | **sector_heat 校准**：none→0 | 板块无热度≠看空；top_10→+1 保留、top_20→+0.5 |
| 4 | pattern_signal 覆盖率排查 | 数据端（当前 93% none，L6 修复后曾 88.6% 非 none——疑退化，需查根因） |
| 5 | **票源动态加权**（状态依赖） | 借鉴知识库《状态依赖的因子合成》：震荡市均值回归类（估值/质量）权重高、趋势市动量类（趋势/资金）权重高；情绪高潮时动量票源降权 |

### 4.3 知识库/同类补充票源（A股五大有效因子：市盈率/规模/速动/税收/市场）

| 候选票源 | 依据 | 实现 |
|---------|------|------|
| **规模因子**（小盘溢价） | 王熙等(2022) A股五大有效因子之一 | 总市值截面分位 → 小盘 +1（可配置是否启用） |
| **速动因子**（流动性） | 同上 | 换手率/成交额 → 低流动性 -1（同时服务 3.4 流动性风险） |
| **低波动因子** | Fama-French 稳健因子 | 20 日波动率 → 低波动 +1 |
| 质量因子（ROE/ROCE） | Barra 质量因子 | fina_health 已近似，可补 roce_pass 票源 |

## 五、操作建议升级（形成方式精细化）

### 5.1 现状问题

- 共识率 → 动作/标签机械映射（_map_consensus_to_action）
- entry_plan 硬编码"60% 当前价 + 40% 回踩"
- **stop_loss/target_price 恒 None（完全缺失）**
- 仓位映射粗糙（事件分/共识率 → 0-0.8）

### 5.2 结构化输出设计（升级后 operation_advice 结构）


### 5.3 各要素形成规则（知识库/同类软件借鉴）

| 要素 | 规则 | 借鉴来源 |
|------|------|---------|
| **入场区间** | 缠论买点位置 / MA10-MA20 回踩带 / 筹码峰上沿 / 突破确认位 | 缠论买卖点定理、《简单估值法》龙头锚 |
| **建仓节奏** | 首仓 40-60%（按风险等级下调）→ 回踩加仓 → 突破加仓（分批金字塔） | 凯利公式（仓位上限）、A股分批建仓惯例 |
| **止损** | 跌破 MA20 / 缠论三卖 / 亏损 5% / 日内回撤 4% / ATR(2×) | 知识库《多层次动态风控网络》（实证回撤 -13.43% 的关键） |
| **止盈** | 估值回归合理（_check_valuation_exit 联动）/ 主力出货 / 情绪高潮减仓 / 前高目标 | 已有退出通道 + 知识库情绪周期 |
| **时间止损** | 持仓 N 日未达预期 → 减半/退出 | 多层次风控网络"时间止损" |
| **仓位** | 基础 = 共识率映射（保留）；叠加：风险等级压缩、情绪环境（climax 降档）、凯利修正 | 资产配置权益仓位图（六维度）、凯利公式 |

### 5.4 数据支撑补强

- 止损/止盈需**价格点位**：buy_sell_point 需补点位（当前标签仅类型）；支撑/压力位计算（MA/前高前低/筹码峰）
- target_price：估值合理区间上沿（由 valuation_deviation 反推）或前高/通道上沿

1. **矛盾消除**：蓝色（强确认）∩ 门禁不推荐 <10%（当前 33.3%）

4. **建议可执行**：抽样 20 只 operation_advice 均含止损/目标价/入场区间（无 None）
5. **下游兼容**：闸门1（daily_change）、闸门2（右侧确认）、退出通道、前端展示正常
6. **回归**：pytest 全通过；诊断 API 四类股票（银行/白酒/成长/亏损）抽样正确
7. **时间稳定**：连续 3 交易日共识分布波动 <±5%

## 九、风险与回滚

- **门禁后移风险**：深度高估但多源共振的股票可能建议"建仓"——通过"深度高估强制不推荐"尾部保留硬约束；回滚=恢复投票前截断（一行条件）
- **票源移除风险**：sentiment 移除后情绪影响仅靠 Step B 权重——需验证权重矩阵效果；回滚=恢复 VOTE_MAP 条目
- **新增票源风险**：规模/低波动可能引入风格偏向（小盘扎堆）——默认关闭，IC 验证后启用
- **止损价格数据**：价格点位计算依赖历史高低点/MA——数据不足时降级为"结构位"文字描述（不阻塞）
