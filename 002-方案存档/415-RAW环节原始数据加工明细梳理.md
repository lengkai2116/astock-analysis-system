# 415-RAW环节原始数据加工明细梳理

> **背景**：用户要求系统梳理 RAW 环节（原料加工）对原始数据的所有加工明细。
> **范围**：RAW 是确定性「数据计算」层（非策略推理），位于 `COL（采集存储）→ RAW（原料加工）→ SIG（现状分析）→ JUD（判定整合）→ OUT（输出）` 管道中 SIG 的上游。
> **方法**：直接核查 `data_daemon.py` 编排逻辑 + 各引擎/存储层实现。

---

## 一、RAW 环节架构总览

### 1.1 编排位置

`data_daemon.py` 日终同步后触发，RAW 三步并行（`ThreadPoolExecutor(max_workers=3)`），读同一源表、写不同目标表，无数据依赖：

```python
RAW_STEPS = {
    'RAW-1': _precompute_indicators,    # 技术指标预计算
    'RAW-2': _precompute_raw_features,  # 特征提取
    'RAW-3': _precompute_preset_combos, # 因子预计算
}
```

前置：`_precompute_market_stats()`（市场级统计，在 RAW 三步之前执行）。

### 1.2 三步职责与产出

| 步骤 | 函数 | 目标表 | 产出内容 |
|------|------|--------|---------|
| 前置 | `_precompute_market_stats` | `market_stats_cache` | 7 项全市场级统计 |
| RAW-1 | `_precompute_indicators` | `indicator_ma/macd/other` | MA/MACD/RSI/KDJ/BOLL/VOL/BBI/ENE/九转 |
| RAW-2 | `_precompute_raw_features` | `pre_feat_cache`(JSON) | 21 组特征 |
| RAW-3 | `_precompute_preset_combos` | `factor_cache` | 13 个量化因子 |

---

## 二、前置：市场级统计预计算（`_precompute_market_stats`）

在 RAW 三步之前执行，产出 7 项全市场指标，写入 `_market_stats_cache`（内存）+ `market_stats_cache` 表（SQLite 持久化，414号R8 已落地）。

| 指标 | 数据源 | 计算逻辑 |
|------|--------|---------|
| `ma20_ratio` | `daily_cache` | MA20 强势股占比（窗口20日均线） |
| `turnover_percentile` | `daily_basic_cache` | 换手率 60 日分位 |
| `limit_ratio` | `daily_cache`+`stk_limit_cache` | 涨跌停比 |
| `rsi_percentile` | `indicator_other` | RSI 中位数 60 日分位 |
| `erp_percentile` | `daily_basic_cache` | 股权风险溢价 252 日分位 |
| `margin_trend` | `margin_cache` | 融资余额 5 日趋势 |
| `pe_percentile` | `daily_basic_cache` | PE 252 日分位 |

## 三、RAW-1：技术指标预计算

**输入**：`daily_cache`（日线，阈值 `len(df) >= 60`，414号R6 已落地）
**引擎**：`TechnicalIndicatorEngine.calculate_all_indicators()`
**写入**：`cache_indicators_wide()` → 3 张宽表

| 目标表 | 字段 |
|--------|------|
| `indicator_ma` | `ma5/10/20/30/60/120/250`、`vol_ma5/10`（MA120/250 为 414号P1.2 已落地） |
| `indicator_macd` | `macd_dif/dea/hist` |
| `indicator_other` | `rsi14`（Wilder's EMA，414号P1.1 已落地）、`kdj_k/d/j`、`boll_upper/mid/lower`、`bbi`、`ene_upper/lower`、`nine_buy/sell`（BBI/ENE/九转为 414号R5 已落地） |

## 五、RAW-3：因子预计算（13 个）

**输入**：`daily_cache`（阈值 `len(df) >= 30`）
**写入**：`factor_cache`（`FactorPrecomputeManager.precompute_factor`）

通过 `FACTOR_NAME_MAP` 将中文因子名映射到 FactorRegistry 英文名，实际预计算 13 个因子：

| 中文名 | 英文因子 | 类别 |
|--------|---------|------|
| 20日动量 / 动量 | `QLIB_ROC_20` | 动量 |
| 5日动量 / 短期动量 | `QLIB_ROC_5` | 动量 |
| 14日RSI | `QLIB_RSI_14` | 动量 |
| 5日量比 / 量比 | `VOL_RATIO_5` | 量 |
| 20日换手率 | `VOL_RATIO_20` | 量 |
| 20日波动率 / 低波因子 | `VOLATILITY_20` | 波动率 |
| 20日均线乖离率 | `BIAS_20` | 乖离 |
| 5日反转因子 | `QLIB_REVERSAL_5` | 反转 |

> FactorRegistry 实际注册 287+ 个因子类（a_stock/qlib158/gtja191/alpha101/academic 等），但 RAW-3 仅预计算映射表中命中的 13 个。

## 六、辅助：分钟 K 线聚合（RAW 涉及部分）

`minute_backfill.py` / `minute_data_manager.py` 的 `_resample_minute` 按 A 股交易时段边界（570/690/780/900）聚合：

```
1min → 5min → 15min/30min/60min
```

（414号P1.3 已修正 60min 对齐，每交易日恰好 4 根）

## 七、消费链路汇总

```
RAW-1 → indicator_ma/macd/other → chart.py 图表、SIG dim 引擎（data_context）
RAW-2 → pre_feat_cache → StatusEngine._flatten_pre_feat() → tags → dim1-dim7
RAW-3 → factor_cache → SIG factor 引擎、dim4 筹码引擎
market_stats → dim5 BociasiQuadrant
```

---

## 八、关键约束（红线）

- RAW 是**唯一权威计算源**，散落独立计算（如 `condition_evaluator` 的 4 个计算器）应统一委托 `TechnicalIndicatorEngine`（414号P2.5 已落地）。
- API 路由**禁止实时计算**技术指标（红线 #3），应读 RAW 预计算产物（414号P2.1 已落地，含 chart.py 信号路径）。
- 分钟 K 线聚合（`minute_backfill`/`kline_resampler`）属于 RAW 涉及部分。
