## 1. 背景与定位

### 1.1 定位

账户管理板块在系统中的定位：

- **记账工具**：用户手动记录实盘交易的买入/卖出操作
- **交易行为分析入口**：基于用户的实际交易记录，结合实盘行情数据，对用户的操作进行复盘分析
- **与复盘中心的关系**：复盘中心（playback）负责"策略有效性诊断"（个股+日期维度的策略分析快照），账户管理负责"用户操作质量复盘"（用户层面的实盘操作复盘）。两者通过 **RV-xxx 策略实例ID** 关联——用户可在录入交易时关联到复盘中心的某张策略卡片，从而在复盘时判断"用户操作是否与策略方向一致"

### 1.2 核心原则

- 系统提供的是**建议而非指令**，复盘**不评估"是否跟从了系统"**，而是评估"用户的实际操作本身质量如何"
- 策略信号有效性的判定依据**复盘中心的诊断结论**（RV-xxx 的 `diagnostic_summary.overall_verdict`），而非策略历史胜率
- 所有分析输出遵循**叙事+情景推演+改进建议**的格式，不使用评分制
- 涉及的手续费/印花税由系统**自动核算**（需用户一次配置佣金率）

## 4. 第二层：持仓监控

### 4.1 持仓表格

| 字段 | 说明 | 计算方式 |
|:-----|:-----|:---------|
| 股票 | 名称+代码 | 自动从交易记录汇总 |
| 持仓数量 | 当前持有股数 | 买入总数 - 已卖出总数 |
| 持仓均价 | 加权平均成本 | 买入总金额(含手续费) / 买入总股数 |
| 现价 | 实时/最近收盘价 | 行情数据接口 |
| 浮动盈亏 | 未实现盈亏 | (现价 - 均价) × 持仓数量 |
| 盈亏百分比 | 浮动收益率 | (现价 / 均价 - 1) × 100% |
| 占比 | 占总资产比例 | (持仓数量 × 现价) / 总资产 |
| 持有天数 | 首次买入至今 | 当前日期 - 首次买入日期 |
| 操作 | 卖出/补仓 | 点击触发交易录入（自动带出股票） |

### 4.2 持仓指标

- **持仓集中度**：最大单只占比 / 最大行业占比（>10%/30% 标记提醒）
- **总仓位**：持仓总市值 / 总资产
- **持仓盈亏汇总**：合计浮动盈亏 + 今日浮动盈亏变动

### 4.3 交互

- 双击某只股票 → 跳转到 `indicator-ide.html?symbol=xxx`
- 点击「卖出」按钮 → 弹出卖出录入框（自动填充股票名称）
- 点击「补仓」按钮 → 弹出买入录入框（自动填充股票名称）

### 5.2 手续费自动核算

系统根据用户配置的费率参数自动计算（需用户在账户设置中一次配置）：

| 费用项 | 计算规则 | 能否自动算 |
|:-------|:---------|:----------|
| **印花税** | 卖出金额 × 0.05%（单向卖出征收） | ✅ 固定，自动算 |
| **券商佣金** | 成交金额 × 用户佣金率（买入+卖出均收） | ✅ 需配置佣金率（默认万2.5） |
| **过户费** | 成交金额 × 0.001%（沪深统一） | ✅ 固定，自动算 |

**用户配置入口**：账户设置中录入佣金率（万分之一至千分之一）。

**竞合逻辑**：自动计算后展示结果，用户可手动覆盖修改。如用户手动修改，系统标注"用户手动调整"。

### 5.3 关联复盘策略

用户在录入交易时，可选择关联复盘中心已有的策略实例（RV-xxx 卡片）：

```
关联到复盘中心正在跟进的策略：

┌──────────────────────────────────────────────────┐
│  ☐ RV-003  西藏矿业  06-01 → 持仓中              │
│     综合策略 · BULLISH 78% · 入场12.10-12.50     │
│                                                   │
│  ☐ RV-001  西藏矿业  05-20 → 已完结(+8.2%)      │
│     综合策略 · BULLISH 85% · 入场11.50-11.80     │
│                                                   │
│  [跳过关联]                                        │
└──────────────────────────────────────────────────┘
```

**关联路径**：
1. 用户录入交易选择股票后
2. 系统查询复盘池中该股票的所有卡片（通过 `review_pool_data_v2` 数据）
3. 按时间倒序展示可关联的卡片列表
4. 用户勾选后建立关联 (`trade.review_unit_id = "RV-xxx"`)

**友好提示**：
> 💡 提示：如果你的操作是基于个股策略分析页的某个策略建议，可先在个股策略分析页点击"加入复盘池"保存到复盘中心，再在此处关联。

### 5.4 部分卖出

支持对持仓进行部分卖出操作：

| 场景 | 展示 | 计算 |
|:-----|:-----|:-----|
| 全部卖出 | 买→卖配对完成，进入已完结 | 全部数量卖出，计算已实现盈亏 |
| 部分卖出 | 持仓数量减少，剩余继续持有 | 按先进先出(FIFO)计算已实现盈亏 |

**示例**：
- 曾买入西藏矿业 1000 股，均价 ¥11.38
- 卖出 300 股，价格 ¥12.34
- 已实现盈亏 = (12.34 - 11.38) × 300 = +¥288（另扣除手续费）
- 剩余持仓：700 股，均价不变 ¥11.38

### 5.5 交易记录列表

| 功能 | 说明 |
|:-----|:------|
| 默认展示 | 按交易日期倒序，展示最近3个月 |
| 分页 | 每页20条，支持翻页 |

| 搜索 | 按股票代码/名称模糊搜索 |

**列表展示字段**：日期 | 股票 | 方向(买入/卖出) | 数量 | 价格 | 金额 | 手续费 | 盈亏(卖出时) | 关联策略 | 理由 | 操作

## 6. 第四层：操作复盘——六维评估模型

### 6.1 模型总览

```
┌──────────────────────────────────────────────────────────────────┐
│              账户管理 · 操作级复盘 — 六维评估模型                 │

│                                                                    │
│  维度A 买卖点质量  │  维度B 策略执行与有效性  │  维度C 资金风控  │
│  · 入场位置相对性  │  · B1 策略诊断结论读取    │  · 单笔风险敞口  │
│  · 出场时机合理性  │  · B2 有效→一致性检查    │  · 持仓集中度    │
│  · 支撑阻力关联    │  · B3 无效→独立判断      │  · 补仓性质识别  │
│  · 追涨杀跌判定    │    有效性评估             │  · 回撤操作归因  │
├──────────────────────────────────────────────────────────────────┤
│                                                                    │
│  维度D 交易时机节奏  │  维度E 行为模式识别     │  维度F 综合归因  │
│  · 持有周期评估     │  · 过早止盈/过晚止损    │  · 盈利/亏损归因  │
│  · 操作频率分析     │  · 追涨杀跌             │  · TOP改进项      │
│  · 分批操作质量     │  · 频繁交易             │  · 情景推演       │
│  · 市场节奏匹配     │  · 报复性交易           │  · 下期重点       │
│                     │  · 过度自信/禀赋效应    │                   │
└──────────────────────────────────────────────────────────────────┘
```

### 6.2 维度A：买卖点质量评估

| 评估项 | 判断逻辑 | 数据来源 |
|:-------|:---------|:---------|
| 入场位置 | 买入价在当日K线区间中的百分位位置 | K线(开盘/收盘/最高/最低) |
| 出场时机 | 卖出价与卖出后5日走势的比较 | K线 |
| 支撑阻力关联 | 买入价与MA20/MA60/前低前高的位置关系 | 技术指标 |
| 错误模式(追涨) | 买入价位于当日K线前20%分位 或 当日涨幅>5%后买入 | 两者取或 |
| 错误模式(杀跌) | 卖出价位于当日K线后20%分位 或 当日跌幅>5%后卖出 | 两者取或 |

**输出格式示例**：
> **维度A · 买卖点质量** — 西藏矿业 1000股
>
> ▸ **买入(6月1日)**：买入价¥12.34位于当日K线区间(¥12.10~¥12.60)的34%分位——非追高 ✅。当日价格在MA20(¥11.80)上方，均线多头排列支撑良好 ✅
>
> ▸ **卖出(6月15日)**：卖出价¥13.38后5日继续上涨至¥14.20(+6.1%)。**→ 过早止盈嫌疑**，若采用移动止盈(回调5%卖出)可多赚¥820

### 6.3 维度B：策略执行与有效性评估

**前置条件**：仅当用户在录入交易时关联了复盘策略(RV-xxx)时开展。

```
B0 前置判断：关联的 RV-xxx 是否已生成复盘报告？
   │
   ├─ 未生成 → 输出提示"请先在复盘中心生成策略复盘报告"
   │
   └─ 已生成 → 读取 review_analysis.diagnostic_summary.overall_verdict
        │
        ├─ "亏损"（策略方向未验证通过）
        │    → B3: 策略方向偏移，用户偏离不视为负面
        │       正向：独立判断有效 ✅
        │       跟随亏损：关联策略方向有误，执行无责
        │
        └─ "盈利"（策略方向验证通过）
             → B2: 检查用户操作与策略一致性
                入场价是否在 practical_ref.entry_zone 内？
                止损是否未跌破 practical_ref.risk_line？
                方向是否匹配 arbitration.direction？
```

**输出格式示例**：

> **维度B · 策略执行与有效性**
>
> ▸ 关联策略：**RV-003**（西藏矿业，6月1日入池）
> ▸ 策略诊断：✅ 方向判断准确，综合得分78/100，入场位置合理
>
> ▸ 执行一致性检查：
>   - 买入方向(BULLISH)匹配 ✅
>   - 入场价¥12.34在建议区间¥12.10~¥12.50内 ✅
>   - 持有期间未触发止损线¥11.80 ✅
>
> ▸ **结论**：用户操作与有效策略方向一致，执行质量良好

### 6.4 维度C：资金与风险管理

| 评估项 | 判断逻辑 |
|:-------|:---------|
| 单笔风险敞口 | 单笔买入金额 / 总资产（建议≤总资产10%，参考203号方案§4.4） |
| 持仓集中度 | 单行业占比 / 单只占比（建议单行业≤30%，单只≤10%） |
| 补仓性质识别 | 首次买入→价格下跌X%→加仓：价格梯度>5%+加仓量≤首次50% → **合理低吸**；加仓量>首次 → **激进补仓**；首次亏损后3日内加仓 → **报复性补仓** |
| 回撤操作归因 | 最大回撤发生前后3日的交易行为分析 |
| 仓位健康度 | 总仓位 vs 市场环境（根据BOCIASI情绪周期判定：高波动期应降仓） |

**补仓判断输出示例**：
> **维度C · 资金与风险管理**
>
> ▸ **补仓分析**：西藏矿业 首笔买入¥12.34 → 股价下跌8%至¥11.35时补仓300股，补仓量为首笔的30%。**→ 合理低吸 ✅**，在下跌中补仓且控制了加仓规模，降低了持仓均价至¥11.38
>
> ▸ **风险提示**：有色金属板块占比51%（建议≤30%），集中度偏高 ⚠

### 6.5 维度D：交易时机与节奏把控

**参考来源**：181号方案BOCIASI情绪周期体系 + 203号方案超时机制

| 评估项 | 判断逻辑 |
|:-------|:---------|
| 持有周期评估 | 实际持有天数与盈亏率的交叉分析（短期<5天的胜率 vs 中期30天的胜率） |
| 操作频率分析 | 月度交易次数 vs 胜率的关系（推荐间隔≥3天，频繁操作降胜率时可识别） |
| 分批操作质量 | 分批买入的价格梯度是否呈"金字塔"形（低价多买、高价少买） |
| 节奏匹配(进阶) | 操作频率 vs BOCIASI市场波动率指标（高波动期是否降频） |

**输出格式示例**：
> **维度D · 交易时机与节奏把控**
>
> ▸ **持有周期**：本月4笔交易，平均持有28天。其中短期持有(<5天)的1笔胜率0%，中长期持有(10~30天)的3笔胜率100%。**→ 中长期持有策略在本月更有效**
>
> ▸ **操作频率**：月均0.7次，节奏合理，未出现频繁买卖

### 6.6 维度E：行为模式识别

**参考来源**：125号方案心态纪律复盘 + review_engine.py + 行为金融学 + 知识库补充

| 行为模式 | 检测规则 | 来源 |
|:---------|:---------|:-----|
| 过早止盈(处置效应) | 盈利≤5%即卖出，且卖出后10日内有更高价(cf=新高) | 行为金融学 |
| 过晚止损 | 亏损≥8%仍未卖出 | 参考系统默认止损8% |
| 追涨 | 买入价位于当日K线前20%分位 或 当日涨幅>5%后买入(取或) | 账户管理自定义阈值 |
| 杀跌 | 卖出价位于当日K线后20%分位 或 当日跌幅>5%后卖出(取或) | 账户管理自定义阈值 |
| 频繁交易 | 同一股票买卖间隔<3个交易日 | 行业惯例 |
| 报复性交易 | 单笔亏损>5%后，3个交易日内买入金额超平时单笔金额的2倍 | review_engine.py |
| 过度自信 | 连续3笔盈利后，第4笔仓位突然超过前3笔均值的1.5倍 | 行为金融学 |
| 禀赋效应 | 同一股票上，持仓亏损时间 > 持仓盈利时间（倾向持亏抛盈） | 行为金融学 |

**行为模式识别说明**：
- 各行为模式均为**提示性**而非定罪性，输出使用"嫌疑"、"倾向"等措辞
- 每个模式的判定阈值初始固定，后续可在条件库中配置为可调参数
- 单个交易周期内，同一模式触发多次时只汇报最严重一次

**输出格式示例**：
> **维度E · 行为模式识别**
>
> ▸ **过早止盈嫌疑**：西藏矿业(6月15日)盈利+8.4%即全部卖出，卖出后5日继续上涨至¥14.20。**→ 建议尝试移动止盈**
>
> ▸ **禀赋效应提示**：宁德时代持有亏损状态累计22天，盈利状态下累计仅5天。**→ 倾向持有亏损股等待回本，注意止损纪律**
>
> ▸ ✅ 未发现追涨杀跌、频繁交易、报复性交易等异常行为

### 6.7 维度F：综合归因与改进建议

| 评估项 | 内容 |
|:-------|:-----|
| 归因分析 | 按个股维度汇总盈利/亏损来源（盈利贡献TOP3 / 亏损来源TOP3） |
| TOP改进项 | 基于A-E维度识别的最需要改进的2-3项，按优先级排序 |
| 情景推演 | "如果当时...会怎样"的假设推演（仅在有明确数据支持时给出） |
| 下期重点 | 基于当前问题的下阶段关注方向 |

**输出格式示例**：
> **维度F · 综合归因与改进建议**
>
> ▸ **归因分析**：
>   - 盈利来源：西藏矿业(+48%)、平安银行(+22%)、其他(+30%)
>   - 亏损来源：海康威视(-12%)、五粮液(-6%)——均为止损执行不及时
>
> ▸ **TOP改进项**：
>   1. **止盈策略优化**：西藏矿业过早卖出，建议用移动止盈替代固定目标价止盈
>   2. **止损纪律**：海康威视和五粮液亏损持续天数过长，建议严格执行预设止损位
>   3. **行业分散**：有色金属板块占比51%，建议关注其他板块机会
>
> ▸ **情景推演**：西藏矿业若采用移动止盈(从最高价回撤5%)，可在¥13.55卖出多赚¥210(可避免过早卖出问题)
>
> ▸ **下期重点**：
>   - 关注新能源板块的持续性机会
>   - 宁德时代持仓已22天超平均持有期，需确认止损位
>   - 控制有色板块持仓占比至30%以内

## 7. 第五层：周期回顾

### 7.1 时间跨度

| 周期 | 默认 | 说明 |
|:-----|:-----|:------|
| 按周 | 本周一~当前 | 快速查看本周交易情况 |
| 按月 | 本月1日~当前 | 月度交易报告 |
| 按季度 | 本季度初~当前 | 季度复盘 |
| 自定义 | 用户选择起止日期 | 任意时间跨度的回顾 |

### 7.2 周期回顾内容

每一份周期回顾包含以下组成部分：

1. **关键数字**：交易笔数、胜率、总盈亏、收益率、最大回撤
2. **收益归因**：按个股/操作类型的盈利/亏损分布
3. **行为模式趋势**：各行为模式在本周期内的触发次数汇总
4. **TOP改进项**：基于本周期全部操作的综合建议
5. **下期重点关注**：基于BOCIASI情绪周期和持仓状况的建议

### 7.3 与复盘中心报告的关系

| 对比维度 | 周期回顾(账户管理) | 深度报告(复盘中心) |
|:---------|:------------------|:------------------|
| 范围 | 用户全部交易 | 单只股票单次策略 |
| 核心问题 | 我的操作质量如何？ | 这个策略有效吗？ |
| 输出格式 | 叙事报告 | 诊断分析 |
| 使用场景 | 固定周期总结 | 单次策略完结时 |

## 9. 配置与数据流

### 9.1 用户配置项

| 配置项 | 默认值 | 说明 |
|:-------|:-------|:-----|
| 券商佣金率 | 万2.5 (0.00025) | 计算交易手续费 |
| 印花税率 | 0.05% (固定) | 只卖出时征收 |
| 行为模式阈值(追涨) | 前20%分位或>5% | 涨幅阈值 |
| 行为模式阈值(过早止盈) | ≤5% | 低于此比例卖出标记过早止盈嫌疑 |
| 过晚止损阈值 | ≥8% | 亏损超过此比例仍未卖出标记嫌疑 |

### 9.2 数据流关系

```
用户手动录入交易
    │
    ├── 关联复盘策略（可选）
    │      │
    │      └── 复盘中心 RV-xxx（通过 localStorage review_pool_entries 读取）
    │
    ├── 系统自动核算手续费（印花税+佣金+过户费）
    │
    ├── 自动计算持仓汇总
    │
    ├── 触发复盘（手动或周期） →
    │    ├── 维度A：调用K线数据评估买卖点位置
    │    ├── 维度B：读取关联RV-xxx的复盘报告诊断结论
    │    ├── 维度C：基于持仓+交易计算风控指标
    │    ├── 维度D：基于交易序列分析节奏
    │    ├── 维度E：基于交易序列检测行为模式
    │    └── 维度F：聚合A-E生成归因+建议
    │
    └── 生成叙事报告（去评分化+情景推演）
```
