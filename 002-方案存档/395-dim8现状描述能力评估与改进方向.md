# 395 — dim8现状描述系统配置规范

> **背景**：394号方案已将dim8重构为"质量守门员+现状描述生成器"，Phase 2-5已完成。但当前dim8仅做plain文本平铺拼接，存在三个核心差距：(1) 各维度未通过字段组合将现状讲清楚——不是输出一个结果标签，而是要说明**因为什么触发了什么规则所以得出什么判断**；(2) dim2/dim3/dim5的plain中泄漏英文术语；(3) 维度排序未遵循"风险前置"原则。本方案基于dim2-dim7代码实审（status_description共188个字段全部核查），制定dim8的三层描述体系和系统配置规范。

---

## 一、总体架构

### 1.1 核心原则

dim8的描述标准：**不是单纯输出结果，而是因果链描述**。

每个维度的描述必须包含三层：

| 层次 | 内容 | 作用 |
|------|------|------|
| **因为** | 触发了什么具体规则/条件/阈值（引用实际数据+规则名） | 让用户知道结论怎么来的 |
| **所以** | 得出什么判断/结论（对应judgment标签） | 核心结论 |
| **验证** | 其他维度/指标是否一致支撑（有则写，矛盾则标注） | 交叉验证，增强可信度 |

### 1.2 输出结构

```python
{
    "dim_key": str,           # 维度标识
    "title": str,             # 维度中文名
    "light": str,             # 红绿灯
    "text": str,              # 完整描述（因为→所以→验证三层）
    "judgment": str,          # 一句话判断标签
    "evidence": list,         # 证据链（供稽核）
    "metrics": dict,          # 关键数值（供前端展示）
}
```

text字段组合规则：`{因为段}，所以{所以段}。{验证段}`

### 1.3 前端渲染结构

```
每维显示：{light灯色} + {title维度名}：{text主内容}
         {judgment标签}
         条件稽核 {passed}/{total} (置信XX%)
```

### 1.4 维度排序（风险前置，326号定稿）

```python
SIX_DIM_PRIORITY = ['risk', 'valuation', 'emotion', 'structure', 'volume_price', 'chip_fund']
```

### 1.5 各维度职责边界（去重后）

| 维度 | 唯一负责描述 | 不再重复描述 |
|------|------------|------------|
| dim1 | 信号类型、共振数、生命周期天数、衰减状态 | — |
| dim2 | 中枢位置/偏离度、均线具体价位、RSI/KDJ/MACD、缠论方向/买卖点 | 支撑阻力价位（→dim6） |
| dim3 | 量价形态、状态机方向、背离、三定律、多时间框架、入场/目标区间 | 量比数值（→dim4）、均线排列（→dim2） |
| dim4 | 主力阶段、资金流向、筹码集中度、获利比、拥挤度、筹码信号 | 量能形态（→dim3） |
| dim5 | 市场阶段、四象限、温度、板块热度、个股情绪 | — |
| dim6 | 风险等级、防守位/压力位价位、盈亏比、波动率、止损条件、事件 | — |
| dim7 | 估值等级、PE/PB分位、FCF收益率、股息率、四锚评分、财务健康、潜力 | — |

### 2.1 dim6 风险边界

| `dist_to_support_pct` | 因为 | 距防守位百分比 | 必须 |
| `resistance_price` | 因为 | 压力位价格 | 必须 |
| `dist_to_resistance_pct` | 因为 | 距压力位百分比 | 必须 |
| `rr_value` | 因为+所以 | 盈亏比数值→等级判定 | 必须 |
| `rr_level` | 所以 | 盈亏比判断 | 必须 |
| `volatility_percentile` | 因为 | 波动率历史分位 | 必须 |

| `invalidation` | 所以 | 止损条件 | 必须 |

#### 整合规则

**因为段**：风险源判定 + 几何距离 + 盈亏比计算 + 波动率定位

```
规则1（风险源）：遍历risk_factors中satisfied=True的项，列出触发的风险源名称和级别
规则2（几何距离）：support_price取MA20/MA60/60日最低中合理支撑
                  dist_to_support_pct = (support_price/close - 1) × 100%
规则3（盈亏比）：以dim6代码中calc_geometric()实际计算为准，
                 dim8直接读取rr_value字段，不做二次计算。
                 等级映射以_calc_rr_level()为准（含边界值处理）。
规则4（波动率）：volatility_percentile基于ATR历史分位
                 <25%低波动 / 25-75%中等 / >75%高波动
```

**所以段**：风险等级结论 + 盈亏比判断 + 止损条件

```
风险等级：以dim6代码中_assess_risk_level()的加权评分为准（非简单计数），
  综合考虑severity="极高"/"高"/"中"的权重差异和数量。
  dim8直接读取risk_level字段（已由dim6计算完成），不做二次映射。
盈亏比等级：以dim6代码中_calc_rr_level()的边界处理为准。
止损条件：invalidation列表取第一条
```

**验证段**：事件验证 + 突破天数验证 + 矛盾标注

```
若event_summary非空：补充"近期事件：{event_summary[0]}"
若signal_days > 0：补充"突破已持续{signal_days}天"
若rr_value < 1 且 risk_level = "低"：标注"风险低但盈亏比不支持入场"
```

#### text模板

```
判定为{risk_level}——{因为段}。所以{所以段}。{验证段}
```

#### 完整示例

> 判定为中等风险——6项风险源均未触发高风险（财务正常、无事件风险、无商誉减值、无质押风险、无ST风险、无退市风险），防守位11.39元取自MA20支撑（距现价-2.3%），压力位11.75元取自60日最高（距现价+0.9%）；因为向上空间仅0.9%而下行风险达2.3%，盈亏比=0.39（<1R不值得交易标准），波动率处于历史45%分位（ATR=0.18）。所以判定为中等风险，盈亏比不划算。止损条件：收盘跌破11.39元。近期事件：突破站上60日线（已持续3天）。

### 2.2 dim7 估值

#### 字段消费锁定

| 字段路径 | 消费层 | 用途 | 必须/可选 |
|---------|-------|------|----------|
| `valuation_level_cn` | 所以 | 估值判断（中文） | 必须 |
| `composite_rating` | 因为+所以 | 综合评分→偏离度 | 必须 |
| `valuation_deviation` | 因为 | 偏离程度 | 可选 |
| `pe_percentile_5y` | 因为 | PE历史分位 | 必须 |
| `pb_percentile_5y` | 因为 | PB历史分位 | 可选 |
| `fcf_yield` | 因为 | FCF收益率 | 必须 |
| `dividend_yield` | 因为 | 股息率 | 必须 |
| `asset_anchor_rating` | 因为 | 资产锚评分 | 必须 |
| `earnings_anchor_rating` | 因为 | 盈利锚评分 | 必须 |
| `cashflow_anchor_rating` | 因为 | 现金流锚评分 | 必须 |
| `fina_health` | 验证 | 财务健康度 | 必须 |
| `roce_pass` | 验证 | ROCE达标情况 | 可选 |
| `potential_score` | 验证 | 潜力评分 | 必须 |

#### 整合规则

**因为段**：四锚评分 + 关键指标 + 历史分位

```
规则1（资产锚）：asset_anchor_rating基于PB 5年分位→-2~+2
  PB分位>80%→资产锚=-1或-2 / 20-80%→0 / <20%→+1或+2
规则2（盈利锚）：earnings_anchor_rating基于PE+PEG+股息率综合
规则3（现金流锚）：cashflow_anchor_rating = fcf_yield vs CN_10Y_BOND_YIELD_PCT
  CN_10Y_BOND_YIELD_PCT为dim7代码中的常量（10年期国债利率）。
  FCF收益率>国债利率→现金流锚偏正（低估）
  FCF收益率<国债利率→现金流锚偏负（高估）
规则4（历史分位）："近5年仅有{100-pe_percentile_5y}%的时间PE比现在更高"
```

**所以段**：composite评级 + 四锚结论

```
composite = 四锚加权综合分（以dim7代码中实际计算为准）
valuation_level判定（以dim7代码中valuation_level阈值逻辑为准）：
  dim8直接读取valuation_level_cn字段（已由dim7计算完成），不做二次映射。
```

**验证段**：财务健康 + 潜力评分 + 矛盾标注

```
若fina_health = "fail"：补充"财务异常（ROCE={roce}%，未达15%达标线）"
若potential_score ≥ 80：补充"潜力{score}/100"
若composite偏高但cashflow_anchor偏正：标注"贵在价格，但现金流回报尚可"
```

#### text模板

```
判定为{valuation_level_cn}——{因为段}。所以{所以段}。{验证段}
```

#### 完整示例

> 判定为偏高——PE处于近5年95.4%历史分位（近5年仅有4.6%的时间PE比现在更高，当前PE=68.3 vs 5年中位数=32.1），资产锚评分-1.0（PB分位84.2%，高于历史中位数）；但盈利锚评分0.0（PE+PEG+股息率综合合理）、现金流锚评分-1.0（FCF收益率9.20%>国债利率2.8%，现金流角度仍被低估）。所以四锚加权composite=-1.0，综合判定偏高——贵在价格，但现金流回报尚可。财务异常（ROCE=8.2%，未达15%达标线），潜力92/100。

#### 整合规则

**因为段**：市场阶段 + BOCIASI快慢线 + 温度计算 + 板块排名

```
规则1（市场阶段）：六段论映射
  冰点→极度低迷 / 萌芽→开始回暖 / 发酵→氛围偏暖
  高潮→情绪过热 / 退潮→情绪降温 / 回归→情绪恢复

规则2（BOCIASI快线）：阈值以BociasiQuadrantAnalyzer中FAST_HIGH_THRESHOLD为准（当前=0.6）
  快线计算：MA20强势股占比 + 换手率分位 + 涨跌停比 + RSI中位数

规则3（BOCIASI慢线）：阈值以BociasiQuadrantAnalyzer中SLOW_HIGH_THRESHOLD为准（当前=0.5）
  慢线计算：ERP分位 + 融资余额趋势 + 股债收益差 + 市场估值分位

规则4（温度）：7维度加权 + BOCIASI修正
  ≥80极度亢奋 / ≥60乐观 / ≥40中性 / ≥20悲观 / <20极度恐慌

规则5（板块热度）：行业排名前10→"前10" / 前20→"前20"
```

**所以段**：四象限结论 + 温度结论 + 板块结论 + 个股结论

```
四象限映射：
  LL→"情绪底部，高性价比区间" / LH→"高位低性价比，风险积累"
  HL→"低位高性价比，买入价值高" / HH→"情绪高位，过热风险"
  MM→"中性区间，观望为主"
```

**验证段**：快慢线一致性 + 板块+个股验证

```
若快线看多且慢线看多：标注"快慢线一致，情绪底部确认"
若快线看多但慢线看空：标注"短线偏暖但长线性价比不足"
若板块前10且个股积极：标注"板块+个股双重共振"
若板块一般但个股积极：标注"个股情绪优于板块整体"
```

#### text模板

```
市场处于{market_phase}（{market_detail}），四象限{quadrant_cn}——{因为段}。所以{所以段}。{验证段}
```

#### 完整示例

> 市场处于"发酵"阶段（板块轮动活跃），四象限LL——因为全市场MA20强势股占比=58%（>50%多空分界线）+涨跌停比=3.2:1（赚钱效应扩散）+RSI中位数=58（偏暖但未过热），所以BOCIASI快线=0.65（>0.6高位阈值→"看多"）；同时股权风险溢价处于历史低位（ERP分位=35%）+融资余额5日增加8%（杠杆资金入场），所以BOCIASI慢线=0.60（>0.5→"看多"）。快线高位+慢线高位→四象限落入LL。情绪温度62/100——7维度加权=61.2，经BOCIASI修正+0.8→62。所以市场情绪偏暖，处于情绪底部高性价比区间。板块银行排名第3（前10），个股情绪积极（量价配合良好）。快慢线一致，板块+个股双重共振。

#### 整合规则

**因为段**：中枢位置 + 均线排列 + 技术指标 + 缠论状态

```
规则1（中枢）：收盘价vs中枢上下沿
  close>上沿→"上方（偏离{distance_pct}%）"
  下沿<close<上沿→"内部"
  close<下沿→"下方"
规则2（均线）：MA5>MA10>MA20>MA60→"多头排列"
  翻译：bullish→多头排列 / bearish→空头排列 / mixed→交叉排列
规则3（技术指标）：RSI>70超买 / <30超卖 / 30-70中性
  KDJ: K>D金叉 / K<D死叉
  MACD: DIF>DEA多头 / DIF<DEA空头
规则4（缠论）：方向=up→向上 / down→向下
  强度=评分×70%+一致性×15%+幅度×15%
```

**所以段**：结构位置结论

```
position="上方" + 均线多头 → "结构偏强，价格在成本区之上"
position="上方" + 均线空头 → "结构矛盾，价格虽在上方但均线走弱"
position="内部" → "结构中性，价格在箱体内震荡"
position="下方" + 均线空头 → "结构偏弱，价格在成本区之下"
```

**验证段**：买卖点 + 趋势结构 + 多周期验证

```
若buy_sell_points非空：补充"出现{points[0]}"
若trend_structure_signal ≠ "none"：翻译后补充
若level_cross_score > 0.7：标注"多周期一致性高（{score}），信号可信"
若level_cross_score < 0.4：标注"多周期分歧（{score}），信号待确认"
```

```python
def _translate_fields(dim_key: str, sd: dict) -> dict:
    """对status_description中的英文字段做统一翻译"""
    trans_map = DIM_TRANSLATION_MAP.get(dim_key, {})
    result = dict(sd)
    for field_key, cn_dict in trans_map.items():
        val = result.get(field_key)
        if val and val in cn_dict:
            result[field_key] = cn_dict[val]
    return result
```

```python
            builder = DIM_TEXT_BUILDERS.get(dim_key)

                'metrics': _extract_key_metrics(dim_key, sd_translated),
            }
```

### 7.4 各维度文本构建器（示例：dim6）

```python
def _build_risk_text(sd: dict) -> str:
    """dim6三层描述生成"""
    # 因为段
    parts_yw = []
    risk_factors = sd.get('risk_factors', [])
    if risk_factors:
        factors_cn = [f.split('：')[1].split('（')[0] for f in risk_factors[:3]]
        parts_yw.append(f"{'、'.join(factors_cn)}等风险源")
    else:
        parts_yw.append("6项风险源均未触发高风险")

    support = sd.get('support_price')
    dist_sup = sd.get('dist_to_support_pct')
    resistance = sd.get('resistance_price')
    dist_res = sd.get('dist_to_resistance_pct')
    if support and dist_sup is not None:
        parts_yw.append(f"防守位{support}元（距现价{dist_sup:+.1f}%）")
    if resistance and dist_res is not None:
        parts_yw.append(f"压力位{resistance}元（距现价{dist_res:+.1f}%）")

    rr = sd.get('rr_value')
    rr_level = sd.get('rr_level', '')
    if rr is not None:
        parts_yw.append(f"盈亏比{rr}（{rr_level}）")

    vol_pct = sd.get('volatility_percentile')
    if vol_pct is not None:
        vol_cn = VOLATILITY_CN.get(sd.get('volatility_level', ''), '')
        parts_yw.append(f"{vol_cn}（波动率{vol_pct:.0%}分位）")

    yw_text = '，'.join(parts_yw)

    # 所以段
    risk_level = sd.get('risk_level', '')
    invalidation = sd.get('invalidation', [])
    stop = invalidation[0] if invalidation else ''
    syw_text = f"{risk_level}风险"
    if rr is not None and rr < 1:
        syw_text += "，盈亏比不划算"
    if stop:
        syw_text += f"。止损条件：{stop}"

    # 验证段
    parts_yz = []
    events = sd.get('event_summary', [])
    if events:
        parts_yz.append(f"近期事件：{events[0]}")
    signal_days = sd.get('signal_days')
    if signal_days and signal_days > 0:
        parts_yz.append(f"突破已持续{signal_days}天")
    yz_text = '。'.join(parts_yz)

    text = f"{yw_text}。所以{syw_text}"
    if yz_text:
        text += f"。{yz_text}"
    return text
```

## 九、分阶段实施计划

### 实施原则

1. **每阶段可独立交付验证**——完成一个阶段即可运行测试确认功能正确
2. **渐进式替换**——新功能以增量方式加入，不破坏现有输出，旧输出作为fallback保留
3. **为后续管路预留接口**——翻译字典、文本构建器均采用配置化设计，后续新增维度或修改规则只需改配置
4. **精简代码**——每个阶段只写必须的代码，不做超前抽象

### 当前代码结构（394号实施后）

```
dim8_summary_engine.py (313行)
├── 辅助函数：_extract_dim_*() × 5个
├── 质量检查：_check_dim_quality() + _calc_quality_score()
├── 红绿灯：_build_eight_dim_summary()
├── 重算：_trigger_recalc() + _update_dim_results()
├── 现状描述（基础版）：_collect_dim_plain() + _unify_dim_plain() + _build_seven_dim_report()
└── Dim8SummaryEngine.evaluate() → 组装输出
```

### 阶段划分

```
Phase 1: 翻译基础设施          ──→  验证：翻译字典可正确映射
```
