# 市场地图修订详细方案

## 一、背景与目标

### 1.1 问题背景

现有市场地图（`_ui-prototype/opportunity-treemap.html`，309号 F1 四级展示）存在以下问题：

1. **视觉拥挤**：5000 只股票 + 110 行业组全铺一张画布，平均方块边长仅 16px，行业与个股无法通过视觉有效识别
2. **标签重叠**：所有方块恒显文字，小方块标签互相覆盖
3. **交互缺失**：无行业下钻、无右侧明细列表、无行业选择器
4. **数据缺口**：快照表缺 pe/pb（已修）、amount/turnover_rate（未修），成交额视图无法生效

### 1.2 目标

通过原型 v2（`opportunity-treemap-optimized-preview.html`）验证的 6 项优化，重构市场地图展示层：

- TOP N 截断 + 标签阈值隐藏 → 解决拥挤
- 点击行业下钻 + 右侧股票列表 → 解决识别
- 行业选择器（模糊搜索+下拉）→ 便捷导航
- 市值/成交额双面积模式 → 多视角
- 单行业视图居中 + 列表滚轮独立 + 行浮窗 → 交互完善

### 1.3 原型验证结论（已确认）

| # | 特性 | 原型验证结果 |
|:-:|------|:-----------:|
| 1 | TOP N 截断（300/500/1000/全部） | ✅ 接受 |
| 2 | 市值/成交额面积双模式 | ✅ 接受（成交额需后端补数据） |
| 3 | 行业不压缩（保持 110 行业） | ✅ 接受 |
| 4 | 点击行业 → 单行业 treemap + 右侧列表 | ✅ 验证通过 |
| 5 | 行业选择器（模糊搜索+下拉） | ✅ 验证通过 |
| 6 | 标签隐藏默认开启、长尾聚合取消 | ✅ 接受 |
| 7 | 单行业视图居中（roam 重置） | ✅ 验证通过 |
| 8 | 右侧列表滚轮独立 + 行浮窗 | ✅ 验证通过 |

## 二、前端改造（_ui-prototype/opportunity-treemap.html）

### 2.1 页面结构改造

```
现状：单一 chart 容器 + modeToggle(市场/机会/价值)
目标：chart 容器 + 右侧 side-panel + 控制栏(面积/TOP N/行业选择器)
```

**新增 HTML 结构**：

```html
<!-- 控制栏（替换原 modeToggle 区块） -->
<div class="controls">
  <div class="group">面积: [市值] [成交额]</div>
  <div class="group">个股数量: <select id="topN">300/500/1000/全部</select></div>
  <div class="group">行业选择: <input id="indSearch"> + 下拉</div>
  <div class="group">[✕ 退出行业视图]</div>
</div>

<!-- 主布局：左 treemap + 右列表 -->
<div class="main">
  <div class="chart-wrap"> <div id="chart"></div> </div>
  <div class="side-panel" id="sidePanel">
    <div class="sp-head">行业名 + ✕</div>
    <div class="side-list" id="sideList"></div>
    <div class="row-tip" id="rowTip"></div>   <!-- 行浮窗 -->
  </div>
</div>
```

### 2.2 控制栏逻辑

| 控件 | 行为 | 实现要点 |
|------|------|---------|
| 面积模式 | 市值/成交额切换 | `sizeMode` 全局变量；`setSize()` 重渲染 |
| TOP N | 300/500/1000/全部 | `topN` 读取；`buildTree()` 中 slice |
| 行业选择器 | 模糊搜索 + 下拉 | `filterInd()` 输入过滤；`selectIndustry()` 进入单行业 |
| 退出行业视图 | 返回全市场 | `clearIndustry()` |

**modeToggle 保留**：市场/机会/价值三模式仍需（mode 决定面积编码与着色）。

### 2.3 单行业下钻交互

```
点击行业块（chart.on('click')，params.data.children 存在）→ selectIndustry(name)
  ├─ treemap 重渲染为仅该行业（左侧容器）
  ├─ 右侧 side-panel 显示该行业股票列表
  └─ 布局稳定后 chart.resize() + 重渲染（重置 roam 视图居中）
```

**关键实现**：

```js
// ECharts nodeClick 只接受字符串，需用事件
chart.on('click', function(params) {
  const d = params.data;
  if (d && d.children && !currentInd && d.name !== 'A股全市场') {
    selectIndustry(d.name);
  }
});

function selectIndustry(name) {
  currentInd = name;
  render();
  requestAnimationFrame(() => {
    chart.resize();
    render();   // zoom:1/translate:[0,0] 重置 roam，强制居中
  });
}
```

### 2.4 右侧股票列表

| 列 | 内容 | 说明 |
|----|------|------|
| 名称 | 股票名 | 超长省略 |
| 涨跌 | +x.xx% | 红涨绿跌（A股惯例） |
| 市值 | xx亿 | 或成交额（随面积模式） |

**交互**：
- 行悬浮 → `.row-tip` 自定义浮窗（跟随鼠标，内容与地图浮窗一致：涨跌/市值或成交额/信号强度）
- 点击行 → 详情弹窗（PE/PB/涨跌/信号）
- 滚轮 → 列表原生滚动（`wheel` 事件 `stopPropagation` 阻止冒泡到图表）

### 2.5 展示配置（ECharts treemap）

```js
series: [{
  type: 'treemap',
  roam: true,
  nodeClick: false,                 // 下钻由 chart.on('click') 处理
  breadcrumb: { show: !currentInd },
  label: {
    formatter: 行业组→名称；个股→面积 < 900px² 隐藏文字（LABEL_MIN_AREA）
  },
  zoom: 1, translate: [0, 0],       // 每次 setOption 重置 roam 视图（防偏移）
  levels: [边框0层, 行业组层(粗边框+upperLabel), 个股层(细边框)]
}]
```

**标签阈值隐藏**：`LABEL_MIN_AREA = 900`（px²，≈30px 边长），小于阈值只显色块不显字，hover 浮现——核心降噪手段。

### 2.6 布局 CSS 要点

```css
.main { flex: 1; display: flex; min-height: 0; }
.chart-wrap { flex: 1; min-width: 0; min-height: 0; overflow: hidden; }
.side-panel { width: 300px; position: relative; z-index: 10; }  /* 防 canvas 覆盖 */
.side-list { flex: 1; overflow-y: auto; min-height: 0; }        /* 列表滚动 */
.row-tip { position: fixed; z-index: 1000; pointer-events: none; } /* 行浮窗 */
```

## 三、后端数据接口改造（opportunity_atlas + ECM）

### 3.1 数据缺口清单

| 字段 | 现状 | 数据源 | 所需动作 |
|------|------|--------|---------|
| `pe` / `pb` | ✅ 已补（014 修复） | daily_basic_cache | 无 |
| `amount`（成交额） | ❌ 快照表无列 | daily_cache.amount（千元） | 快照建表加列 + 提取 + 透出 |
| `turnover_rate`（换手率） | ❌ 快照表无列 | daily_basic_cache | 快照建表加列 + 提取 + 透出 |
| `circ_mv`（流通市值） | ❌ 快照表无列 | daily_basic_cache | 可选：列表/浮窗展示 |

### 3.2 快照表 schema 变更（treemap_snapshot）

在 `_build_treemap_snapshot`（data_daemon.py）中：

```sql
-- 建表新增列（现有 ts_code...exit_conditions, snapshot_date 之后）
amount REAL,          -- 成交额（千元，需 /1e4 转亿元展示）
turnover_rate REAL,   -- 换手率（%）
circ_mv REAL          -- 流通市值（可选）
```

**提取逻辑**（basic_df 查询扩展）：

```sql
-- 现状：SELECT ts_code, total_mv, pe, pb FROM daily_basic_cache
-- 扩展：+ turnover_rate, circ_mv
-- 新增：amount 从 daily_cache 取（与 close/pct_chg 同源查询加 amount 列）
```

### 3.3 API 响应透出（get_treemap_snapshot_items）

```python
# enhanced_cache_manager.py 组装 dict 增加：
'amount': _safe_float(r['amount']),
'turnover_rate': _safe_float(r['turnover_rate']),
```

**单位约定**：amount 源为千元，前端展示统一 `/ 1e8` 转"亿元"（1 亿元 = 1e5 千元，注意换算：2318839.88131 千元 = 23.19 亿元，需 `/ 1e5`）。

### 3.4 现有 API 复用（无需改动）

| 接口 | 用途 | 状态 |
|------|------|:----:|
| `/api/v3/opportunity-atlas/treemap?mode=market` | 全市场数据（含新字段后） | ✅ 复用 |
| `/api/v3/opportunity-atlas/diagnose?ts_code=` | 点击个股详情（L4 诊断） | ✅ 复用 |
| `/api/v3/opportunity-atlas/treemap?mode=opportunity/value` | 机会/价值模式 | ✅ 复用（注意：opportunity 需 tags 参数） |

**注意**：现有前端 `loadMarketData` 已从 `s.amount`/`s.turnover_rate` 读取——后端补透出后前端无需改数据映射（原型已按此设计）。

## 四、后台运行支持（data_daemon 管道）

### 4.1 快照重建触发

- `_build_treemap_snapshot` 是 S1 管道步骤（日终自动执行）
- **修订后需一次性手动重建**（应用新 schema），后续日终自动
- 重建方式：停 daemon → 运行快照构建函数 → 重启 daemon（参照 014/008 操作流程）

### 4.2 无新增采集需求

- `amount` 来自 daily_cache（已有日终采集）
- `turnover_rate`/`circ_mv` 来自 daily_basic_cache（已有日终采集）
- **无需新增数据源或采集频率**

### 4.3 兼容性保障

| 项 | 措施 |
|----|------|
| 旧快照表 | 原子表替换（DROP+ALTER），无迁移风险 |
| API 降级 | 快照读取失败 → `_fallback_legacy_treemap`（旧路径仍可用，仅缺新字段） |
| 前端兼容 | 新字段缺失时前端 `typeof === 'number'` 守卫显示 `--` |
