# 个股策略分析前端展示架构重设计方案

> **背景**：272/273/273a 号方案全量实施后，后端数据能力大幅增强（九层框架DeepSeek描述、C1-C3筹码增强、情绪四阶段、财务排雷等），但前端 `indicator-ide.html` 仍沿用旧有 5 卡平权设计，大量数据不可见、展示空间不足。经评估，需要从展示架构层面重设计，而非修补。

---

## [S1] 设计原则

| 原则 | 说明 |
|------|------|
| **数据层次清晰** | 展示结构匹配九层框架的三层数据流：环境定位 → 个股全息 → 辅助验证 |
| **一目了然** | 用户扫一眼 Dashboard Bar 即知整体状态，无需逐个卡片阅读 |
| **下钻深度充足** | 每个维度有专属 Tab 面板容纳完整指标和增强数据 |
| **常驻操作入口** | 策略选择 + 运行按钮始终可见，不折叠不隐藏 |
| **用户主动触发** | 切换股票不清除策略选择，但不会自动运行分析，需点击"运行分析" |

### [S2.1] 保留不变的部分

- K线图表区域（左侧主图 + 副图 + 叠加指标）
- 右侧行情面板（股票信息、报价网格、盘口五档、资金流向饼图、5日资金流向条）
- K线周期切换（日/周/月/分钟）
- 筹码分布面板（侧滑）
- AI仲裁区（情景推演 A/B/C + 行动建议 + 实操参考 + 数据来源追溯）

### [S2.2] 移除/替换的部分

- **移除**：原有的 5 张平权 `dim-card`（走势结构/量价/筹码/情绪/Vibe）
- **移除**：交叉验证条（`cross-verify-bar`）——验证链整合到 Dashboard Bar 和 Tab 面板中
- **替换**：策略组合栏 + 可折叠配置面板 → 常驻策略工具栏

## [S3] 策略工具栏（常驻）

### [S3.1] 定位与可见性

取代现有 `#strategyBar + #strategyConfig`（点击展开/折叠）模式。新工具栏始终显示在 K 线图下方，策略分析区的正上方。**切换股票不会隐藏工具栏。**

### [S3.2] 布局

```
┌────────────────────────────────────────────────────────────┐
│ 策略选择  [✅缠论走势] [⬜量价形态] [⬜筹码资金] [⬜情绪…] [⬜多因子]  ⚙️高级  ▶ 运行分析 │
└────────────────────────────────────────────────────────────┘
```

- 每个策略以 **badge 圆角标签** 展示
- 选中态：背景色 + 边框高亮 + ✅ 前缀
- 未选中态：灰色透明背景 + ⬜ 前缀
- 点击 badge 切换选中/取消
- "运行分析"按钮三态：

| 状态 | 文案 | 样式 | 交互 |
|------|------|------|------|
| 未分析 | `▶ 运行分析` | 蓝色实心 | 可点击，发起 E12+E13 请求 |
| 分析中 | `🔄 分析中...` | 蓝色 + 旋转动画 | 禁用，策略badge同时禁用 |
| 已完成 | `🔄 重新分析` | 蓝色实心 | 可点击，重新发起请求 |

### [S3.3] 高级设置 popover

点击 ⚙️ 弹出浮动小窗，包含：

| 项目 | 说明 |
|------|------|
| Kronos AI 信号增强 | 开关，操作说明文字 |
| 从选股系统同步 | 从 `/api/v3/screener/fusion-config` 取当前权重覆盖策略选择 |
| 保存为默认 | 写 localStorage |
| 加载默认 | 从 localStorage 恢复 |

popover 行为：点击 ⚙️ 打开，点击外部关闭，单次只能打开一个。

### [S3.4] 持久化规则

- 策略选择在切换股票时保留（不重置为默认）
- 策略选择在页面刷新时从 localStorage 恢复
- 策略选择在"从选股系统同步"时被覆盖
- 分析结果在切换股票时清空（回到未分析状态）

## [S4] Dashboard Bar（顶行指标条）

分析完成后显示在策略工具栏与现状概览之间。5 格等宽卡片：

| 指标卡片 | 数据来源 | 展示内容 |
|---------|---------|---------|
| **信号共识** | E12 factor 维度 + E13 chains | 方向文字（看涨/看空/震荡偏多）+ 一致性比率（3/5） |
| **市场情绪** | E12 emotion 维度 + MarketSentimentService | 阶段标签（冰点/复苏/高潮/退潮）+ 涨停/跌停数 |
| **主力资金** | E12 chip 维度 | 方向（净流入/净流出/中性）+ 金额（万） |
| **财务排雷** | FinanceReportService (273a) | 判定（通过/关注/预警）+ ROCE 值 |
| **数据完整度** | E12 data_availability | 百分数 + 策略就绪数 |

设计要点：
- 每个卡片 2 行：第 1 行标题，第 2 行主数值（大字），第 3 行补充说明（小字）
- 方向类数值带颜色（看涨=红，看空=绿，中性=黄）
- 数据可用时显值，不可用时灰色占位符 `--`

## [S5] 现状概览（九层描述全文）

### [S5.1] 展示方式

独立面板，位于 Dashboard Bar 下方。显示 `dimensions.chanlun.deepseek_text` 的完整内容。

- **默认状态**：显示前 5 行（约 150 字），尾部跟 `... 展开全部 ↓` 链接
- **展开状态**：显示全文（300-800 字）
- 底部操作栏：字数统计 + `展开全部 ↓/收起 ↑` + `📋 复制`

### [S5.2] 降级策略

| 场景 | 展示内容 |
|------|---------|
| DeepSeek 可用 | `deepseek_text` 全文 |
| DeepSeek 不可用 + `status_text` | 走势结构的 `status_text`（fallback_description），加注"系统规则描述" |
| 无任何文本 | "数据不足以生成现状描述" |

## [S6] Tab 下钻面板

### [S6.1] Tab 栏

5 个水平排列的 Tab，默认选中"综合总览"：

| Tab | 激活态 | 内容概要 |
|-----|--------|---------|
| 综合总览 | ✅ 默认 | 3 列网格，各维度关键指标一览 |
| 走势结构 | — | 完整缠论指标 + 多级别联立 + active_signal + zhongshu_list |
| 量价形态 | — | FMZ状态 + 活跃形态 + 增强模式列表 + 共振评分 + V2反转序列 |
| 筹码资金 | — | 5项旧指标 + 9项C1-C3增强字段 |
| 情绪审核 | — | 情绪指标 + 验证链 + 不确定因素 |

### [S6.2] 综合总览 Tab（默认）

3 列等宽网格，每列展示一个维度的关键指标（精简版），格式为 key-value 对列表：

```
┌──────────────┬──────────────┬──────────────┐
│ 📉 走势结构   │ 🌡 量价形态   │ 🧩 筹码资金   │
│ 方向: 下降   │ FMZ: RANGING │ 获利比: 65%  │
│ 中枢: 12-13.5│ 形态: 双针底  │ 偏离: -7.7%  │
│ 位置: 内部   │ 量价: 价跌量缩│ 拥挤: 过热   │
│ 买卖点: 三买  │ 共振: 偏多   │ 散户: 恐慌   │
│ 级别: 日线   │ 支撑: 12.10  │ 主力: 净流入  │
└──────────────┴──────────────┴──────────────┘
```

前 4 行展示核心指标，空间不足时省略部分字段。

### [S6.3] 走势结构 Tab

展示 `dimensions.chanlun` 的完整数据，分为 3 个子区：

| 区块 | 字段 | 说明 |
|------|------|------|
| **基础指标** | direction, zhongshu_range, zhongshu_position, buy_point, ma_alignment, critical_levels | 原卡1 内容 |
| **增强指标** | active_signal / label, near_levels_filtered, level_upper_limit, position_detail | P1-2 新增 |
| **多级别联立** | multi_level.long/medium/short 各自的 direction_text, near_levels | 271号重构 |
| **中枢详情** | zhongshu_list[]（每个中枢的 low/high/type/level/duration/seg_count） | tooltip 或折叠展示 |

### [S6.4] 量价形态 Tab

展示 `dimensions.volume_price` 的完整数据：

| 区块 | 字段 |
|------|------|
| **基础形态** | phase (FMZ状态), phase_label (活跃形态), volume_price_relation (量价关系), trend_strength (共振), support/resistance |
| **增强形态** | active_pattern (置信最高), enhance_patterns[] (所有匹配形态列表) |
| **V2反转序列** | 放量止跌/止涨序列匹配结果，含已匹配 step 数 |

### [S6.5] 筹码资金 Tab

展示 `dimensions.chip` 的完整数据，**这是改动最大的 Tab**——增加 9 个增强字段：

| 区块 | 旧字段（原卡3） | 新增字段（P1 + C1-C3） |
|------|---------------|---------------------|
| **成本分析** | profit_ratio, avg_cost, concentration | **distance_pct**（偏离度）, **margin_cost_price**（融资成本价）, **sandwich_zone**（夹层区间） |
| **资金流向** | main_force_direction, large_order_net | **net_lg_amount_5d**, **net_elg_amount_5d**, **net_sm_amount_5d** |
| **情绪指标** | — | **retail_vs_institutional**（散户4态）, **sentiment_crowding/label**（拥挤度） |

### [S6.6] 情绪审核 Tab

展示情绪环境 + 验证链 + 不确定因素。合并原卡4（情绪环境）+ 卡6（冲突与不确定性）+ 交叉验证条。

| 区块 | 内容 |
|------|------|
| **情绪指标** | market_temp（情绪周期）, sector_pct（行业指数）, risk_level（风险等级） |
| **验证链** | 4 条验证链（主力行为/结构位置/外部环境/共振）的通过/冲突状态 |
| **维度间关系** | consistent/conflict 状态列表 |
| **不确定因素** | 各维度的数据完整性问题 |

## [S8] 数据流与交互时序

### [S8.1] 用户操作流程

```
用户进入页面
  → (默认显示000002.SZ的K线图 + 行情面板)
  → 策略工具栏显示当前保存的策略选择 + ▶ 运行分析按钮
  → 用户点选/取消策略 badge（可选）
  → 用户切换股票（通过搜索/自选/代码输入）
    → 行情数据刷新
    → 策略选择保持不变
    → 分析结果区域清空（回到空状态）
    → ▶ 运行分析按钮保持可点击
  → 用户点击 ▶ 运行分析
    → 按钮变为 🔄 分析中...
    → 发起 E12 + E13 并行请求
    → 完成后填充 Dashboard Bar + 现状概览 + Tab下钻
    → 按钮变为 🔄 重新分析
```

### [S8.2] API 请求

| 端点 | 时机 | 说明 |
|------|------|------|
| `/api/v3/strategy/analyze` | 点击"运行分析" | E12，传 ts_code + kronos_enabled |
| `/api/v3/strategy/status-aggregate` | 同时 | E13，传 ts_code |
| `/api/v3/ai/status-interpret` | E12/E13 完成后 | E14（可选，现有逻辑） |
| `/api/v3/chart/kline/` | 切换股票 | 已有，不变 |
| `/api/v3/chart/chip-distribution/` | 切换股票 | 已有，不变 |
| 盘口/资金流向等 | 切换股票 | 已有，不变 |

### [S8.3] 状态机

```
               切换股票（清空结果，保留策略）
                    │
                    ▼
              ┌───────────┐
              │  UNANALYZED │
              │ (未分析)    │
              └─────┬─────┘
                    │ 点击"运行分析"
                    ▼
              ┌───────────┐
              │  ANALYZING │  ← 禁用策略选择
              │ (分析中)    │
              └─────┬─────┘
                    │ 请求完成
                    ▼
              ┌───────────┐
              │  COMPLETED │  ← 全部数据就绪
              │ (已完成)    │
              └─────┬─────┘
                    │ 切换股票 / 点击"重新分析"
                    │
              ┌─────┴─────┐
              │           │
          UNANALYZED    ANALYZING
```

## [S11] 暂不处理的事项（后续迭代）

| 事项 | 原因 |
|------|------|
| 多周期切换（period=long/medium/short） | 后端已支持但前端暂不设计入口，待验证数据有效性后加入 |
| 情绪四阶段/财务排雷独立卡片 | 用户确认合并到情绪审核 Tab 和 Dashboard Bar 间接展示 |
| 收益驱动维度（九层第⑥层） | 后端数据管道未就绪（272号文档评估为 0% 就绪） |
| 单页应用化（Vue/SPA） | 维持现有原型 HTML + vanilla JS 架构 |
