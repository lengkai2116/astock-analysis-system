# 456 号 — dim4 融资成本价进阶段投票

## 一、问题确认（445 §6.1 dim4，代码级已核 + 真实库验证）

445 §6.1 登记 dim4 偏差：**「融资成本价…只到文案层」**。具体缺口：

1. **阶段投票缺口**：443 R2 已让 `_dim_ssrp` 消费 `cost_ext.main_force_cost`（现价近主力成本 5% → washing 增强），但 **`margin_cost_price`（融资成本价）完全未进阶段投票**——只到 `evaluate()` 的 `status_description['margin']`/`_assess_margin` 文案层。wiki《融资成本价》语义（解套压力位）未参与 dim4 阶段判定。
2. **framework 双份缺口**：`chip_strategy.py._calc_margin_cost_price`(:1056) 已实现但 **零消费点**（grep 确认仅 data_daemon:3582 调用、无 scoring 消费）；`_score_retail_contrarian` 只消费融资余额方向信号（rzye 趋势），不消费融资成本价本身。
3. **【关键】precompute_raw 形态 bug（真实库验证发现）**：`data_daemon.py:3581-3583` 把 `_calc_main_force_cost()/_calc_margin_cost_price()` 的**完整返回 dict** 塞进 `cost_ext`：
   ```json
   "main_force_cost":    {"cost_price":0,"distance_pct":0,"near_cost":false},
   "margin_cost_price":  {"cost_price":null,"distance_pct":null}
   ```
   而 443 R2 的 `_dim_ssrp` 把 `cost_ext` 值当**标量**用（`abs(current-mfc)/mfc`）→ 真实数据下抛 `TypeError` → 被 evaluate 外层 `except` 吞掉 → **main_force_cost 近距增强 + （若有）margin 投票在真实库里根本没进阶段判定**。这正是「只到文案层」的**真实接线根因**（原型验证：修复前 600000.SH evaluate `judgment.phase=None` audit 1/5；修复后 washing 置信0.47）。

## 二、修复方案（用户拍板：扩展 _dim_ssrp + framework 双份同步）

### 2.1 dim4 `_dim_ssrp`：融资成本价弱补充投票（wiki 解套压力位语义）
新增 `_apply_margin_signal(vec, current, cost_ext)`，对 `_dim_ssrp` 各分支主向量叠加**弱补充信号**（不覆盖主规则、不触 supporter≥2 门槛）：

```python
rel_m = current / mcp
if rel_m >= 1.05:      vec["lifting"]  += 0.2   # 站上/突破解套压力位 → 上方抛压释放、阻力锐减(做多)
elif rel_m <= 0.85:    vec["building"] += 0.1   # 融资盘深套 → 安全边际/远期机会
else:                  vec["washing"]  += 0.2   # 成本位下方/附近 → 反弹遇散户解套抛压(承压蓄势)
```

- 对齐 wiki《融资成本价》：现价在下方→反弹至该位受解套抛压（washing）；站上/突破→上方抛压释放、阻力锐减（lifting）。
- 融资**方向**信号（暴增+滞涨=危险）已在 `_score_retail_contrarian`/`_assess_margin` 消费，本方法只做成本锚定的压力位弱投票，不重复。

### 2.2（关键）`_cost_value` 归一化：兼容 precompute dict 与标量双形态
真实库 `precompute_raw` 存完整返回 dict，单测用标量。新增 `_cost_value(cost_raw)` 统一取数值（dict→`cost_price`；标量→float；None/非法→0），替换 `_dim_ssrp` 原 `cost_ext.get("main_force_cost")` 直用与 `_apply_margin_signal` 直用——**修复接线 bug，让既有 443 R2 近距增强 + 本号 margin 投票在真实库真正生效**。

### 2.3 framework `_score_chip_distribution`：补融资成本价消费（双份同步）
`_score_chip_distribution`(:919) 补上零消费的 `_calc_margin_cost_price`：
```python
margin_cost = self._calc_margin_cost_price(symbol, current_price)
mcp = margin_cost.get('cost_price') if margin_cost else None
if mcp and mcp > 0 and current_price > mcp * 1.05:
    score += 0.2   # 现价站上融资成本价 → 上方融资盘抛压释放、阻力锐减(做多)
```
对齐 dim4 `_apply_margin_signal` 阈值（>1.05→做多）。framework 是实时自算返回 dict，无形态 bug。

**SIG/JUD 边界**：本号只改 dim4 阶段投票证据（SIG 产证据/条件），不触碰 judgment/灯色。
