# 463 — 缠论复权口径 + 中枢选用/级别修复

> **定位**：444 第③步冲突核查发现 A 类核心根因——**缠论"结构下降"的判定依据（现价 vs 5 年未复权历史中枢）系统性失真**：
> ①数据未复权（除权除息跳空被误判为走势结构）；②`zs_list[-1]` 取"最后识别中枢"无时效/失效判定（000002 中枢=2021 年价位 19~23 vs 现价 3 元 → 恒判"中枢下方/下降"）；③日线中枢跨度过长未升级周线级。
>
> **边界（445 冻结）**：只修**数据口径（复权）与中枢选用/级别规则**（事实/取数/口径层），**不改变缠论判定条件本身**（分型/笔/线段/中枢重叠公式/背驰条件不动）。修正后结构判定真实化（000002 等不再恒"下降"）。

## 〇、探查实证（2026-09-18，勿重做）

### 数据层
- `dim1_signal_engine.py:75` 加载 daily_df 用 `dm.get_cached_daily_data(ts_code)` **默认 adj=None（未复权）** → dim2 缠论/量价/风险全用未复权价。
- `data_daemon._precompute_raw_features`（:3184）all_data 用 `_ecm.get_cached_daily(code)` **同样未复权** → RAW 预计算（chanlun/支撑阻力/量价）与 SIG 一致地未复权。

- daily 数据 = **1263 根（2021-07-07 ~ 2026-09-17）**，缠论 `analyze(df)` 全量使用无窗口截断。

## 一、知识库依据（权威口径）

1. **复权**（《缠论走势结构量化系统配置指南》§一/§七）：**分析用后复权**，避免除权除息跳空被误判为走势结构；前复权用于实际交易。→ **当前未复权 = 明确错误**。
2. **中枢定义**（《中枢的量化定义》《笔中枢与线段中枢》）：中枢 = 连续三段次级别走势重叠区（下沿=max 三段低点最大值，上沿=min 三段高点最小值）；**延伸/扩展/新生动态跟踪，保留最新三个中枢状态**。
3. **中枢跨度**（《中枢跨度时长》）：日线级别中枢经验跨度 **1 周~3 个月**，**超 6 个月升级周线级**；级别由结构决定不由时间决定。

## 二、处置设计

### A. 复权口径（取数层，两处接线 + 语义修复）

- **口径**：缠论/结构分析用**后复权**（知识库权威）。后复权最新价≠实际价 → 展示绝对价格（中枢区间/支撑压力"元"）时按 **scale（=实际最新价/后复权最新价 = 1/最新累计因子）** 换算回实际价。
- **改动**：
  1. `_apply_adjust_factor`：**修复 hfq/qfq 语义反转**（hfq=真后复权 base=最早因子；qfq=前复权 base=最新因子），并补充 scale 信息（或新 helper `get_hfq_daily(ts_code) → (df_hfq, scale)`）。
  2. `dim1_signal_engine.py:75`：daily_df 改后复权加载；data_context 附带 `price_scale`（供展示换算）。
  3. `data_daemon._precompute_raw_features`（:3184）：all_data 改后复权加载（RAW 预计算与 SIG 一致）。
  4. **展示换算点**：dim2 `vs_support_resistance`/`vs_zhongshu`、dim6 `support_price/resistance_price/支持阻力文案` 的"元"值 × scale → 实际价。**相对位置/百分比不受 scale 影响**（dim2 判定、dim6 dist_pct 等零改动）。
- **影响面**：daily_df 同源供 dim2/3/4/6；后复权下相对计算（量比/涨跌幅/形态/分位）等比缩放不受影响；仅"绝对元"展示换算。

### B. 中枢选用（framework + dim2，核心）

新增 **`_select_current_zhongshu(zs_list, klines)`**（chanlun_strategy.py）：
```
从 zs_list 尾部向前扫描（保留最新三个中枢状态，知识库）：
  1. 级别过滤：中枢跨度(duration) > 6 个月 → 周线级，跳过（不作为日线级有效中枢）
  2. 时效/失效：中枢 end_date 距最后一根K线 > 6 个月（日线级合理跨度上限）→ 已失效，跳过
  3. 破坏确认：中枢之后价格已有效离开（突破上沿/跌破下沿且未回抽——三类买卖点）→ 已破坏，跳过
  返回第一个通过过滤的中枢（= 当前有效中枢）；全部过滤 → None
```
- 接线：`_determine_trend`/`_determine_trend_basis`/dim2 `_assess_vs_zhongshu` 三处 `zs_list[-1]` → 改用 `_select_current_zhongshu`。
- **无有效中枢** → 趋势走"无中枢"兜底（最后段方向，原逻辑已有），`vs_zhongshu` 输出"当前无有效中枢（趋势延续）"而非拿旧中枢伪对比。
- 中枢序列辅助（≥2 中枢比较上移/下移）仅对**有效中枢序列**生效。

### C. 级别标注（输出层）

- `vs_zhongshu` detail 补**中枢时间信息**（start~end 日期、跨度、级别），"价格位于中枢上方/下方/内部（区间，跨 X 月，日线级）"——现状描述可回溯（444 因果链要求）。
- `_determine_trend_basis` 相应补"基于 X 年 Y 月至 Z 月中枢"。
