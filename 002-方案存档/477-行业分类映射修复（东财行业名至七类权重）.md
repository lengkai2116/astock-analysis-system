# 477号｜行业分类映射修复（东财行业名 → 七类权重）

**定位**：dim7 定稿前置核查（2026-09-23）发现①——`Stock.industry`（Tushare stock_basic 东财口径）与 `INDUSTRY_CATEGORY`（申万口径键）两套体系错位，**97.6% 股票落「微小/亏损」兜底权重**，CATEGORY_WEIGHTS 七类差异化权重从未生效。

**状态**：✅ **已实施**（2026-09-23）。`EASTMONEY_CATEGORY`（东财 111 行业 → 七类）+ 双侧 `_category` 优先查东财映射；验证：覆盖率 **99.9%**（5543/5547，仅 None 兜底），分布 科技1119/周期2021/成长1423/蓝筹716/稳定收息144/金融120；600519→蓝筹、000002→周期、证券/保险→金融、300750→成长。测试 `tests/test_477_industry_category.py` **4 passed** + 回归 26 passed。待 478 回补后全量重算生效。

## 根因（实证）
- `Stock.industry` = Tushare `stock_basic(fields='ts_code,name,industry,area')`（data_daemon:1008）——**东财二级行业**枚举 111 类（白酒/全国地产/电气设备/元器件/专用机械/软件服务…）。
- `INDUSTRY_CATEGORY`（valuation_estimator.py，431 G1 收敛）——**申万一级**键 31 类（食品饮料/房地产/电子/电力设备…）。
- 仅「家用电器」「银行」2 类恰好同名 → **5413/5547 只（97.6%）`_category()` 返回 '微小/亏损'** → 全部用微小/亏损权重 (0.4,0.05,0.3,0.2,0.05)。
- 实证：600519（白酒）→微小/亏损、000002（全国地产）→微小/亏损；保险 5/证券 50/多元金融 23 只被当非金融 → `_fina_health` 负债率判定失真。

## 影响
1. **dim7 composite/level 权重系统性错**：七类设计意图（蓝筹 a3/a5 权重高、科技 a4 高、周期 a1 高、金融跳过 a3）从未生效；微小/亏损权重下资产锚 0.4 主导、收益锚仅 0.05（茅台 a2 贡献被压）。
2. **`_fina_health` 金融排除失效**：无映射金融类（保险/证券/多元金融）被当非金融 → 负债率<70% 判定失真。
3. 消费 `INDUSTRY_CATEGORY` 的仅 dim7/valuation_estimator（`_category`）——影响面=估值体系。

## 方案（待拍板）
- **核心**：新增**东财行业名 → 七类**映射（111 项），`_category` 优先查东财映射，无映射才落微小/亏损。
- 七类 = CATEGORY_WEIGHTS 既有键（蓝筹/成长/周期/科技/金融/稳定收息/微小亏损）。归类建议（示例）：
  - 蓝筹：白酒/食品/乳制品/软饮料/家用电器/日用化工/汽车整车/家居用品…
  - 成长：软件服务/互联网/通信设备/IT设备/半导体/元器件/影视音像/传媒类…
  - 周期：钢铁/煤炭/有色（铝/铜/铅锌/黄金/小金属）/化工（原料/塑料/化纤/橡胶）/地产（全国/区域/园区/房产服务）/建材/水泥/玻璃/航运/水运/空运/港口…
  - 科技：半导体/元器件/软件服务/通信设备/IT设备/电器仪表/新型电力…
  - 金融：银行/证券/保险/多元金融/信托…
  - 稳定收息：电力（火/水/新型）/水务/供气供热/公用事业/公路/铁路/机场…
  - 微小/亏损：仅兜底（无映射/未知）
- **实现位置**：`valuation_estimator.py` 的 `INDUSTRY_CATEGORY`（保留申万键兼容）+ 新增东财映射常量（或并入同一 dict）；`_category` 查两表。
- **验证**：全市场七类分布（97.6% 兜底 → 覆盖率>95%）；600519→蓝筹、000002→周期、银行/证券→金融；composite 重算对比（476 回算脚本复用）；回归测试。
