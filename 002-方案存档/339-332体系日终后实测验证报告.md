## 二、实测发现并修复的问题（3 个）

| # | 问题 | 根因 | 修复 |
|:-:|---|---|---|
| 1 | **信号生命周期负距离误判"初期🟢"**（603897 跌破信号价却显示初期） | `_signal_lifecycle` 阶段映射只覆盖正距离，负距离（现价<信号价）落入"初期" | 加**"回撤"态**（dist_pct<0 → 回撤/🔴，信号有效性受损；_DIM_DIRECTION time 加回撤:-1）——603897 时间维=回撤 ✅ |
| 2 | **active_signal 标签解析失败（单引号字符串）** | 标签值为 Python 单引号字面量（`"{'type':...}"`），`json.loads` 抛错 → 生命周期 None | 改 `ast.literal_eval` 兼容（status_engine + advice_builder L0c 两处） |
| 3 | **`_signal_lifecycle` 用 `tags.get('ts_code')` 取码失败** | tags dict 无 ts_code 键 → `get_cached_daily_data('')` 返回空 → 生命周期 None | 改显式传入 ts_code 参数 |
