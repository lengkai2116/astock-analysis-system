### 1.4 差距详解

#### 差距1：信号属性分类器（新建）

**现状**：`_check_right_side_confirm()` 输出4值（否决/强确认/基础确认/未确认）

**目标**：7类全量分类（右侧确认/右侧初现/左侧试探/趋势运行/盘整待变/风险警示/中性）

**判断逻辑**（数据驱动）：

```
风险优先：risk_level≥高 → risk_warning
右侧确认：signal_registry匹配 AND 验证通过 AND 共振≥2 AND 风险<高
右侧初现：signal_registry匹配 AND 未验证 AND 共振≥1
左侧试探：结构下降 AND 筹码流入>0.5 AND 量价>60 AND 估值低估 AND 风险<高
趋势运行：结构强度>0.6 AND 无新信号 AND 量价>50 AND 风险<中
盘整待变：结构盘整 AND 量价40-60 AND 筹码中性 AND 无信号
中性观望：以上均不满足
```

#### 差距2：信号衰减检测器（新建）

**现状**：衰减逻辑分散在缠论(weakening)、量价(trend strength)、筹码(衰减率)

**目标**：集中化5维度联合衰减检测（0-100衰减分）

**5维度权重**：

| 维度 | 数据源 | 权重 |
|------|--------|:----:|
| 走势变化 | daily_cache（价格vs信号价3日趋势） | 30% |
| 量价关系 | daily_cache+daily_basic（动态量价状态四类八种） | 25% |
| 量能变化 | daily_cache（成交量vs20日均量） | 20% |
| 筹码变化 | moneyflow+stk_holder（集中度变化+资金流向） | 15% |
| 主力行为 | lhb_cache+margin（龙虎榜+融资余额） | 10% |

**衰减等级**：0-39 healthy / 40-69 fading / 70-100 broken

#### 差距3：信号强度评分调整

**现状**：potential_engine的7维潜力评分（估值/业绩/板块/事件/资金/趋势/综合）

**目标**：4维度加权（结构×0.25+量价×0.30+筹码×0.25+因子×0.20）

#### 差距4：风险三维模型扩展

**现状**：L0三级（hard_veto/soft_constraint/hold_only）

**目标**：三维输出（severity×timing×reversibility）

**严重度分级**：极端→高→中→低→可忽略

**时间性分级**：即将(1-5日)→中期(1-3月)→远期(3月+)→持续

**可逆性分级**：不可逆→部分可逆→可逆

**组合逻辑**：
```
不可逆+极端 → avoid
高+即将 → 限仓≤10%+持有≤5天
高+中/远期 → 限仓≤20%+必须止损
中 → 限仓≤30%+持有≤20天
低 → 仅提示
```

### 1.6 新建文件详细设计

#### signal_attribute_classifier.py

```python
class SignalAttributeClassifier:
    """信号属性7类全量分类器"""
    
    def classify(self, dims, risk_flags, lifecycle_info) -> dict:
        """
        输入：
          dims: dict - 6维度数据（structure/volume_price/chip/factor/emotion/risk）
          risk_flags: dict - 风险标志（hard_veto/severity/timing/reversibility）
          lifecycle_info: dict - 信号生命周期（triggered/verified/resonance_count）
        输出：
          {code, name, confidence, evidence, light}
        """
        # 1. 风险优先
        if risk_flags.get('severity') in ('extreme', 'high'):
            return self._risk_warning(risk_flags)
        
        # 2. 右侧确认
        if (lifecycle_info.get('verified') and 
            lifecycle_info.get('resonance_count', 0) >= 2):
            return self._right_confirmed(dims, lifecycle_info)
        
        # 3. 右侧初现
        if lifecycle_info.get('signal_triggered') and not lifecycle_info.get('verified'):
            return self._right_emerging(lifecycle_info)
        
        # 4. 左侧试探
        if self._check_left_probing(dims):
            return self._left_probing(dims)
        
        # 5. 趋势运行中
        if self._check_trend_running(dims, lifecycle_info):
            return self._trend_running(dims)
        
        # 6. 盘整待变
        if self._check_consolidating(dims, lifecycle_info):
            return self._consolidating(dims)
        
        # 7. 中性观望
        return self._neutral()
```

#### signal_decay_detector.py

```python
class SignalDecayDetector:
    """5维度联合信号衰减检测器"""
    
    WEIGHTS = {
        'price_trend': 0.30,
        'volume_price': 0.25,
        'volume_energy': 0.20,
        'chip_change': 0.15,
        'main_force': 0.10,
    }
    
    def detect(self, ts_code, signal_date, current_date) -> dict:
        """
        输出：
          {overall_score, overall_status, breakdown: {dim: {status, score, detail}}}
        """
        breakdown = {}
        
        # 1. 走势变化
        breakdown['price_trend'] = self._check_price_trend(ts_code, signal_date)
        
        # 2. 量价关系
        breakdown['volume_price'] = self._check_volume_price(ts_code)
        
        # 3. 量能变化
        breakdown['volume_energy'] = self._check_volume_energy(ts_code)
        
        # 4. 筹码变化
        breakdown['chip_change'] = self._check_chip_change(ts_code, signal_date)
        
        # 5. 主力行为
        breakdown['main_force'] = self._check_main_force(ts_code)
        
        # 聚合评分
        overall_score = sum(
            breakdown[dim]['score'] * self.WEIGHTS[dim]
            for dim in self.WEIGHTS
        )
        
        # 状态判定
        if overall_score >= 70:
            status = 'broken'
        elif overall_score >= 40:
            status = 'fading'
        else:
            status = 'healthy'
        
        return {
            'overall_score': round(overall_score),
            'overall_status': status,
            'breakdown': breakdown
        }
```

```python
def calculate_emotion_temperature(limit_ecology_score, bociasi_score, vp_score, flow_score, volatility_score):
    """
    情绪综合分 = 0.3×涨停生态分 + 0.2×BOCIASI分 + 0.2×量价形态分 + 0.15×资金流向分 + 0.15×波动率分
    """
    temperature = (0.30 * limit_ecology_score +
                   0.20 * bociasi_score +
                   0.20 * vp_score +
                   0.15 * flow_score +
                   0.15 * volatility_score)
    return round(temperature, 1)
```

各分项计算：
- **涨停生态分**：f(涨停家数分位, 炸板率, 涨停溢价, 连板高度) → 0-100
- **BOCIASI分**：四象限fast_score → 0-100
- **量价形态分**：全市场VP-1~VP-9分布 → 0-100
- **资金流向分**：全市场大单净流入方向和强度 → 0-100
- **波动率分**：全市场波动率历史分位 → 0-100

```python
def _status_bar(self, dims: dict, state: str, l0: dict) -> str:
```

```python
class ConditionAuditor:
    """条件稽核器基类"""

class SignalConditionAuditor(ConditionAuditor):
    """第1维：信号确认条件稽核器"""
    
    def audit(self, ts_code, dims, tags, signals):
        conditions = []
        
        # 条件1：信号触发
        signal_triggered = bool(tags.get('active_signal'))
        conditions.append({
            'name': '信号触发',
            'satisfied': signal_triggered,
            'actual': '已触发' if signal_triggered else '未触发',
            'threshold': '需有活跃信号',
            'detail': f'活跃信号：{tags.get("active_signal", "无")}'
        })
        
        # 条件2：信号验证
        verified = dims.get('time', {}).get('verified', False)
        conditions.append({
            'name': '信号验证',
            'satisfied': verified,
            'actual': '已验证' if verified else '未验证',
            'threshold': '3-5日不破信号价',
            'detail': f'验证状态：{verified}'
        })
        
        # 条件3：共振维度
        resonance_count = self._count_resonance(dims)
        conditions.append({
            'name': '共振维度',
            'satisfied': resonance_count >= 2,
            'actual': f'{resonance_count}维',
            'threshold': '≥2维',
            'detail': f'共振维度数：{resonance_count}'
        })
        
        # 条件4：风险等级
        risk_level = dims.get('risk', {}).get('state', '中')
        conditions.append({
            'name': '风险等级',
            'satisfied': risk_level in ('低', '中'),
            'actual': risk_level,
            'threshold': '<高',
            'detail': f'风险等级：{risk_level}'
        })
        
        # 统计满足数量
        satisfied_count = sum(1 for c in conditions if c['satisfied'])
        total_count = len(conditions)
        
        # 判定属性
        attr_code = dims.get('signal_confirm', {}).get('state', '中性观望')
        light = dims.get('signal_confirm', {}).get('light', 'yellow')
        
        return {
            'dimension': '信号确认状态',
            'judgment': attr_code,
            'light': light,
            'conditions': conditions,
            'satisfied_count': satisfied_count,
            'total_count': total_count,
            'confidence': satisfied_count / total_count if total_count > 0 else 0,
            'plain': self._generate_plain(attr_code, conditions, satisfied_count, total_count)
        }
    
    def _count_resonance(self, dims):
        """统计共振维度数"""
        count = 0
        for dim in ['structure', 'vp', 'chip_fund', 'factor']:
            if dims.get(dim, {}).get('confidence', 0) > 0.5:
                count += 1
        return count
    
    def _generate_plain(self, attr_code, conditions, satisfied_count, total_count):
        """生成白话总结"""
        attr_name = SIGNAL_ATTR_MAP.get(attr_code, '中性观望')
        satisfied_conditions = [c['name'] for c in conditions if c['satisfied']]
        
        if satisfied_conditions:
            return f"这只股票处于【{attr_name}】状态，因为{satisfied_count}/{total_count}个条件被满足：{'、'.join(satisfied_conditions)}"
        else:
            return f"这只股票处于【{attr_name}】状态，条件满足度较低（{satisfied_count}/{total_count}）"
```
