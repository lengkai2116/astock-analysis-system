# 机会图谱实施计划总纲

> **范式转变**：从「选股系统」(Stock Screener) 到「机会图谱」(Opportunity Atlas)
>
> 选股系统输出一个排序列表，问"哪些股票好？"
>
> 机会图谱是一张**可缩放导航的市场地图**，问"今天市场上机会在哪里、风险在哪里？"

---

## 一、一键启动

```bash
# 后端开发（各模块独立）
python backend/app/opportunity_atlas/valuation_estimator.py   # P0: 估值引擎
python backend/app/opportunity_atlas/phase_detector.py        # P0: 阶段判定引擎
python backend/app/opportunity_atlas/library_manager.py       # P1: 标的库

# 前端开发
cd _ui-prototype && open opportunity-treemap.html             # 已有原型起点
```

- P0.4 必须在 P0.1 + P0.2 + P0.5 都完成后才能开始

- P2.2 同时依赖 P1.1 标签池（共识投票的输入）
- P2.3/P2.4 必须在 P1.2 标的库就绪后才能开始

## 八、关键决策记录（与 295-302 号方案通用）

| 编号 | 决策 | 选择 | 替代方案 | 理由 |
|------|------|------|---------|------|
| D1 | 标签引擎架构 | 引擎统一产出标签→标签池 | 引擎按管线分配 | 同一策略对长短线需求不同，不由引擎决定归属 |

| D6 | 标的库评分 | 分层（基础分 + Factor/Vibe 加成） | 单层混合 | 防止策略变更导致标的库震荡 |
