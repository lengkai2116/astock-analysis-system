# 东财HTTP实时行情替代mootdx可行性评估报告

## 一、背景

mootdx TCP 数据源自 2026-07-20 起因通达信服务端协议更新而断裂（GitHub Issue #157），`quotes()` 和 `bars()` 返回空数据，仅 `minute()` 尚可用。项目作者已两年未活跃，库无修复预期。已确认 Tushare/AKShare 无法替代实时行情。

本报告对**东方财富 HTTP API** 作为主替代方案进行稳定性、效率、限流和数据质量的全面实测。

---

## 二、测试结果汇总

### 2.1 稳定性 — 通过 ✅

| 指标 | 结果 |
|------|------|
| **连续请求** | 200 次连续请求（无间隔），**0 次失败**，成功率 **100%** |
| **错误模式** | 未观察到任何 HTTP 错误、限流（429）、超时或数据格式异常 |
| **IP 限制** | 未发现 IP 级别的频率限制 |
| **结论** | 东财 push2 API 在生产环境下稳定可靠 |

### 2.2 响应速度 — 极快 ✅

| 场景 | 耗时 | 说明 |
|------|------|------|
| 单只股票查询 | **0.08-0.10s** | `ulist.np` 批量端点 |
| 批量 10 只 | **0.08s** | |
| 批量 60 只 | **0.09s** | |
| 批量 500 只 | **0.23s** | 返回 ~420只有效 |
| 200 次连续请求（P95） | **0.097s** | 最大 0.104s，最小 0.071s |

> 响应时间不随批量大小显著增长——瓶颈在 HTTP 往返而不是数据量。

### 2.3 批量限制

| 请求量 | 返回量 | 结论 |
|--------|--------|------|
| 60 只 | ~47 只 | 约 78% 命中率（部分代码无对应股票） |
| 500 只 | ~422 只 | 无硬性限制，API 返回有效数据的股票 |

**推荐批量大小：60 只/请求**，既能充分利用请求容量，又保持 URL 长度在合理范围内。

### 2.4 全市场扫描效率

并行采集（`ulist.np`，50只/批）：

| 线程数 | 1500只耗时 | 5000只估算 |
|--------|-----------|-----------|
| 串行（1线程） | 5.9s | 19.6s ❌ |
| 并行 4 线程 | **1.6s** | **5.2s** ✅ |
| 并行 8 线程 | **0.8s** | **2.6s** ✅ |

**结论：4 线程即可在 5s 周期内完成全市场 5000 只快照采集。** 与 mootdx TCP 之前的 4.9s/11478只性能相当。

### 2.5 数据质量

#### 字段丰富度

| 端点 | 返回字段数 | 示例字段 |
|------|-----------|---------|
| `ulist.np`（批量） | **80+** 通用非空字段 | price, volume, amount, turnover, amplitude, market_cap, PB, PE... |
| `stock/get`（个股） | 43+ 字段 | 含资金流（主力净流入5日历史）、换手率、量比、市盈率等 |

**数据一致性与 mootdx 对比：**

| 字段 | mootdx 列名 | 东财字段码 | 东财 ulist.np 值（fltt=2） | 正确缩放 |
|------|------------|-----------|--------------------------|---------|

| 涨跌幅% | change_pct | f3 | 0.36 | ✅ |
| 涨跌额 | change | f4 | 0.14 | ✅ |
| 成交量 | volume | f5 | 145243（手） | ✅ |
| 成交额 | amount | f6 | 561800258 | ✅ |
| 振幅 | amplitude | f7 | 1.03 | ✅ |
| 换手率% | turnover | f8 | 0.07 | ✅ |
| 量比 | volume_ratio | f10 | 1.61 | ✅ |
| 代码 | code | f12 / f57 | 600036 | ✅ |
| 名称 | name | f14 / f58 | 招商银行 | ✅ |
| 最高 | high | f15 | 38.85 | ✅ |
| 最低 | low | f16 | 38.45 | ✅ |
| 开盘 | open | f17 | 38.68 | ✅ |

| 总市值 | total_mv | f20 | 9797.9亿 | ✅ |

#### 数据时效性一致性测试

| 股票 | 东财 | 腾讯 | 新浪 | 一致性 |
|------|------|------|------|--------|
| 600036 招商银行 | 38.77 | 38.77 | 38.770 | ✅ 完全一致 |
| 000001 平安银行 | 11.0 | 11.00 | 11.000 | ✅ |
| 600519 贵州茅台 | 1291.44 | 1290.00 | 1291.440 | ⚠️ 腾讯延迟约2s |

**结论：东财数据与新浪完全一致，腾讯偶有 ~2s 延迟。** 东财数据可作为可信来源。

### 2.6 五档盘口数据

| 数据源 | 五档买价/量 | 五档卖价/量 | 说明 |
|--------|-----------|-----------|------|
| **东财 `ulist.np`** | ❌ 无 | ❌ 无 | 批量端点不含五档 |
| **东财 `stock/get`** | ⚠️ 有部分字段 | ⚠️ 有部分字段 | 字段码不直观 |
| **新浪** | ✅ 完整 | ✅ 完整 | 字段[10-19]=买盘, [20-29]=卖盘 |
| **腾讯** | ✅ 完整 | ✅ 完整 | 字段[7-26]含五档 |

**结论**：全市场批量快照不需要五档盘口。五档仅当用户查看个股详情时需要，可单独走新浪 API。

## 三、东财 API 端点总结

### 推荐：全市场批量快照

```
GET https://push2.eastmoney.com/api/qt/ulist.np/get
  ?fltt=2                                    # 启用值缩放（必须）
  &fields=f2,f3,f4,f5,f6,f7,f8,f9,f10,      # 行情字段
          f12,f14,f15,f16,f17,f18,           # 代码/名称/K线
          f20,f21,f37,f38,f39,f40,f41,       # 市值/股本
          f45,f46,f48,f50,                   # 财务指标(PE/PB/ROE)
          f57,f58,f60,f61,f62                # 代码/昨收/流通市值
  &secids=1.600036,0.000001,1.600519,...     # 市场.代码(逗号分隔,最多~60个)
```

### 可选：自选股明细 + 五档（新浪）

```
GET http://hq.sinajs.cn/list=sh600036,sz000001
返回格式: CSV, 字段按索引解析
  [3]=最新价  [4]=最高  [5]=最低
  [10-19]=买五档(vol,price交替)
  [20-29]=卖五档(vol,price交替)
```

### 腾讯备选

```
GET http://qt.gtimg.cn/q=sh600036,sz000001
返回格式: ~分隔的CSV, 字段更丰富但索引不一致
  含五档盘口 [7-26]
```

## 四、风险与注意事项

| 风险 | 级别 | 说明 | 应对 |
|------|------|------|------|
| 东财 API 端点变更 | 🟡 中 | 非官方 API，无契约保障 | 采集器加一层适配器，变更时只改字段映射 |
| 批量请求 URL 超长 | 🟢 低 | 60只× secid ≈ 900字符 | 保持在合理范围内 |
| 并发限流 | 🟢 低 | 200次测试未触发，但生产环境可能不同 | 初始用 4 线程，逐步调优 |
| 非交易时段数据 | 🟢 低 | 非交易时段可能返回昨日收盘 | 沿用 `is_trading_time()` 判断 |
| 五档数据缺失 | 🟢 低 | 批量端点不含五档 | 全市场快照不需要五档；个股详情走新浪 |

## 五、实施建议

### 推荐架构

```
data_daemon 新增 HTTP 快照采集线程
  └→ 每 5s (并行4线程, 60只/批):
      push2.eastmoney.com/api/qt/ulist.np/get
      → 解析 JSON → 转换为 mootdx 兼容的 dict 格式
      → 写入 InMemoryStateStore 的 snapshot 槽
      → 后续的板块自算、涨跌榜、涨跌停池逻辑完全不变

自选股行情推送 (已有 push_watchlist_quotes)
  └→ 直接使用 ECM 快照数据，不涉及数据源变更

五档盘口 (仅个股详情页调用)
  └→ 新浪 API hq.sinajs.cn (或腾讯 qt.gtimg.cn)
  └→ 按需查询，不入 InMemoryStateStore
```

### 改动范围

| 文件 | 改动内容 | 复杂度 |
|------|---------|--------|
| `mootdx_collector.py` | 新增 `_fetch_eastmoney_snapshot()` 方法 | **低** |
| `mootdx_collector.py` | 修改 `collect_market_snapshot()` 检测 mootdx 失败时走 HTTP | **低** |
| `mootdx_collector.py` | 字段映射表（东财字段码 → mootdx 列名） | **低** |

**核心原则**：采集器接口不变（`InMemoryStateStore` 写入、5s 定时调度、全量快照 DataFrame 格式），只替换数据获取层。
