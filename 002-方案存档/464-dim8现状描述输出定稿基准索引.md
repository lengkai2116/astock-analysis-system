## 二、定稿方法论（dim3 六步流程，各维通用）

1. **列全量输出项**：真实数据 dump `{status_description, judgment, audit}` 三层全键 + 实例值（两股对照）。
2. **逐键深挖**：每键定性**果**（定性/评分）还是**因**（被满足的具体条件/实例）；查规则标准来源；多数"因"引擎已算出但未透传——**透传优先、不重算**。
3. **逐键拍板**：采用 / 不采用 / 去重（跨维主源归一）/ 归 JUD。
4. **映射 437 第二层维度**。
5. **用户拍板**。
6. **存档定稿**：最终去向表 + 补产出项 §六 + 本索引登记 + 记忆。

**核心原则**（dim3 确立，dim2 复核沿用）：现状=因非果；评分/合成键归 JUD；透传引擎已算的"因"（conditions/details/reason/状态机 rule 等）；主原料=audit.conditions + 结构化键（非 plain）。
