# 闸门2右侧确认信号体系设计

## 一、背景与定位

### 1.1 在 307 号方案中的位置

307 号方案（三元条件驱动框架）定义了入场三道闸门：

```
闸门 1：机会还在（第一元复核）——当初看好的理由还在不在
闸门 2：右侧确认（技术信号）★ 本方案 ——股票自己走出了要上涨的信号了吗
闸门 3：L4 共识率 ≥ 55%（方向可信度）——多数信号都在说买吗
```

本方案针对**闸门2"右侧确认"信号体系**进行专项设计。核心结论：右侧确认不限于均线突破，而是由**五层来源**（均线 / 趋势结构 / 缠论买卖点 / 量价形态 / K线反转）构成的多源信号库，每类机会按"基础确认 + 增强确认 + 否决条件"三档组合判定。

### 1.2 右侧交易原则回顾

- **左侧交易（错误示范）**：看到好公司大跌，觉得"这么便宜不买可惜"，在下跌途中买入——"接飞刀"，本质是预测"我觉得到底了"
- **右侧交易（正确做法）**：等它止跌企稳、放量突破关键价位之后才买——用"已经发生的上涨事实"确认"它确实开始涨了"
- **右侧确认的本质**：让市场自己告诉你方向，而不是你去猜市场方向

### 1.3 设计原则（与 307 号方案一致）

- **基础确认保证覆盖率**：均线等全市场信号（覆盖率 100%）作为入场必要条件
- **增强确认提升精度**：缠论/量价形态/K线作为加分信号
- **否决条件过滤假信号**：量价背离/空方形态/缠论卖点行使一票否决权
- **每种机会有自己的确认方式**：不搞一刀切，每种机会的"启动方式"本来就不同

## 三、各层信号详细梳理

### 3.1 ① 均线系统（基础层，覆盖率 100%）

知识库依据：`量价关系八准则（格兰威尔）.md`、`均线系统.md`、`背离形态.md`。

**买入类（右侧确认）**：

| 信号 | 白话 | 知识库依据 |
|------|------|-----------|
| 放量站上 MA20/MA60 | 价格放量突破中期均线，趋势转多 | 格兰威尔：放量突破均线=趋势转强 |
| 回踩 MA10/MA20 不破 | 涨起来后回调到均线附近获支撑 | 背离配套：10日均线是生命线 |
| MA5 金叉 MA10/MA20/MA60 | 短期均线上穿中期均线 | 均线系统金叉买点 |
| 均线多头排列 | 短期>中期>长期，趋势完整 | 均线系统多头排列=健康上涨 |
| 价托形成（三均线汇聚上翘） | 短中长均线粘合后向上发散 | 价托与多方炮配合 |

**否决类（右侧反面）**：

| 信号 | 白话 | 知识库依据 |
|------|------|-----------|
| MA5 死叉 MA10 | 短期均线下穿 | 均线系统死叉卖点 |
| 均线空头排列 | 短期<中期<长期 | 均线系统空头排列 |
| 放量跌破 MA20/MA30 | 放量长阴破位 | 格兰威尔准则8：方向调整 |

**工程支撑**：`indicator_ma` 宽表全市场预计算 ✅（307号§9.1 已记录）。

### 3.2 ② 趋势结构（背景层，右侧反转确认）

知识库依据：`趋势线.md`、`123法则.md`、`通道线.md`。

**123法则**（三步确认，与右侧交易字面一致）：

```
做多三步：
  假设1：价格向上突破下降趋势线      → 下跌趋势结束的信号
  假设2：回调但不创新低（回调不破前低）→ 确认底部抬高
  假设3：向上突破前期反弹高点        → 反向推动浪形成
  买入点：突破时买入，止损设在假设2波谷下方
```

**关键价值**：123法则的"假设2：回调不创新低"与缠论**二买**（回抽不破前低）、量价**回探缩量**（卖压轻）是**同一逻辑的三种表述**——跨理论共识信号，可靠性最高。

**趋势线突破确认（二日原则）**：当日收盘突破 + 次日收盘仍在趋势线外 = 突破确认——防止单日假突破。

**理想斜率**：上升趋势线理想角度 30°~50°（`趋势线.md`）。

**工程支撑**：⚠️ 未实现——需新增趋势线/123法则检测器（基于日线高低点序列计算），列为二期增强。

### 3.3 ③ 缠论买卖点（增强层，结构确认）

知识库依据：`三类买卖点.md`、`区间套.md`、`背驰.md`。

**采用（右侧）**：

| 信号 | 白话 | 知识库依据 |
|------|------|-----------|
| 二买（second_buy） | 一买后反弹、回抽不破前低 | 三类买卖点："趋势确认后入场，安全性较高，风险收益比最佳，适合大多数交易者" |
| 三买（third_buy） | 离开中枢后回抽不进入中枢区间 | 三类买卖点："中枢破坏点，趋势确认后的追击入场点" |
| 级别验证 | 月线/周线趋势向上 + 日线买点 → 确认 | 区间套："大级别判断方向，小级别精确定位" |

**排除（左侧）**：

| 信号 | 原因 |
|------|------|
| 一买（first_buy/first_buy_p） | 知识库明确"风险最高、转折早期信号"——本质是左侧抄底。仅作画像观察信号，不作入场扳机 |
| 单纯背驰信号 | 区间套"反复背离"反例——背驰不必然转折，需二买/三买确认 |

**级别验证规则**（`chanlun_level_validator.py` 已实现）：

```
月线趋势向上 + 日线买点 → 买点确认（最高可信）
周线趋势向上 + 日线买点 → 买点确认
周线 + 日线同时有买点   → 共振加强
月线趋势向下 + 日线买点 → 买点待验证（降权）
级别权重：月线 3x、周线 2x、日线 1x
```

**工程支撑**：`chanlun_strategy.py` buy_sell_point 标签覆盖 82%（4548/5555）；`chanlun_level_validator.py` 通过日线重采样周/月线，不依赖分钟线 ✅。

## 四、按机会类型的完整右侧确认信号映射

每类型 = **基础确认（必选）+ 增强确认（加分）+ 否决条件（一票否决）**：

| 机会类型 | 基础确认（均线/趋势） | 增强确认（缠论/量价/K线） | 否决条件（出现即不确认） |
|---------|---------------------|------------------------|------------------------|
| `value_bottom` | 放量站上 MA20 | 二买（回抽不破前低）/ 平台放量突破 / 双针探底 / 锤子线 | 量价背离 / 放量滞涨 / MA5死叉 |
| `building_watch` | 突破建仓成本区上沿 | 三买（离开中枢回抽不进入）/ 缩量上穿筹码密集区 / 强于大市缩量整理 | 跌破建仓区间下沿 / 空方炮 |
| `main_upsurge` | 回踩 MA10 不破 | 三买 + 周线级别向上 / 上升三法（持续确认） | 放量滞涨 / 顶背离 / 缠论一卖 |
| `steady_rise` | MA20 之上稳步上行 | 二买 + 周线共振 / 均线多头排列 + 价托 | 价升量减 / 均线走平拐头 |
| `wash_hot` | 突破洗盘区间上沿 | 二买（洗盘结束回抽确认）/ 地量后倍量启动 / 红三兵 | 跌破洗盘区间下沿 |
| `event_driven` | 放量启动 + 事件确认 | 三买（有中枢结构时）/ 放量突破形态 | 事件落空 / 放量长阴（高台跳水） |
| `dividend_play` | 价格低位 + 未急涨 | 缩量回踩筹码密集区 / 低位小阳线蓄势 | 放量滞涨 / 均线空头排列 |

**核心设计**：基础确认保证覆盖率（100%），增强确认提升精度（加分），否决条件过滤假信号（一票否决）。此设计是"缠论作为增强而非替换"结论的扩展——增强信号从单一缠论扩展为**缠论 + 量价形态 + K线反转**三类。

## 七、实施建议

### 7.1 实施优先级

| 优先级 | 内容 | 工作量 | 说明 |
|:------:|------|:------:|------|
| **P0** | `EnhancedPatternDetector` 接入 `_precompute_l2_labels()`，修复 `pattern_signal` 标签 | ~10 行 | 一次接入获得 45+ 种形态信号，零新增数据 |

### 7.2 与 L4 的衔接

- 右侧确认强度影响 L4 共识率权重：强确认（基础+增强双过）→ 加权 ×1.2；基础确认（仅均线）→ 正常；否决触发 → 直接投 -1 票或要求共识率 ≥75%
- `buy_sell_point` 已在 L4 VOTE_MAP 中（buy_1/buy_2/buy_3 = +1），缠论增强层与闸门3自然联动

### 7.3 待回测验证事项

1. 各形态信号的历史胜率（接入 pattern_signal 后统计）
2. 突破量能 2-3 倍阈值的 A 股适用性验证
3. 否决条件（量价背离/空方炮）对假突破的过滤效果
