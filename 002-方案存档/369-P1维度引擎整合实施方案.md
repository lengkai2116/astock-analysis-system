# 369 — P1 维度引擎整合实施方案

> 本方案基于368号方案P1问题的全部沟通确认内容制定，目标是将分散的策略引擎文件整合为8个独立维度引擎+2个共享服务，消除冗余计算，实现358号方案§10定义的"每维度一个集中的维度引擎"架构。

### 1.2 统一接口契约

每个维度引擎必须实现以下接口：

```python
class DimXEngine:
    """维度X引擎 - [维度名称]"""
    
    def evaluate(self, dims: dict, tags: dict, signals: dict = None, lifecycle: dict = None) -> dict:
        """
        统一评估入口
        
        Args:
            dims: 旧格式维度字典（兼容层输入）
            tags: pre_feat_cache 扁平化后的标签字典
            signals: strategy_signal_detail 解析后的信号字典
            lifecycle: 信号生命周期信息
        
        Returns:
            {
                'status_description': {
                    # 面向用户的现状描述（量化值+白话说明）
                    'field1': '...',
                    'field2': '...',
                    'plain': '一句话概括',
                },
                'judgment': {
                    # 面向系统的判定结论
                    'field1': {'value': '...', 'light': 'green/yellow/red'},
                    'overall_light': 'green/yellow/red',
                    'overall_direction': 1/0/-1,
                },
                'audit': {
                    # 条件稽核（每个判定子项的条件满足情况）
                    'field1': {'satisfied': True/False, 'actual': '...', 'threshold': '...'},
                }
            }
        """
        raise NotImplementedError
    
    def get_data_dependencies(self) -> list:
        """返回本引擎读取的数据源清单（运维用）"""
        raise NotImplementedError
```
