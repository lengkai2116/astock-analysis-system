# 372 — 全局数据体系红线违规稽核与修正方案

> **稽核目的**：基于292号红线规则和353号存储层设定，逐一稽核所有违规项，确认正确修复路径。
>
> **稽核范围**：backend/app/ 全部.py文件 + data_daemon.py
>
> **违规总数**：113处（CRITICAL 10 + HIGH 7 + MEDIUM 74 + STRUCTURAL 24）

---

## 一、红线规则与存储层设定

### 1.1 红线规则（292号§2.2）

| 红线 | 规则 | 适用层 |
|------|------|--------|
| **RL1** | 禁止非采集层实例化数据源Provider | 计算层/调用层 |
| **RL2** | 禁止调用DataManager.sync_*() | 计算层/调用层 |
| **RL5** | 所有数据读取必经DataManager只读方法 | 计算层/调用层 |
| **RL8** | 数据缺失必须走sync_requests | 调用层 |

### 1.2 存储层设定（353号§3.2）

```
采集层（data_daemon）→ 写入STG原始表
计算层（dim引擎/SIG/JUD）→ 读写compute/snapshot表，经DataManager
调用层（routes/services）→ 只读成品仓，经DataManager
```

**唯一写者**：data_daemon（采集层）。计算层和调用层禁止绕过DataManager直连ECM。

**正确修复路径**：

7个查询均为**市场级聚合统计**（全市场百分位/比率），需在ECM中新增对应方法：

| 当前直接SQL | 新增ECM方法 | 返回类型 |

| 融资趋势 | `get_market_margin_trend()` | dict{trend, change_pct} |
| PE中位数百分位 | `get_market_pe_median_percentile()` | float |

**修复步骤**：
1. `bociasi_quadrant` 继承 `DataAwareMixin`
2. 删除 `_get_conn()` 方法
3. `enhanced_cache_manager.py` 新增7个市场级聚合方法
4. 所有查询改用 `self._get_dm().cache.get_market_xxx()`

### 3.2 统一修复模式

```python
# 修复前

class DimXEngine:
    def evaluate(self, dims, tags, signals, lifecycle):
        ecm = get_ecm_instance()

        # ...

# 修复后
from app.data.mixins import DataAwareMixin

class DimXEngine(DataAwareMixin):
    def __init__(self):
        self._dm = None  # DataAwareMixin懒加载

    def evaluate(self, dims, tags, signals, lifecycle):
        dm = self._get_dm()
        df = dm.cache.get_cached_daily(ts_code)
        # ...
```
