## 二、升级方案

### 2.1 P0-1：evaluate()数据源修复（8h）

**目标**：evaluate()消费自身组件的分析结果，而非从tags/dims读取。

**当前代码**：
```python
# 从dims读取（旧路径，不准确）
vp_state = dims.get('vp', {}).get('state', '中性')
dp = -1.5 if any('背离' in str(e) for e in dims.get('vp', {}).get('evidence', [])) else 0
```

**修改为**：
```python
# 使用自身组件分析（新路径，准确）
analyzer = VolumePriceStrategy()
result = analyzer.analyze(df)
stage = result.stage           # StageDetector输出
vol_state = result.vol_state   # VolumeStateAnalyzer输出
relation = result.relation     # RelationAnalyzer输出
signal = result.signal         # SignalGenerator输出

vp_state = signal.pattern_name  # 来自状态机的状态分类
```

**影响范围**：
- `evaluate()`方法重写（~120行）
- 新增`VolumePriceStrategy`实例化
- 移除对`dims.get('vp')`的依赖

### 2.2 P0-2：状态机输出接入status_description（4h）

**目标**：将VPStateMachine的详细输出整合到status_description。

**新增输出字段**：

| 字段 | 来源 | 内容 |
|------|------|------|
| state_machine.state | signal.pattern_name | 状态机分类标签（如"放量突破"/"缩量回调"） |
| state_machine.direction | signal.direction | 方向（BUY/SELL/WATCH/HOLD） |
| state_machine.confidence | signal.confidence | 状态机置信度 |
| state_machine.position_suggestion | signal.position_suggestion | 仓位建议 |
| state_machine.holding_period | signal.holding_period | 持有周期 |
| state_machine.signal_label | signal.signal_label | 信号标签（中文） |

### 2.3 P0-3：evidence字段补全（3h）

**目标**：为所有判定类输出添加evidence字段。

**evidence字段清单**：

| 输出字段 | evidence字段 | 规则触发条件 |
|---------|-------------|-------------|
| vp_state | vp_state_evidence | 状态机分类依据+慢线分布 |
| volume_energy | volume_energy_evidence | 量比数值+量能判定规则 |
| divergence | divergence_evidence | 量价背离判定条件（价格涨+量缩） |
| pattern | pattern_evidence | 检测到的形态名称+置信度 |
| granville | granville_evidence | 格兰威尔八准则匹配条件 |
| three_laws | three_laws_evidence | 三大定律各自的判定结果 |

### 2.4 P1-1：量价背离定义修正（2h）

**目标**：从价格-MACD背离修正为量价背离。

**知识库依据**（`量价分析确认与异常.md`）：
- 确认：成交量验证价格变动（高实体阳线+高成交量=确认上涨真实）
- 异常：量价背离（价格上涨+成交量萎缩=多头陷阱；价格下跌+成交量放大=恐慌抛售）

**修改内容**：
```python
# 修正前：价格-MACD背离
pn = close.iloc[-1] >= close.iloc[-20:].max()
mn = macd.iloc[-1] < macd.iloc[-20:].max() * 0.8

# 修正后：量价背离（知识库标准）
# 1. 价格上涨+成交量萎缩（量价背离）
price_rising = close.iloc[-1] > close.iloc[-5:].mean()
vol_shrinking = volumes[-1] < volumes[-5:].mean() * 0.7
vp_divergence = price_rising and vol_shrinking

# 2. 价格下跌+成交量放大（恐慌抛售/放量止跌）
price_falling = close.iloc[-1] < close.iloc[-5:].mean()
vol_expanding = volumes[-1] > volumes[-5:].mean() * 1.5
panic_selling = price_falling and vol_expanding
```

### 2.5 P1-2：量价三定律输出（1h）

**目标**：将已计算的three_laws输出到status_description。

**知识库依据**（`量价分析三大定律.md` - 威科夫体系）：
- 供求定律：需求>供给→价涨，供给>需求→价跌
- 因果定律：横盘时间越长→趋势幅度越大
- 投入产出定律：价格大幅变动应伴高量；量价背离=异常信号

**输出格式**：
```
three_laws: {
  supply_demand: "量增价涨→需求确认" | "量缩价涨→供给不足" | ...,
  cause_effect: "横盘15天→盘整蓄势" | "横盘60天→大级别蓄势" | ...,
  effort_result: "量价配合→投入产出匹配" | "量缩价涨→投入产出异常" | ...
}
```

### 2.6 P1-3：健康度评分移至JUD（2h）

**目标**：evaluate()移除hs/sl计算，仅保留现状描述。

**移除内容**：
- `hs`（0-10分）计算公式
- `sl`（强健康/健康/中性/弱/严重背离）等级判定
- `pattern_deviation`（形态评分纳入健康度）
- `vp_score`/`ve`/`ms`/`cs`/`is_`/`dp`多因子加权

**保留内容**（status_description）：
- vp_state、volume_energy、divergence、pattern、vol_ratio、granville、plain
- stage（阶段信息）、vol_state_detail（量能详细）、relation_detail（量价关系）、state_machine（状态机）

**JUD环节新增**：
- 健康度评分公式（多因子加权）在JUD环节讨论细化
- 权重校准基于历史回测数据

### 2.7 P1-4：70+形态清理（4h）

**目标**：清理重叠/冗余形态，保留高价值形态。

**清理规则**：

| 类别 | 处理 | 理由 |
|------|------|------|
| 均线类（~15种） | 移除MA5/10/20/60排列检测 | 已在dim2的vs_ma输出，避免重复 |
| 格兰威尔类（8种） | 从EnhancedPatternDetector移除 | 已通过granville字段单独输出 |
| 放量类（~12种） | 保留并增强evidence | 知识库高价值（`放量止跌与放量止涨.md`） |
| 缩量类（~6种） | 保留 | 知识库有依据（`量价分析三大定律.md`） |
| K线形态类（~20种） | 保留核心10种 | 知识库有依据（`规则化特征工程.md`），移除低价值的 |
| 经典形态类（~8种） | 保留但标记待验证 | 知识库有依据但A股有效性待验证 |
| 特殊类（~8种） | 保留涨停/缺口，移除其他 | 涨停/缺口是A股特有高价值形态 |

**清理后预期**：70+种 → ~40种核心形态
