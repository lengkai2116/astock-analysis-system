## 问题1：L1 仅86只通过 — 存在单位不匹配Bug

### L1 过滤链逐规则分析

| 规则 | 阈值 | 初始池影响 | 说明 |
|------|------|-----------|------|
| 初始数据池 | ≥120天K线 `load_stock_data_batch` | **4,725只** → 过滤掉818只(793新股+9稀疏) | ✅ 合理 — 新股确实没有足够历史数据 |
| 规则1: ST/退市 | 名称含ST/退市 | 约50-80只（估计） | ✅ 合理 |
| **规则2: 低流动性** | **成交额<1000万** | **5403只(97.5%) → 通过仅约129只** | **❌ 单位BUG** |
| 规则3: 高PE | PE>300(金融豁免) | 约301只 | ✅ 合理 |
| 规则4: 亏损微盘 | PE=0+市值<30亿+换手<3% | 约331只(实际PE=0的为0，不触发) | ❌ daily_basic仅1天数据，PE=0为0 |
| **L1 最终通过** | | **约86只** | **应为约4,093只** |

### 根因：amount单位不匹配

`daily_cache` 中 `amount` 字段的单位是**千元**（Tushare标准），但 `_filter_low_liquidity` 中：

```python
# screener.py:122
avg_amount = data['amount'].tail(20).mean()
if avg_amount < 10000000:  # ← 注释写"1000万"但实际检查的是 100亿
    return False
```

- `amount` 单位：千元 → `avg_amount = 888,789`（平安银行）
- 阈值 `10,000,000` 千元 = **100亿元**日均成交额
- 只有贵州茅台/宁德时代等极少超级大盘股超过此阈值
- **正确阈值应为 `10,000`**（千元）= 1000万元（符合注释意图）

**后果**：市场中97.5%的股票因这个单位不匹配在L1被剔除。如果修复，L1通过数应约4,093只（与你的预期一致）。

## 问题2：L2 未发挥筛选作用

### 当前逻辑

```python
# screener.py:200-211
for symbol in l1_passed:           # 遍历所有 L1 通过者
    s = scorer.score(df)            # ChipScorer 评分 0-10
    if s > 0:                       # 极低门槛 — 几乎所有股票 score > 0
        scored.append(...)
l2_top = scored[:100]               # 截断前100
```

当前 L2 对所有86只L1通过者评分，score>0=99.8%，所以全部保存在内存中，再 `[:100]` 一网打尽。

### ChipScorer 评分测试（1000只抽样）

| 评分阈值 | ≥该分占比 | 说明 |
|---------|----------|------|
| ≥ 3分 | 99.8% | 几乎全部通过 |
| ≥ 5分 | 95.1% | 区分度低 |
| ≥ 7分 | 44.9% | 有区分度 |
| ≥ 8分 | 8.5% | 高度精选 |

**问题**：L2的score>0门槛形同虚设。当前（只有86只L1输入的情况下）等于全部透传。ChipScorer的评分范围 2-10 分均值为 6.6，**没有设置有效的候选阈值**，因此L2不发挥筛选作用。

### ChipScorer 四维评分体系合理度

| 维度 | 分项 | 合理性 |
|------|------|--------|
| ① 成本位置(0-3) | VWAP(120)偏离度 | ✅ 合理 — 判断主力成本区 |
| ② 量能剖面(0-3) | 低位/高位+量比 | ✅ 合理 — 判断建仓/出货 |
| ③ 趋势健康(0-2) | 均线排列方向 | ✅ 合理 — MA5/MA20/MA60 |
| ④ 价格稳定(0-2) | 波动率+价格位置 | ✅ 合理 — 吸筹特征识别 |

评分体系本身设计合理，但**缺少实际筛选门槛**。L2应筛选出主力关注的股票，合理做法是设置阈值（如≥7分）或按评分排名截断。

### L3 评级映射保守度

```python
def _score_to_grade(score):
    S: ≥8    A: ≥7    B: ≥5.5    C: ≥4    D: <4
```

| 评级 | 条件 | 解读 |
|------|------|------|
| S (🔥强烈推荐) | 综合评分≥8 | 需要VP和CL都高分+方向一致 |
| A (✅推荐) | 综合评分≥7 | VP或CL一方高分+另一方中性 |
| B (👀关注) | 综合评分≥5.5 | 中等信号 |
| C (⚠️谨慎) | 综合评分≥4 | 微弱信号 |
| D (❌回避) | 综合评分<4 | 无明显信号 |

修复VP后，评级从 "C=2只/D=8只" 变为 "B=5只/C=5只/D=0只"，分布合理了。但整体偏保守，缘于：
1. 缠论天然保守 — 无明确买卖点时 base=5.0，靠买卖点数累加减
2. 等权重(50/50) + 方向一致性+1分 — 要求两个策略都看好
