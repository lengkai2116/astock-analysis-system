## 二、只读核查结论（2026-09-26，探针 + 生产库实证）

### 2.1 数据源可用性（Tushare 实探，600519 验证）
- **`pledge_stat` ✅**：608 行/周频（end_date=20260918），列 `ts_code/end_date/pledge_count/unrest_pledge/rest_pledge/total_share/pledge_ratio`（茅台 pledge_ratio=0.06%）。
- **`stk_holdertrade` ✅**：16 条，列 `ts_code/ann_date/holder_name/holder_type/in_de/change_vol/change_ratio/after_share/after_ratio/avg_price/total_share`（in_de=IN 增持/DE 减持）。
- **`cashflow` 折旧列 ✅**：`depr_fa_coga_dpba`（固定资产折旧等，茅台 1.02e9 元）、`c_pay_acq_const_fiolta`（购建固定资产等支付的现金=capex，茅台 8.3e8 元）。
- **`fina_indicator` 空壳列 ✅ 可取**：roic/roa/ebit/gross_margin 全字段返回有值（茅台 roic=16.37/roa=19.97/ebit=6.1e10）；**`roce` 非 fina_indicator 字段**（请求即报错，473 用 EBIT/净资产近似正确）。
- **行业 ✅ 已就绪**：app.db `stocks.industry` 东财行业 5543/5547；477 已建 `INDUSTRY_CATEGORY` 七类映射（含东财名兼容）。
- **积分权限**：质押/增减持属「参考数据」需 **3000 积分**，当前 token 5000 分（033 报告 + provider 注释双证）。

### 2.2 生产库现状（关键，含两处根因升级）
- **`cashflow_cache.cashflow_oper/inv/fin` 恒 NULL（76878 行 / 0 非空）**——⚠️ **根因升级**：Tushare 返回列名为 `n_cashflow_act`/`n_cashflow_inv_act`/`n_cash_flows_fnc_act`，`cache_cashflow_data` 无列名映射（income/balancesheet 均有 _COL_MAP）→ 经营现金流/投资/筹资三列从未落库。**消费端 `valuation_estimator:749`、`event_monitor:270`、`dim7:684` 读 `cashflow_oper` 的 OCF 逻辑实际从未生效**（与 473 roce=0.0 假值同型静默退化）。free_cashflow 有值（61491）不受影响。
- **fina_indicator roic/roa/gross_margin 空壳**（22427 行中仅 ~224 有值）：**根因三层**——(a) `provider.get_fina_indicator` 用 `FINA_FIELDS_ORIGINAL`（11 基础字段，无 roic/roa/ebit）；(b) `_batch_fina_indicator` 方案2 `stock_codes[:100]` 恒取前 100 只 + 428 P1-1 跳过 → **每季度只有前 100 只拿到新报告期**（224 行 roic 全为 000xxx 早期代码实证吻合）；(c) 5574 只覆盖来自 426 时代 backfill_all.py（字段集不含 roic）。(b) 已本号修复为全量遍历未覆盖累计 100。
- **`FINA_FIELDS_EXTENDED` 混入 6 个非 fina_indicator 字段**（roce/operating_profit/total_assets/total_liab/current_assets/current_liab）→ finance_report_cache 对应列恒 NULL。
- **`gross_margin` 语义陷阱**：Tushare fina_indicator 该字段为**毛利额（元）非毛利率%**（茅台 2026H1=8.12e10≈收入 889 亿×91.4% 验证）——watchlist 当比率展示，**禁止回填**，已在字段集注释登记。
- **balancesheet_cache.current_liab 已就绪**（72034 行 / 44015 非空）+ 474 已切标准 ROCE（EBIT/(总资产-流动负债)）→ **473 挂账数据侧已满足，无需再动**。
- 全库无 `pledge_stat_cache` / `stk_holdertrade_cache` 表。

### 2.3 消费端占位现状
- `event_monitor.py:310/316`：`_detect_pledge_risk`/`_detect_holder_reduce` 返回「未采集」（已注册于 detector 表 :826-827）。
- `dim4_chip_fund_engine.py:4704` + `chip_pre_filter.py:820`：`_check_industry_risk` 双份恒 `{'passed': True, ...}`。

## 三、子项划分与处置设计

### 484-1｜质押采集（448 R①）
- **新表** `pledge_stat_cache`（分库 history_cache.db，与 stk_holder/top10_holders 同族；sharding_manager 加映射 + DDL + `_NUMERIC_COLUMNS`）。
- **采集** `_batch_pledge_stat`：先按 `end_date` 批量补最近 N 期（周频）+ 441 D 通道②式**按股覆盖巡检**挂 `_COVERAGE_RECONCILE`（防批量漏采）。
- **接线** `event_monitor._detect_pledge_risk`：读 pledge_stat_cache 最新期，`pledge_ratio > 50` → detected（direction<0，语义对齐 448 B2 注释「质押>50%」）。
- **回填**：全市场按股覆盖。

### 484-2｜减持采集（448 R②）
- **新表** `stk_holdertrade_cache`（history_cache.db）。
- **采集** `_batch_stk_holdertrade`：按 ts_code 采集（ann_date 维度，近 1 年窗口）+ 覆盖巡检。
- **接线** `event_monitor._detect_holder_reduce`：读该表近 90 日 `in_de='DE'` 记录 → detected（direction<0，减持预披露/已减持）。
- **回填**：全市场。

### 484-3｜行业风险接线（448 I/S）
- **数据**：`stocks.industry`（东财）+ 477 `INDUSTRY_CATEGORY` 七类（蓝筹/成长/周期/金融/防御/稳定收息/微小亏损）。
- **接线**：`_check_industry_risk` 双份（dim4 + chip_pre_filter）改读 `stocks.industry` → 产 `{'passed': bool, 'reason', 'detail'}`。**判定规则待拍板**（见 §五-③）。

### 484-4｜FCF 折旧列 + cashflow 列名映射修复（449 ④ + 根因）
- **DDL/分库加列**：`cashflow_cache` 加 `depr_fa_coga_dpba REAL, c_pay_acq_const_fiolta REAL`（ALTER 分库 + 总库 DDL 同步 + `_NUMERIC_COLUMNS`）。
- **列名映射修复（根因）**：`cache_cashflow_data` 补 `_CF_COL_MAP = {'n_cashflow_act': 'cashflow_oper', 'n_cashflow_inv_act': 'cashflow_inv', 'n_cash_flows_fnc_act': 'cashflow_fin'}`（对齐 income/balancesheet 先例）——**修后 OCF 消费（估值 OCF/营收、事件 fraud 经营现金流负、FCF 口径）首次真正生效**。
- **补采回填**：复用 `_batch_cashflow`（映射生效后重写最新期即可，无需全历史）。
- **接线**：`_anchor_cashflow` 双侧（dim7 `:489` + valuation_estimator `:501`）改「经营资产FCF = cashflow_oper − depr_fa_coga_dpba（折旧近似保全性资本支出）」；`fcf` 缺失时回退 `free_cashflow`（保持降级不阻塞）。**判定数值变化 → 走 StatusEngine 全链路验证**（449 口径已拍板，实施时验证）。

### 484-5｜空壳财务列扩采 + 标准 ROCE 升级（472/473 挂账，可选纳入）
- **FINA_FIELDS 扩采**：`FINA_FIELDS_EXTENDED` 修正——移除非 fina_indicator 字段（current_liab/operating_profit/total_assets/total_liab/current_assets），补 `roic/roa/gross_margin`；`_batch_fina_indicator` 方案2 改走扩展字段集 → fina_indicator_cache 回填 roic/roa/gross_margin/ebit。
- **标准 ROCE 升级**（数据已备）：生产端 `roce = ebit/(total_assets−current_liab)`（ebit←fina_indicator，total_assets/current_liab←balancesheet），替换 473 的 EBIT/净资产近似——**属判定数值变化，随本子项走全链路验证**。
