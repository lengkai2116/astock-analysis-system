# 估值体系修正方案

## 一、背景与问题（源自 314 号核查）

2026-08-05 核查（314 号）发现估值体系存在系统性误判：**全市场 55.2% 股票被判"偏高"（high）**，但数据铁证显示这些股票的 PE/PB 历史分位仅 28-36%（中低区间，非真实高估）。唯一真实高估的"极度高估"档（61 只）历史分位 78-92%。

根因链：

```
现金流锚（锚3）基准利率固定 2.5%（2022 年前水平，2026 实际约 1.6-1.8%）
  → spread = FCF/EV − 2.5 系统性低估约 0.8-0.9
  → 锚3 全市场打负（high 股均值 -1.93，逼近极端 -2）
  → composite 被拖低 → 大量股票落入 high 档
  → L4 估值门禁（high 直接不推荐）→ 弹窗"蓝色可入 vs 不推荐"矛盾
```

叠加问题：
- **P2**：level 分档用 composite 绝对阈值（>1.0/0.3/-0.3/-1.0），偏离 416 号设计意图（截面百分位 5/20/80/95）
- **P3**：缺 PB-ROE 质量联动（高 ROE 支撑高估值，主流框架标配）
- **P4**：锚权重静态固定（0.10-0.45），无 IC 检验与动态调整
- **P5**：无行业相对估值与生命周期维度（成长股高估值被一刀切）

## 二、修正目标与原则

1. **目标**：level 分布合理（对齐设计：extreme_low≤5% / low 5-20% / fair 20-80% / high 80-95% / extreme_high>95%），"偏高"判定反映真实高估（历史分位 >60%），消除现金流锚的系统性偏误
2. **原则**：
   - 不改变 deviation 语义（deviation = composite×20，正=低估/负=高估——313 潜力引擎与前端依赖）
   - 保持四锚框架与行业权重（结构合理，修正执行层缺陷）
   - 分阶段实施（先解决影响最大的利率校准，再重构分档，避免一步到位的高风险改造）
   - 每阶段有明确验证标准与回滚方案

## 三、阶段 1：无风险利率校准 + level 分档重构（核心）

### 3.1 无风险利率配置化

**现状**：`valuation_estimator.py:25 CN_10Y_BOND_YIELD_PCT = 2.5`（硬编码常量）

**修改**：
- 改为模块级可配置：`CN_10Y_BOND_YIELD_PCT = float(os.getenv('CN_10Y_BOND_YIELD', '1.7'))`
- 默认值 **1.7**（2026 年中国 10Y 国债实际收益率区间 1.6-1.8% 的中值；配置化便于后续动态更新）
- 写入 `.env.example` 与 `.env`（CN_10Y_BOND_YIELD=1.7）
- 副作用检查：该常量仅锚3 使用（L280 spread = fcf_yield - CN_10Y_BOND_YIELD_PCT），无其他引用

**预期影响**：锚3 spread 整体 +0.8 → 锚3 评级上移约 1 档 → composite 上移（锚3 权重 0.10-0.35 依行业）→ high 占比预计从 55% 降至约 30-40%

### 3.2 level 分档重构（对齐 416 号百分位设计）

**现状**：`L503-512 composite 绝对阈值分段`

**方案 A（推荐，渐进）**：先校准利率重算分布，评估是否仍需分档重构：
- 若校准后 high 占比 ≤ 40%（且 high 股 PE 历史分位均值 >50%），维持 composite 绝对分档（简单、可解释）
- 若 high 仍 >40%，执行方案 B

**方案 B（百分位分档，需要时启用）**：
- ValuationEngine 增加截面基准构建（仿 potential_engine.build_percentile_tables）：
  - `build_composite_percentile(ecm)`：全市场 composite 排序表（precompute 前调用一次）
  - `compute_tags` 内：查该股 composite 的截面百分位 → 分档
- 分档边界（对齐 416）：`pct≤5 → extreme_low / ≤20 → low / ≤80 → fair / ≤95 → high / else extreme_high`
- 百分位化后：high 恒为截面 15%（80-95 分位），extreme_high 恒 5%——分布天然稳定，与市场冷热解耦（相对估值语义）
- deviation 保持 = composite×20（绝对偏离连续值，不变——313 潜力引擎/前端展示零影响）
- 注意：百分位化后"偏高"=相对市场偏高（市场整体贵时，相对不贵的股票也会 high）——语义从"绝对贵"变为"相对贵"，需在方案文档与前端 tooltip 标注"估值水平为市场相对分位"

**决策点**：实施阶段 1 时，先跑校准后分布统计，按 3.2 方案 A 的判定条件决定是否启用方案 B。

## 四、阶段 2：PB-ROE 质量联动（补质量修正）

**现状**：composite 纯四锚合成，无 ROE 参与（high 股平均 ROE -0.4%，质量与估值解耦）

**修改**（valuation_estimator.compute_tags，在 L500 composite 计算后加质量修正）：
```
if fina_health == 'pass' 且 ROE > 12%:
    composite += 0.25 * min(1.0, ROE/20)      # 高 ROE 质量溢价（容忍更高估值）
elif fina_health == 'fail':
    composite -= 0.5                            # 财务风险惩罚（低估值也打折）
```
- 阈值 12%/20 与修正量 0.25/0.5 为初值，可配置（QUALITY_ADJUST 常量）
- ROE 数据源：fina_indicator_cache（compute_tags 内可复用 _fina_health 的 df_fina）
- **预期**：高 ROE 白马（如白酒/家电）从 high 回归 low/fair；亏损股 high 判定不受影响（反向正确）
