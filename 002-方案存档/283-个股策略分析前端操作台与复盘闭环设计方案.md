# 个股策略分析前端重设计 — 操作台+现状卡片+策略建议+实操建议

> 本设计在275号方案基础上，重新聚焦于用户视角的直观性，增加科技感操作台组件、优化股票现状展示的可读性、强化策略建议的可操作性、建立与复盘中心的实操闭环。

### 设计原则

| 原则 | 说明 |
|:----|:------|
| **科技感操作台** | 顶部常驻控制面板，类似飞行驾驶舱风格，所有策略选择+运行入口集中 |
| **现状即主体** | 股票现状卡片占页面最大面积，大字体、结构清晰，用户一眼看懂 |
| **建议即行动** | 策略建议明确到价位（止损/止盈/仓位/持有期），不模糊 |
| **实操闭环** | 每条建议都可直接加入复盘池进行虚拟验证，形成"分析→操作→验证→改进"循环 |

## [S2] 操作台 STRATEGY CONSOLE 详细设计

### 定位与视觉风格

位于K线图下方，全宽横向面板。**半透明玻璃态 + 霓虹边框**，营造科技感：

```
┌────────────────────────────────────────────────────────────────────┐
│  STRATEGY CONSOLE                                v2.0.1  ⚡ ONLINE │
│ ───────────────────────────────────────────────────────────────    │
│  ┌── 系统策略 ──────────────────────────────────────────────────┐  │
│  │ ◉ 缠论走势  ◉ 量价形态  ◯ 筹码资金  ◉ 情绪周期  ◉ 多因子   │  │
│  │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░░░░░░░░░ [5/5选中]   │  │
│  └──────────────────────────────────────────────────────────────┘  │
│  ┌── 因子组合 ────── 选中: 1 ─────────────────────────────┐  │  │
│  │ [A股核心五因子]  短线动量 █  价值防御 █  M8精选 █     █ +  │  │
│  └─────────────────────────────────────────────────────────┘  │  │
│  ┌── Vibe 策略 ────── 选中: 0 ──────────────────────────────────┐│
│  │  暂无选中Vibe策略    [创建Vibe策略] [管理Vibe策略]           ││
│  └──────────────────────────────────────────────────────────────┘│
│                                                                 │
│  ⚙ 高级设置  █████████████████████████████████  ▶ 运行分析      │
│  [Kronos AI] 开启  |  从选股系统同步权重  |  保存为默认          │
└────────────────────────────────────────────────────────────────────┘
```

### 三大策略选择区

| 区域 | 内容 | 数据来源 |
|:----|:-----|:---------|
| **系统策略** | 缠论/量价/筹码/情绪(BOCIASI)/因子 — 5个toggle按钮 | 后端固定5策略 |
| **因子组合** | 系统预设组合(PRESET_COMBOS中的p1-p10) + 用户自定义组合 | `GET /api/factors/combinations?filter_type=all` |
| **Vibe策略** | 用户自建Vibe策略列表 + 创建入口 | `GET /api/v3/screener/strategies/vibe` |

### 交互状态

| 状态 | 运行按钮 | 策略选择 |
|:----|:---------|:---------|
| 未分析 | `▶ 运行分析` 蓝色高亮 | 可切换 |
| 分析中 | `🔄 分析中...` 旋转动画+禁用 | 禁用点击 |
| 已完成 | `🔄 重新分析` 蓝色高亮 | 可切换 |
| 切换股票 | 状态复位为「未分析」 | 策略选择**保留** |

### 持久化规则

- 策略选择变更→存入 `localStorage['strategy_console_config']`
- 切换股票时策略选择不重置
- 因子组合和Vibe策略的选中状态同样持久化
- 页面刷新时从localStorage恢复全部选择

## [S3] 股票现状卡片 STOCK STATUS CARD

### S3.1 布局结构

取代275号方案的"默认折叠5行"设计。改为**两层展示**：

**上层：5格指标条（Dashboard Bar）**
```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ 信号共识  │ 市场情绪  │ 主力资金  │ 财务排雷  │ 数据完整度 │
│          │          │          │          │          │
│   看涨    │   复苏   │ ✦ 净流入  │   通过   │   4/5    │
│ 一致性4/5 │ 涨停23只  │ +1.2亿   │ ROCE>15% │ 80%完整  │
└──────────┴──────────┴──────────┴──────────┴──────────┘
```
- 每格2行：第1行大字核心值（如"看涨"用红色大号字），第2行补充说明
- 方向类数值带颜色编码（看涨=红 #f23645，看空=绿 #089981，中性=黄 #f0b90b）
- 数据不可用时灰色占位 `--`

**下层：DeepSeek九层深度解读（全展开，大字体）**
```
┌──────────────────────────────────────────────────────┐
│  📖 现状深度解读                                      │
│                                                       │
│  1.【环境定位】 上证处于日线级别震荡整理。所属         │
│     半导体板块为当前主线(板块指数+8.2%)，个股         │
│     近20日跑赢大盘4.3%，板块内强度排名前15%。         │
│                                                       │
│  2.【走势结构】 日线级别上升趋势中出现背驰信号。       │
│     价格处于中枢(18.83-29.87)上方(+39.4%)，60分钟     │
│     级别未形成有效结构，短期内需关注...                │
│                                                       │
│  3.【筹码成本】 筹码峰集中在24.5-26.0区间，主力       │
│     集中价24.2元，当前价41.63偏离+72%...              │
│  ...                                                  │
│  (有数据则写，无数据跳过)                              │
│                                                       │
│  [📋 复制全文]  共687字                               │
└──────────────────────────────────────────────────────┘
```
- 字体比常规正文大 1.2×（`font-size: 16px` vs 常规 `14px`）
- 每层之间用分割线隔开，层次清晰
- 层标题用特殊标签色块（如【走势结构】用蓝色标签）
- 无数据维度**不显示空标题**，减少视觉噪音

### S3.2 降级策略

| 场景 | 展示内容 |
|:----|:---------|
| DeepSeek 可用 | 九层结构化文本 | 
| DeepSeek 不可用 + status_text | fallback_description() 三要素文本，标注「系统规则描述」 |
| 无任何文本 | "数据不足以生成现状描述" 灰色占位 |

## [S5] 实操建议 ACTION PLAN — 复盘中心闭环

### S5.1 与复盘中心的关联设计

这是本方案与275号方案最大的差异点。**每条实操建议不是"静态文本"，而是可以进入复盘中心虚拟验证的一个操作单元**。

```
分析完成 → 生成实操建议 → 【加入复盘池】 → 复盘中心虚拟验证
                              ↓
                         回顾验证结果
                              ↓
                         修正策略配置
                              ↓
                         再次分析（闭环）
```

### S5.2 实操建议卡片

```
┌─────────────────────────────────────────────────────────┐
│  实操建议    基于当前分析结果，建议的操盘计划            │
├─────────────────────────────────────────────────────────┤
│  ┌── 情景 A：趋势延续（概率 60%） ─────────────────┐   │
│  │  ① 当前价 ≤22.0 建仓 30% 底仓                    │   │
│  │  ② 放量突破 29.87 加仓至 50%（确认趋势）         │   │
│  │  ③ 持有至 32.00 减仓 50%，余仓跟随均线           │   │
│  │  ④ 跌破 25.00（MA20）全部离场                   │   │
│  └──────────────────────────────────────────────────┘   │
│                                                         │
│  ┌── 情景 B：冲高回落（概率 30%） ─────────────────┐   │
│  │  ① 若放量冲高回落（上影线>3%），不开新仓         │   │
│  │  ② 已持仓者在 29.87 附近减仓至 20%               │   │
│  └──────────────────────────────────────────────────┘   │
│                                                         │
│  ┌── 情景 C：破位下行（概率 10%） ─────────────────┐   │
│  │  ① 跌破 18.83（中枢下沿）立即止损                │   │
│  │  ② 等待 60 分钟级别底背驰出现后再入场            │   │
│  └──────────────────────────────────────────────────┘   │
│                                                         │
│  ════════════════════════════════════════════════════    │
│  [▶ 加入复盘池] [📋 虚拟开仓·情景A] [📊 查看复盘中心]    │
└─────────────────────────────────────────────────────────┘
```

### S5.3 加入复盘池的数据映射

当用户点击「加入复盘池」时，当前分析结果映射为复盘条目：

| 复盘条目字段(ReviewUnit) | 来源 |
|:------------------------|:-----|
| `ts_code`, `name`, `sector` | 当前股票基本信息 |
| `snapshot_date` | 分析日期 |
| `base_price` | 策略分析时的最新收盘价 |
| `strategy_config` | 操作台的策略选择配置 |
| `dimension_outputs` | E12 五个维度的完整输出 |
| `cross_verify` | E13 status-aggregate 验证链结果 |
| `arbitration` | E14 AI仲裁/建议结果 |
| `practical_ref` | 实操建议卡片内容（情景A/B/C+关键价位） |
| `direction`, `confidence` | 策略建议的主信号和置信度 |
| `stage` | 初始为 `pending`（待执行） |

### S5.4 虚拟开仓验证流程

点击「虚拟开仓·情景A」后：

1. 后端创建 `PlaybackAccount` 快照（记录当日账户状态）
2. 创建 `ReviewUnit` 条目（绑定选定的情景计划）
3. 后端启动虚拟价格跟踪（基于后续行情数据）
4. 用户可在复盘中心查看该虚拟持仓的实时盈亏、最大回撤、是否触发止损/止盈
5. 回测结束后，七维复盘引擎自动生成诊断报告

## [S6] 交互时序

```
用户进入页面
  → K线图 + 行情面板显示默认股票
  → 操作台：策略选择 ← localStorage持久化配置
  → 状态：【未分析】▶ 运行分析 可点击

用户切换策略（可选）
  → toggle选中/取消
  → 策略进度条更新（如 [3/5选中]）
  → localStorage保存

用户点击 【▶ 运行分析】
  → 按钮变为 🔄 分析中...（禁用）
  → 并行请求 E12 + E13
  → 完成后自动请求 E14（如LLM可用）
  → 填充：
     ① 股票现状卡片（5格指标条 + 九层描述）
     ② 策略建议（四象限卡片）
     ③ 实操建议（情景A/B/C + 加入复盘池入口）
  → 按钮变为 🔄 重新分析

用户切换股票
  → K线图 + 行情面板刷新
  → 策略选择不变（从localStorage恢复）
  → 分析结果区清空 → 回到【未分析】状态
  → 显示「切换至 XXX——点击运行分析获取最新结果」提示

【加入复盘池】
  → 确认弹窗：选择附加备注
  → 调用 POST /api/v3/playback/entries
  → 成功后Toast通知 + 复盘中心角标更新

【虚拟开仓·情景A】
  → 确认弹窗：展示情景A具体操作计划
  → 调用 POST /api/v3/playback/entries + 标记为虚拟开仓
  → 跳转到复盘中心或Toast通知
```

## [S7] 暂不处理的事项

| 事项 | 原因 |
|:----|:------|
| 多周期切换（短/中/长线） | 后端分钟数据就绪但用户感知尚未验证，后续迭代 |
| 收益驱动维度（九层⑥） | 后端数据管道未就绪(0%) |
| 单页应用化(Vue/SPA) | 维持现有原型HTML + vanilla JS架构 |
| 回测验证直接集成 | 属于复盘中心二期功能，当前仅做数据输入 |

| 275号方案原有设计 | 本方案变更 | 原因 |
|:-----------------|:-----------|:-----|
| 策略工具栏(常驻badge) | → 升级为操作台(科技感+因子+Vibe整合) | 增加因子组合和Vibe策略选择入口 |
