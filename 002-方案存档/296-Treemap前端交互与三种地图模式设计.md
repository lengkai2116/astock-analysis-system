# Treemap 前端交互与三种地图模式设计

## 一、技术选型

- **可视化库**：ECharts 5.x Treemap（已有原型验证可行）
- **数据来源**：`/api/v3/opportunity-atlas/treemap`（盘前就绪，约 4800 只）
- **盘中价格**：30s 轮询，仅影响市场地图颜色
- **原型起点**：`_ui-prototype/opportunity-treemap.html`
- **方块大小依据**：以下三种模式中，机会地图的大小依据为"信号强度"（`signal_strength`，0-10 的聚合值，反映多个信号源的一致性程度），**非预测性评分**

## 二、三种地图模式（最终定版）

### 📊 市场地图

| 要素 | 规则 |
|------|------|
| 外层分组 | 申万一级行业 |
| 方块大小 | 流通市值（行业内比较） |
| 方块颜色 | 涨跌幅（红=跌、绿=涨，越深幅度越大） |
| 用户视角 | "今天市场怎么样？" |

### 🎯 机会地图

| 要素 | 规则 |
|------|------|
| 外层分组 | 申万一级行业（不变） |
| 方块大小 | **信号强度**（`signal_strength`，行业内比较，强度越高方块越大） |
| fallback | `signal_strength` 在 P0.4 预计算就绪（详294号§三）。若盘中临时缺失或 P0.4 尚未完成（P1.3 独立开发阶段），fallback 顺序：`phase_confidence` → `main_force_phase` 映射值(building=7, lifting=6, washing=5, distributing=2, unknown=3) → 统一大小(行业均值)。**P0.4 完成前**：后端的 Treemap API（P1.4）应返回一个 `signal_strength_fallback: true` 标识，告知前端当前使用的是 fallback 值而非真实 signal_strength。前端在机会地图标题栏增加"⚠ 信号强度 Fallback"角标提示用户。 |
| 方块颜色 | 机会类型 = 持有周期 |
| 用户视角 | "每个板块里机会在哪、是什么类型的？" |

**颜色映射**：

```
🔵 蓝 = 长线机会（>6个月）
🟢 绿 = 中线机会（1-6个月）
🟠 橙 = 短线机会（1-4周）
🔴 红 = 超短/做T（1-5天）
⬜ 灰 = 无明确信号
```

### 💎 价值地图

| 要素 | 规则 |
|------|------|
| 外层分组 | 申万一级行业（不变） |
| 方块大小 | 前收盘价（行业内比较） |
| 方块颜色 | 估值偏离度 |
| 用户视角 | "每个板块里哪些贵了哪些便宜了？" |

**颜色映射**：

```
🟢 深绿 = 深度低估（偏离度 < -20%）
🟢 浅绿 = 低估（-20% ~ -10%）
⬜ 灰色 = 合理（-10% ~ +10%）
🔴 浅红 = 偏高估（+10% ~ +20%）
🔴 深红 = 高估（> +20%）
```

## 三、交互三能力

### 能力一：模式切换（简化）

右上角三个按钮，切换时行业分组不变，大小和颜色重算（ECharts 300ms 动画过渡）。

### 能力二：悬停浮窗（按模式区分）

三种模式的悬停浮窗内容完全不同，各自回答该模式下用户最关心的问题。

##### 📊 市场地图 — 浮窗回答"今天什么情况？"

```
┌─ 西藏矿业 ─────────────────────────┐
│  现价 28.50                        │
│  ▲ +2.35%    换手率 3.2%           │
├────────────────────────────────────┤
│  开盘 27.85  最高 28.80  最低 27.60 │
│  成交 3.2亿  振幅 4.3%              │
├────────────────────────────────────┤
│  所属板块: 有色金属  ▲ +1.8%        │
│  PE: 32.5  市值: 128.5亿           │
├────────────────────────────────────┤
│  👆 点击查看个股诊断                │
└────────────────────────────────────┘
```

内容全部为当日交易数据，不涉及标签/阶段/估值。

##### 🎯 机会地图 — 浮窗回答"这是什么机会？"

```
┌─ 西藏矿业 ─────────────────────────┐
│  📊 信号强度 7.5  🟢 中线 1-6月    │  ← 核心：信号聚合值+持有周期
├────────────────────────────────────┤
│  方向: ↗ 趋势向上  📊 均线多头     │
│  位置: 💎 估值偏低  📍 区间中位   │  ← 四大标签组摘要
│  质量: 🏗️ 主力建仓  💰 机构主导   │
│  环境: 🌤️ 情绪复苏  🔥 板块前10   │
├────────────────────────────────────┤
│  👆 点击查看完整诊断               │
└────────────────────────────────────┘
```

信号强度为 0-10 的聚合值，反映主力阶段、估值水平、趋势方向等多个信号源的一致性程度。**非未来涨跌预测，仅为当前信号的聚合评估。**

##### 💎 价值地图 — 浮窗回答"贵不贵？为什么？"

```
┌─ 平安银行 ─────────────────────────┐
│  现价 11.20  │  +0.45%             │
├────────────────────────────────────┤
│  💎 估值定位: 低估                  │
│  估值偏离度: -18%（低于合理中轴）   │
├────────────────────────────────────┤
│  PE 5.8  │ 近5年分位 12%            │
│  PB 0.62 │ 近5年分位 8%             │
│  股息率 5.2%                        │
│  行业中位数 PE 6.5 → 折价 11%      │
├────────────────────────────────────┤
│  合理估值区间: 14.2 - 18.5          │
│  当前价 11.2  → 低估 21%            │
├────────────────────────────────────┤
│  👆 点击查看完整诊断                │
└────────────────────────────────────┘
```

展示估值证据链，让用户自行判断估值结论是否可信。

### 能力三：标签筛选栏

```
[ 📊 全市场(4800) ]  [主力建仓(42) ✕] [估值偏低(156) ✕]  [+选择标签▾]

预设场景: [📋 价值低估] [📋 主力跟庄] [📋 短线催化] [📋 做T机会]

当前筛选: 主力建仓 ∩ 估值偏低 = 18 只
```

- 多标签 = AND 交集
- 预设场景 = 预置的标签组合，点击自动勾选
- 支持用户保存自定义场景

**UI 约束**：常驻标签按钮（15个，详见295号§6.3）+ 预设场景（4个）+ 搜索框 + 全市场计数标签。1280px 宽度下建议最多展示 8-10 个标签按钮，其余折叠在"+更多"菜单中；低于 1024px 时自动减少常驻展示数至 5 个，预设场景改为下拉菜单。

### 能力四：点击弹窗（统一完整诊断）

三种地图模式下点击任一方块，弹出统一的完整诊断窗。内容不分模式，用户一次看全。

**弹窗格式**：

```
┌─────────────────────────────────────────────────┐
```

**五个内容区块**：

| 区块 | 内容 | 数据来源 |
|------|------|---------|
| 标题栏 | 名称/代码/行业/现价涨跌/信号强度/持有周期 | L1实时 + 标签池 |
| 仲裁结论 | 交叉验证结果+一致性等级 | L4 仲裁层（300号方案§2.2） |
| 四行标签 | 方向/位置/质量/环境各展开2-3项 | L3 标签池 |
| 估值详情 | PE/PB分位/股息率/行业对比/合理区间 | 估值引擎（297号方案） |
| 操作建议 | 建议类型+分批计划+止损目标 | L4 仲裁层（300号方案§2.3） |
| 风险提示 | 行业风险/公司风险/冲突信号 | L2 标签池 + 仲裁层 |

**底部操作栏**（三个功能按钮）：

| 按钮 | 触发动作 | 关联系统 |
|------|---------|---------|
| 📋 加入自选 | 写入自选列表（默认 level=scan） | 自选系统（299号方案） |
| 📈 策略分析 | 跳转到现有个股策略分析页面（K线+五维） | 已有功能 |
| 🤖 AI投研 | 跳转到现有 AI 多角色投研页面 | 已有功能 |

**交互行为**：

| 行为 | 效果 |
|------|------|
| 点击弹窗外背景 | 关闭弹窗 |
| ESC 键 | 关闭弹窗 |
| 弹窗高度超过视口 | 弹窗内滚动，不影响下方 Treemap |
| 分辨率 < 768px | 弹窗全屏展示 |
| 分辨率 ≥ 768px | 居中弹窗 + 半透明背景遮罩 |

**小方块点击保障**（ECharts 配置）：

| 措施 | 配置项 | 效果 |
|------|--------|------|
| 绝对最小尺寸 | `minSize: 12` | 所有方块至少 12×12 px，可识别 |
| 缩放能力 | `roam: true` | 用户可滚轮缩放，双击行业放大后点击 |
| 搜索入口 | 页面顶部搜索框 | 直接输入代码进入诊断，不受方块大小限制 |

## 四、后端 API

```
GET /api/v3/opportunity-atlas/treemap?mode=market|opportunity|value
→ {
    sectors: [
      { name: "新能源", children: [
        { name: "宁德时代", ts_code: "...", value: 大小, color: "#...",
          tags: { direction: {...}, position: {...}, ... } }, ...
      ] }
    ]
  }
```

- `mode=market`：value = 流通市值，color = 涨跌幅
- `mode=opportunity`：value = **signal_strength**（信号强度），color = 时间周期
- `mode=value`：value = 前收盘价，color = 估值偏离度

标签筛选通过客户端过滤实现（全量数据下发给前端，ECharts 可处理 5000 节点）。
