## 一、问题一：`dims={}` 联动复原（删残留/引擎自产）

**根因**：`_build_dim_engine_results`（`status_engine.py:217`）把调用方传入的 `dims`（`data_daemon.py:5962`、`status_engine.py:89` 均传空 `{}`）直接塞给各维引擎 `evaluate`。引擎内残留对旧 dims 格式的读取，空 dims 逼成默认值。

### 1.1 污染点与修复落点

| 位置 | 当前读取 | 空 dims 后果 | 修复（A1 自产） |
|---|---|---|---|
| dim2:140 `struct_state = dims.get('structure',{}).get('state','盘整')` | 本维旧结构态 | 恒"盘整" | 由 `chanlun_result.trend`（up/down/unknown）映射 上升/下降/盘整，无缠论回退 `tags.state_label` 或"盘整" |
| dim2:155 `light = dims.get('structure',...).get('light','yellow')` | 本维旧灯色 | 恒"yellow" | 由自产 struct_state 派生（上升→green/下降→red/其他→yellow）——**注：灯色迁移归 439-A，此处仅保证不因空 dims 恒黄** |
| dim2:159 `'position': dims.get('position',...).get('state','中位')` | 他维 position | 恒"中位" | 改 `tags.get('price_position','中位')` |
| dim3:4572 `vp_state = dims.get('vp',{}).get('state','中性')` | 本维旧量价态 | 恒"中性" | 引擎已自产 `sl`（强健康/健康/中性/弱/严重背离）→ 直接 `vp_state = sl`（见 dim3:4677） |
| dim3:4603 `dims.get('vp',...).get('evidence')` | 本维背离证据 | dp=0 | 改用自产 `div_det`（dim3:4630） |
| dim5:317 `vp = dims.get('vp',{}).get('state','')` | **他维(dim3)量价态**（真实跨维联动） | 恒空→个股情绪恒"中性" | 在 `_build_dim_engine_results` 循环中**按序注入前序 volume_price 结果**，或改为读 `tags.volume_price_fit` 映射（见 §三 B 方案权衡） |

### 1.2 关键确认（引擎已自产真实状态，仅被空 dims 劫持）
- dim3 已自产 `sl`（评分等级 dim3:4658-4662），但 `judgment['state']` 却取被劫持的 `vp_state` → **只需把 vp_state 源从 dims 改为 sl**；
- dim2 已 import `TrendStructureDetector` / 有 `chanlun_result.trend` + `_assess_vs_*`（自产结构依据），仅 judgment.structure 走空 dims。
