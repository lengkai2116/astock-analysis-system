## 四、逐模块「多日说明」拆分设计（核心）

### ② 四大指数卡 —— 拆入「state 判定依据」（数据最充足 ✅）
- **现状**：miniK 20日只画图不说事；HS300 的 20/60 日、ma60 判定依据集中在末尾 ⑧ `market-state-line`
- **设计**：每指数卡下方补一行（或卡内角标）「近5日 +x% · 近20日 -y% · 站上/跌破 60日线」，4 指数各自一句
- **数据**：前端从 `mini_kline`（20日）自算近5/20日涨跌；60日线需后端补（daily_cache 88 行足够）
- **拆分**：⑧ 的 state 判定依据（HS300 20/60日、ma60）→ 移到 ② 指数区，末尾只保留状态标签汇总

### ③ 四大指数合计成交额 —— 「当日 + 近期趋势」✅
- **现状**：近20日柱状图 + 页头当日额/单日涨跌；趋势要自己看图
- **设计**：图表标题下补一句「当日 X 亿 · 高于/低于近5日均值 y%（放量/缩量）· 近20日高点 z 亿」
- **数据**：`market_volume.days[20]` + `average_amount` **完全现成**，纯前端

### ④ 全市场资金流向 —— 「多日趋势句」✅
- **现状**：近20日主力/散户图，无文字总结
- **设计**：补「主力资金连续 N 日净流入/流出 · 近20日累计主力净流入 ±X 亿（方向：震荡/持续吸筹/持续流出）」
- **数据**：`moneyflow_summary.days[20]` 现成（`moneyflow_cache` 59 日更足），纯前端

### ⑥ 板块 —— 板块热度可讲排名变化，板块净流入需后端
- **板块热度 Top（✅ 现成）**：`sector_heat_cache` 多日 → 补「热度榜首 X 较前日 +n 位 / 新进榜：Y」；数据现成
- **板块净流入（⚠️ 需后端）**：当前仅当日（`get_sector_moneyflow` 取最新交易日）；若做「板块近5日净流入趋势」需后端按 `moneyflow_cache` 59 日聚合新接口

### ⑧ 大盘状态面板 —— 拆解重排（核心）
- **state 判定依据** → 移 ② 指数卡（本就指数趋势）
- **市场宽度（涨跌家数 + ma20/涨停/换手）** → 可独立成「量价宽」说明，或并入 ③/① 组；讲多日宽度变化需后端暴露 `market_stats` 28 日序列（当前接口仅单日）
- **市场情绪（六段论+涨停生态）** → 与 ⑥ 板块/⑦ 涨跌榜呼应，讲情绪阶段演变（`sentiment_pool_cache` 15 日可用，需后端暴露历史阶段序列）
- **预警** → **仍聚合**（跨模块规则输出，天然汇总）

### ⑤ 散点 / ⑦ 涨跌榜 —— 维持单日说明
- 无历史快照（eod_snapshot）/ 榜单本为当日 → 多日不可行；保留「当日分布/当日榜单」说明，不做多日趋势

## 五、可行 / 不可行清单

**可行（多日说明）**：② 指数 / ③ 成交额 / ④ 资金流向 / ⑥ 板块热度 / ⑧ 的 state·宽度·情绪 —— 数据源已实证。
**不可行（维持单日）**：⑤ 日终散点 / ⑦ 涨幅·跌幅前十。
**需后端补口**：② 指数 60 日线统计（或前端只做 20 日）、⑥ 板块净流入多日聚合、⑧ 市场宽度历史序列、⑧ 情绪阶段历史序列。

### 批次1 实施记录（v1.1，2026-10-19）—— ②③④ 纯前端

- **③ 成交额**：图表标题下加 `#volume-trend-note`——「当日 X 亿 · 较近5日均值 ±y%（放量/缩量）· 近20日高点 z 亿」（`renderVolumeChart` 内，`data.slice(-5)` 均值，±20% 判放量/缩量/平量）。

- **验证**：JS 提取 `node --check` 通过；浏览器目检由用户起服后按模块核对。
