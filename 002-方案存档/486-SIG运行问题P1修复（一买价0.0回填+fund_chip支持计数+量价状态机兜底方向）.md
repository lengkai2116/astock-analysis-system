# 486号｜SIG 运行问题 P1 修复

> **定位**：承接 2026-09-26 SIG 全环节真实数据运行（8 股）发现的 P1 三件——全部为「展示/描述层缺陷 + 默认值退化」，不触碰任何「果」侧判定逻辑（445 冻结合规）。

## 一、P1 三件根因（已实证，勿重做）

### 486-1 一买/一卖价格恒 0.0（601318 实证）
- **现象**：601318 structure「一买(0.0)：下跌趋势背驰」；同股二买 47.3 正常。
- **根因**：`dim2_structure_engine.py:215` → `'price': float(_pos.get('price', 0) or 0)`——`_pos`（divergence.position）仅含 `idx` 无 `price` 键（465-2 只回填了 date，未回填 price）→ 兜底 0。
- **修复**：仿 `_resolve_bsp_date`（:358）新增 `_resolve_bsp_price(position, df)`：`price<=0` 且有 `idx` 时从 df 按 idx 反查 close 回填。

### 486-2 fund_chip「N维支持」恒为 1（600519/000002 实证）
- **现象**：600519 投票 5 项中 3 项投「出货」（资金流向0.80/趋势方向0.44/缠论买点0.60）却显示「1维支持」；000002 3 项投「拉升」同样「1维支持」。
- **根因**：生产侧 `vote_ratio["_supporters"] = {top: len(_supporters(top))}`（phase_detector.py:351 / dim4_chip_fund_engine.py:797）——**dict 单键** `{主导阶段: 支持维度数}`；展示侧 `dim4_chip_fund_engine.py:6089` 用 `len(_supp)` 取 **dict 键数（恒=1）**，应取**值**。
- **修复**：展示侧改为 `next(iter(_supp.values()))`（支持主导阶段的维度数）。

### 486-3 量价状态机「价涨量增(强势)」vs 形态「价跌量增」矛盾（600519 实证）
- **现象**：600519 当日收盘 1237 创近 20 日新低、量连续 3 日递增（典型价跌量增），但状态机输出「价涨量增(强势)」，与 dim3 形态「价跌量增」、量价状态「中性」直接矛盾。
- **根因**（当日重算实证）：`volume_price_strategy.classify_fast` 背离预警判定需 `vol_high_3d = all(volumes[-i] > vol_ma5*1.3 for i in 1..3)`——茅台量比约 1.14 未达 1.3× 阈值 → 背离不触发；随后筹码转换、健康动量均不满足 → **落入第 5 步兜底 `return VP_HEALTHY_BULL`（默认"价涨量增强势"）**。即：当日价跌量增却因阈值未达而默认报"价涨量增"——**默认值方向退化**。慢线 `status_recognition.state_label` 实际正确判「横盘整理」（:3594 CONSOLIDATION），但 data_daemon 透传取的是快线 `current_pattern`（data_daemon.py:3794-3796）。
- **修复（两层）**：
  - a) `classify_fast` 兜底段：`price_chg_1d<0` 且量增（`vol_ratio>=1.0`）时返回 `VP_DIVERGE_BEAR`（价跌量增底背离）；`price_chg_1d<0` 时返回 `VP_HEALTHY_BEAR`；仅当数据不足时才默认 `VP_HEALTHY_BULL`。
  - b) `vol_high_3d` 阈值 1.3×→1.0×（对齐 VP 语义「量增」= 量比>1 即算，背离检测对量增更敏感）。
  - 445 冻结合规：vp_state_label 属 SIG 现状层「因」描述（479-3 透传），修复仅修正默认方向错误，不触碰 dim3 判定逻辑。
