# 446 号 D11 — dim4 资金×价格背离补产出

## 一、问题确认（445 §6.1 dim4 偏差，代码级已核）

**445 §6.1 dim4 输出项**：「资金×价格背离缺失」

**引擎现状**（`dim4_chip_fund_engine.py:Dim4ChipFundEngine.evaluate` L5854+）：
- `PhaseDetectionEngine.compute_tags` 已同时计算 **`trend_alignment`**（价格三周期方向：`up_aligned/down_aligned/mixed/no_trend`）与 **`fund_flow`**（5日大单净流入/流出：`5d_inflow/5d_outflow/mixed/none`）。
- `_assess_fund_flow` 把资金流映射为 `direction: inflow/outflow/neutral`。
- 但 evaluate 只**分别**消费 `fund_flow_info['direction']`（judgment.direction）与 `phase_info['phase']`（主力阶段），**从未对「资金方向 vs 价格方向」做交叉背离判定** → 拉抬出货/顶部背离（危险回避信号）与底部吸筹信号静默缺失。445 登记的正是这一缺口。

**知识库权威**（外部 wiki《筹码分布分析-主力视角》）：
> - 「连续买超+股价上涨：机构看多；**连续卖超+股价下跌**：机构看空」→ 同向一致。
> - 「**融资暴增+股价不动/下跌** = 散户接盘，主力出货，是明确的危险信号」→ 资金流出/过热 + 价格滞涨或上涨 = **拉抬出货**危险回避。
> - 「法人持续买超 + 股价站稳主力集中价」多头发力；「卖超 + 股价滞涨开始下跌」坚决回避。
> - 综合到本项目可量化的维度上（资金流向方向 × 价格方向）：
>   - 同向（inflow+up / outflow+down）→ 一致，无背离；
>   - **outflow+up** → 资金流出股价却涨 = 拉抬出货/散户接盘，`危险`回避；
>   - **inflow+down** → 资金流入股价却跌 = 底部吸筹/逆势建仓，看多提示。

## 二、修复方案（补产出，用户未额外拍板——沿用「7 契约键补产出」同款思路：只加输出不调判定）

### 2.1 新增模块函数 `_assess_fund_price_divergence(fund_flow, price_direction)`

纯函数，入参资金流向 dict（`_assess_fund_flow` 形，含 `direction`）与归一化价格方向（`'up'/'down'/'mixed'/'no_trend'`）。返回：
```python
{
  'status': 'aligned' | 'divergence' | 'none',
  'label':  中文结论（供 plain / 前端现状描述）
  'direction': 'bearish'（背离偏空-出货）| 'bullish'（背离偏多-吸筹）| 'neutral',
  'risk':   '危险' | '提示' | '无',
}
```
- 数据不足（`direction=='neutral'` 或价格非 `up/down`）→ `status='none'`，**不产背离结论**，保守。
- 同向 → `aligned`，风险无。
- `outflow+up` → `divergence/bearish/危险`（拉抬出货，散户接盘）。
- `inflow+down` → `divergence/bullish/提示`（底部吸筹/逆势建仓）。

### 2.2 `Dim4ChipFundEngine.evaluate` 接线

- 价格方向：优先取 `phase_engine_result['trend_alignment']`（归一化 `*_aligned→up/down`）；无引擎结果时用 df 末段斜率兜底（`_c[-1]/_c[-6]-1`，>0.01→up，否则 down，异常→no_trend）。
- 新增 `status_description` 三键：
  - `fund_price_divergence`（背离中文结论 label）
  - `fund_price_divergence_status`（aligned/divergence/none）
  - `fund_price_divergence_risk`（危险/提示/无）
- plain 文案：仅当 `risk != '无'` 时追加 `，{label}` 后缀（避免同向/数据不足时啰嗦）。
- audit 新增条件「资金×价格无危险背离」：`satisfied = risk not in ('危险',)`，`actual=label`，`threshold='无拉抬出货/顶背离'`。

## 三、影响评估（445 约束：不破坏 dim4 引擎判定逻辑/阈值/窗口）

- **补产出，不调判定**：新增模块函数 + evaluate 外层补键，**不触碰** 445 冻结的 dim4 基准（主力四阶段/ASR 0-100 量级/SSRP 主力集中价成本锚定/资金流连续性 max_streak/拥挤度三因子 2/3 表决）。`_assess_fund_flow`、`PhaseDetectionEngine` 内部判定逻辑、judgment 计算全部不动。
- **消费链受益**：dim8 现状描述/前端可读「资金流出+股价上涨（拉抬出货危险）」类结论，此前缺失；audit 新增危险背离闸门。
- **边界安全**：资金方向中性或价格方向未知 → `status='none'`，不影响 status_description 其余键，evaluate 不崩。
