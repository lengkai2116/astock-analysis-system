## 一、当前系统问题综述

### 1.1 已确认的根因——中枢延伸机制错误

通过知识库比对和开源项目验证，确认最核心的 bug 在中枢延伸算法：

**知识库**（`中枢的量化定义.md`）：
> 中枢区间 = [min(前三段低点最大值, 高点最小值), max(前三段低点最大值, 高点最小值)]

**本系统**（修复前）：
```python
# 错误：延伸时用 min/max 扩展边界
if seg_r['low'] <= zs.high and seg_r['high'] >= zs.low:
    low_new = min(zs.low, seg_r['low'])
    high_new = max(zs.high, seg_r['high'])
    zs.low = low_new   # 中枢下沿被拉低
    zs.high = high_new  # 中枢上沿被拉高
```

**chan.py 正确做法**（`ZS.py:try_add_to_end`）：
```python
def try_add_to_end(self, item):
    if not self.in_range(item):
        return False   # 不重叠 → 不延伸
    self.update_zs_end(item)  # 只更新结束位置，不改变中枢区间
    return True
```

### 1.2 完整问题链条

```
中枢延伸错误（min/max 持续扩张）
  → 单个中枢吞没全部价格范围
  → only取最后一个中枢 (zhongshu_list[-1])
  → 产生无意义支撑/阻力 (如 34~106)
  → 无级别属性 → 日线级别与周线/60分钟混同
  → 线段简化重叠检测 → 初始边界不精确
  → 笔振幅过滤3% → 低波动期丢笔 → 中枢识别起点延迟
  → 背驰算法单一（仅MACD面积）→ 特定行情误判
  → 买卖点仅3类 → 丢失盘整背驰/类二买卖点信号
  → 大部分参数硬编码 → 无法适应差异化行情
```

## 四、核心算法修正与能力提升细则

### 4.1 中枢延伸修复（P0）

**问题**：`ZhongshuAnalyzer.find()` 延伸时用 `min/max` 扩展中枢边界。

**修正**：改为 chan.py 的 `try_add_to_end` 模式：

```python
def try_extend(self, segment) -> Union[bool, str]:
    """尝试将线段延伸入中枢。
    
    Returns:
        True → 完全在区间内，延伸成功
        'partial_overlap' → 部分超出，触发扩张检测
        False → 完全不重叠，中枢破坏
    """
    seg_range = segment.range
    # 完全在中枢区间内 → 延伸（只更新结束位置）
    if seg_range['low'] >= self.low and seg_range['high'] <= self.high:
        self.end_idx = segment.end_idx
        self.end_date = segment.end_date
        if self.segments is not None:
            self.segments.append(segment)
        return True
    # 部分重叠但超出 → 触发扩张检测
    if seg_range['low'] <= self.high and seg_range['high'] >= self.low:
        return 'partial_overlap'
    # 完全不重叠 → 中枢破坏
    return False
```

**参考**：chan.py `ZS.py:try_add_to_end`

### 4.2 中枢扩张+子中枢链（P1）

**问题**：当前 `expanded` 标记后覆盖原中枢，丢失下级结构。

**修正**：扩张时保留子中枢链 `sub_zhongshu_list`：

```python
def try_expand(self, segment) -> Optional['Zhongshu']:
    """尝试中枢扩张。
    
    与 chan.py 的 combine/do_combine 对齐：
    1. 保存当前中枢到子中枢列表
    2. 创建新的大区间中枢
    """
    if not self._check_expand_condition(segment):
        return None
    # 保存当前中枢到子中枢列表（可追溯下级结构）
    self.sub_zhongshu_list.append(copy.deepcopy(self))
    # 扩张边界
    self.low = min(self.low, segment.range['low'])
    self.high = max(self.high, segment.range['high'])
    self.type = 'expanded'
    return self
```

**中枢演化状态机**：

```
初始中枢 ──→ 线段在区间内 → 延伸（不改变边界）
        ├── 线段超出但返回 → 扩张（保留子中枢+变大区间）
        ├── 线段离开不返回 → 新生（列表追加同级别新中枢）
        └── 两中枢区间重叠 → 合并（保留各自为子中枢）
```
