## 二、架构变更说明

### 2.1 新旧数据流对比

**旧数据流（当前）**：
```
SIG → signal_json (5引擎)
  ↓
OUT步骤内:
  StatusEngine.evaluate() → dim_states
    → build_seven_dim_report(row, tags, geo)  ← 旧Path B
    → one_liner_detail
  → status_snapshot + treemap_snapshot
  → 归档
```

**新数据流（v3.0目标）**：
```
SIG步骤:
  5引擎计算 → signal_json
  引擎输出组装 → seven_dim_json  ← SIG直接产出
  dim引擎连续值 → dim_results_json (可选)
  → 写入 strategy_signal_detail (3列)

JUD步骤（独立）:
  StatusEngine.evaluate()
    → _build_dim_engine_results()  ← Path C（注：dim1在SIG预计算，作为dim_results_json的一部分，JUD通过dim_results复用，不重复计算dim1）
    → dim8状态总结
    → _convert_to_dims_format()  ← 兼容层
    → _apply_l0() GATE门禁
    → _aggregate() + P3动态权重
    → arbitrate() P0-P7仲裁
  → status_snapshot + treemap_snapshot

OUT步骤（简化）:
  读取 strategy_signal_detail.seven_dim_json
  → 写入 status_snapshot.one_liner_detail
  → 归档 (status_snapshot_history)
  → watchlist_status_diff（自选股变更检测）
```

## 四、strategy_signal_detail新增列说明

### 4.1 当前schema

```sql
CREATE TABLE strategy_signal_detail (
    ts_code TEXT NOT NULL,
    trade_date TEXT NOT NULL,
    signal_json TEXT NOT NULL,      -- 5引擎信号
    schema_version INTEGER DEFAULT 1,
    cached_at TEXT,
    PRIMARY KEY (ts_code, trade_date)
)
```

### 4.2 新增列

```sql
ALTER TABLE strategy_signal_detail ADD COLUMN seven_dim_json TEXT;    -- SIG七维描述→OUT
ALTER TABLE strategy_signal_detail ADD COLUMN dim_results_json TEXT;  -- 维度判定原始值→JUD
```

### 4.3 方案选择理由（方案A：ALTER TABLE）

| 维度 | 方案A（ALTER TABLE） | 方案B（新建表） |
|------|---------------------|----------------|
| 复杂度 | 低（1次ALTER TABLE） | 高（新表+JOIN） |
| 数据一致性 | ✅ 同一(ts_code,trade_date)原子写入 | ⚠️ 两表需事务保证 |
| 管道简化 | ✅ SIG一次INSERT覆盖3列 | ⚠️ SIG写两张表 |
| 分库兼容 | ✅ 跟随snapshot_cache.db | ⚠️ 需决定路由 |
| 维护成本 | ✅ 单表 | ⚠️ 两表schema同步风险 |

**结论**：三列天然同源（SIG同一轮计算产出），单表最简。

## 五、P3动态权重实施说明

### 5.1 当前状态

`_aggregate()` 使用等权投票计算consensus_rate，`_dimension_weights` 配置为空。

### 5.2 目标状态

358号定义 `MARKET_REGIME_WEIGHTS`（4种市场状态×7维权重），在 `_aggregate()` 中根据市场状态动态选择权重矩阵。

### 5.3 市场状态×维度权重矩阵

| 市场状态 | signal | structure | vp | chip_fund | emotion | risk | valuation |
|---------|--------|-----------|----|----|---------|------|-----------|
| 趋势上行 | 0.15 | 0.20 | 0.15 | 0.10 | 0.10 | 0.15 | 0.15 |
| 震荡盘整 | 0.10 | 0.15 | 0.20 | 0.10 | 0.10 | 0.20 | 0.15 |
| 趋势下行 | 0.10 | 0.10 | 0.10 | 0.10 | 0.10 | 0.30 | 0.20 |
| 极端恐慌 | 0.05 | 0.05 | 0.05 | 0.10 | 0.10 | 0.40 | 0.25 |

### 5.4 市场状态判定逻辑

从dim8_summary_engine的status_bar或pre_feat_cache.sentiment中推导当前市场状态。
