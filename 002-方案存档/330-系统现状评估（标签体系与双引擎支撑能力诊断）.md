# 330 — 系统现状评估：标签体系与双引擎支撑能力诊断

> 背景：聚焦两大核心问题——①股票现状没有弄清楚也没有描述清楚；②操作建议可参考性太差且无法确保有效性。本文评估标签体系与两套策略引擎（机会图谱 + 个股策略分析）现阶段能否支撑上述目标，梳理整体系统问题与根因。**仅评估，未修改任何方案与代码。**

## 一、总体判断

**两大目标当前均未被充分支撑，且根因同源：数据链断裂 + 闭环缺失。**

| 目标 | 现状 | 支撑程度 |
|------|------|:---:|
| A. 现状讲清楚 | 标签真实（83 个）但**呈现层只露 8 个**、**结构位失真**、**矛盾维度被隐藏** | ⚠️ 30% |
| B. 建议可参考/有效 | 输出模板化（止损拍脑袋、目标虚构、情景空话）、**无有效性闭环** | ❌ 15% |

---

## 二、目标 A（现状描述）支撑评估

### 已具备的能力（真实的部分）
1. **83 个标签全部有真实生产链**（估值/缠论/筹码/资金/事件/情绪，覆盖 5587 只）——"现状"的**数据原料是真实的**（见 329 号报告标签信息表）
2. 七维红绿灯、几何指标、标签解说已实现"用实际值叙述现状"（301119 输出正确）

### 4 个致命缺口

| 缺口 | 实证 | 后果 |
|------|------|------|
| **① 呈现层只露 8/83 标签** | `collectHitTags` 仅采 26 候选键，康龙化成 83 标签只展示 8 个（筹码深度/财务深度全漏） | 用户看到的"现状"是**残缺切片**，筹码健康/财务风险等关键维度不可见 |
| **② 结构位失真** | 300759 `near_levels_filtered` 支撑 78.43/82.89 **高于现价 47.9**（2021 历史中枢未过滤）；`support_resistance` support=28.74 与现价差 40% | 现状卡里的"支撑/压力位"与实际 K 线**对不上**，用户无法信任 |
| **③ 矛盾维度被硬合成** | 300759：`risk_level=HIGH` + `state_label=下降` + `profit_ratio=0.99` + `main_force_presence=none`，却输出"可入场"——arbiter 把冲突压成单一 enter | **"现状"是伪一致**——真实风险（高位+缠论下降+无主力）被掩盖 |
| **④ 共识口径自相矛盾** | 同一股票弹窗共识 100%/90%，个股页 67%（标签轻量推导 vs 真实五维） | 用户看到两个互相矛盾的"现状结论" |

### 结论

**数据真实 ≠ 现状清楚。** 标签层 90% 达标，但从标签到"用户能看懂的现状"之间——采集不全、结构失真、矛盾隐藏、口径分裂——4 层失真叠加，用户看到的是"看似真实实则残缺且矛盾"的现状。

## 三、目标 B（操作建议有效）支撑评估

### 已具备的能力（真实的部分）
- 止损/目标/情景/失效有**真实计算入口**（executable/geometric/scenarios 结构完整）
- 系统**有**回测/校准/复盘服务（backtest_evidence_service、prediction_calibration、review_engine）

### 5 个致命缺口

| 缺口 | 实证 | 后果 |
|------|------|------|
| **① 止损非真实结构位** | 300759 止损 40.71 = 15% 上限压缩产物（真实 MA20=39.89 被掩盖）；301119 止损 16.69 曾致 -25% | 建议的"止损"不是任何真实支撑，**风控数字无依据** |
| **② 目标位虚构** | 300759 目标 50.23=60日高点（昨天刚摸到）+57.76=×1.15 纯乘法；geometric 却说压力位 31.0（矛盾双源） | "目标位"是数学拼凑，**不是可执行的价格决策** |
| **③ 失效条件漏真实信号** | 300759 数据库有 exit_conditions（跌破MA20/出货/估值退出）但失效条件只显示"收盘跌破止损位"一条 | 策略失效判定**信息严重不全** |
| **④ 三情景空话** | 情景步骤是写死模板（"回踩支撑位可加仓"），无具体价位/触发/操作；对照 326 定稿原型（应有"近3日量能≥1.5倍/站稳13.50/资金转流入"） | 用户**无法执行**，建议形同虚设 |
| **⑤ 建议无有效性闭环** | 回测服务只消费 `signal_type=BULLISH/WATCH`（信号层），**未接入 operation_advice 的止损/目标/仓位**；校准服务是内存存储未持久化；建议层完全不读胜率数据 | **无法回答"这个建议历史上靠不靠谱"**——有效性无任何保障机制 |

### 结论

**建议链路"有引擎、无依据、无验证"。** 执行层（advice_builder）用近似计算替代真实结构数据（MA20/筹码峰/exit_conditions 都在库里但没用），回测/校准体系与建议输出**完全脱节**——有"建议"但没有任何机制证明它有效。

## 五、根因分析（第一性原理）

```
问题表面：现状不清、建议无效
    │
    ├─ 直接原因1：数据链路断裂
    │    P4 产出的真实数据（MA20/筹码峰/exit_conditions/support_resistance）
    │    → 执行层(advice_builder) 只用其中一小部分做近似计算
    │    → 呈现层(collectHitTags) 又只采集 26/83 键
    │    → 两层各丢一次信息，真实数据到用户面前只剩残片
    │
    ├─ 直接原因2：无闭环验证
    │    回测/校准/复盘服务存在，但消费的是"信号层(signal_type)"
    │    而非"建议层(operation_advice 的止损/目标/仓位)"
    │    → 建议从未被评估，有效性永远无法回答
    │
    ├─ 直接原因3：双引擎各自为政
    │    机会图谱(diagnose)与个股页(analyze)共享标签库，
    │    但各自调用 build_operation_advice 时传参不同(_dims vs 真实五维)
    │    → 同一股票两个结论，用户无所适从
    │
    └─ 深层根因：架构上"数据计算"与"策略核算"分层了
         (292号红线：数据计算后台预计算、策略核算按需触发)
         但执行层的"建议生成"既不是纯数据计算、也没接入策略核算的验证环，
         卡在中间——成了无数据支撑、无验证反馈的"真空层"
```

**一句话根因**：系统具备真实的标签数据和完整的回测机制，但**建议生成层既没有充分消费真实数据（断链），也没有接入验证环（无闭环）**——两套引擎各自消费同一标签库却口径不一（分裂），导致"现状只剩残片、建议凭空生成"。

## 六之二、改进方向详细展开 + 双板块影响评估（2026-08-13 补充）

### 改进 1：执行层接真数据（消灭模板化）

**现状问题**（`advice_builder.py` 实证）：
- **止损**：`_geometric()` 取 `support = max(MA20, 近20日低点)`，但被 15% 上限强制压缩（`price×0.85`），真实 MA20=39.89 被掩盖、止损 40.71 不是任何真实结构位
- **目标**：`_build_target_levels()` 用 `hi60 × 1.15` 纯乘法，60日高点 50.23 是昨天刚摸到的价位，57.76 是虚构位
- **失效**：`_build_invalidation()` 只检查 3 个来源（support/sentiment/rsc），数据库里现成的 exit_conditions（跌破MA20 且 3 日未收回/出货信号/估值退出）完全没用
- **情景**：`scenarios` 步骤是硬编码字符串（"回踩支撑位可加仓"），与股票无关

**修改内容**（预计涉及 `advice_builder.py` + 新增结构位工具函数）：
1. **止损**：新增"真实近端结构位"选择器——从 `MA20 / 近20日低点 / 筹码主峰(chip_peak) / 中枢下沿(support_resistance)` 中选**距现价最近且低于现价**的作为止损位；距离上限 15% 保留为**兜底校验**而非主逻辑（仅在结构位缺失时启用）
2. **目标**：用"真实压力位"——`60日高点 / MA60 / 筹码主峰上方 / 中枢上沿` 中**高于现价且最近**的作为目标1，目标2 用真实次压力位而非 ×1.15
3. **失效**：解析 `exit_conditions` JSON（desc/check 结构）转成中文失效条件列表，与现有 3 源合并
4. **情景**：将真实价位注入场景步骤（如"回踩 MA20(39.89) 不破可加仓""放量站稳 50.23（60日高点）追进"），每情景带触发条件+操作+目标

### 改进 4：呈现层扩源（让现状真实可见）

**现状问题**：
- **采集不全**：`collectHitTags` 只采 26 候选键（keyMap 14 + 深度 12），康龙化成 83 标签只展示 8 个——筹码深度（asr/cyqkl/profit_ratio/peak_type）、财务深度（fcf_yield/revenue_growth/roce_pass）、事件深度全漏
