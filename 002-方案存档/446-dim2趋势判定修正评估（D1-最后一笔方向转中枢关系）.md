# 446 — dim2 趋势判定修正评估（D1）

## 一、问题确认（445 §6.1 dim2 D1，代码级已核）

**现状**（`chanlun_strategy.py:_determine_trend` L2418-2424）：
```python
def _determine_trend(self) -> str:
    if self.bi_zs_mode:
        if self.strokes:
            return self.strokes[-1].direction   # 笔中枢模式：最后一笔方向
        return 'unknown'
    if not self.segments:
        return 'unknown'
    return self.segments[-1].direction           # 线段模式：最后一段方向
```

**消费链**（`dim2_structure_engine.py`）：`trend` → `struct_state`（上升/下降/盘整）→ `judgment.light`（green/red/yellow）+ `overall_direction` + `status_description.chanlun_direction`。

**知识库标准**（外部 wiki《缠论走势结构量化系统配置指南》）：趋势判定应基于**中枢关系**（中枢上移/下移），"价格高于中枢上沿"为上升；**单笔回调不应翻转趋势**。

**矛盾机制（实证）**：笔中枢模式下 `vs_zhongshu` 用价格 vs 最后中枢位置（`_assess_vs_zhongshu`，dim2 L196-213），`trend` 用最后一笔方向——**两者来自不同依据**。场景：价格突破中枢上沿（vs_zhongshu='上方'，plain="价格突破中枢上沿，离开成本区"）但最后一笔是向下回调 → trend='down' → struct_state='下降' → light=red。**同一股票"离开成本区"与"红灯下降"同屏矛盾**——正是 444 现状描述自相矛盾的引擎源头之一。

3. 线段中枢仅 1-2 个 → 方案 C 的"**1 中枢用价格位置**"是主要路径（符合知识库"价格高于中枢上沿=上升"），"≥2 中枢比较上移/下移"为辅。

### 2.6 方案 C 实施设计（D1+D2）

**framework（chanlun_strategy.py）**：
1. 新增 `_determine_zs_trend()`（方案 C 主判据）：
   - **≥2 中枢**：比较 `zs[-1]` vs `zs[-2]`——`zs[-1].low > zs[-2].high` 强上移→up / `zs[-1].high < zs[-2].low` 强下移→down / 否则比较中心（`(h+l)/2` 上移→up、下移→down、|差|<宽度×阈值→震荡）
   - **1 中枢**：最新 close vs 上下沿——close > 上沿→up / < 下沿→down / 内部→震荡
   - **0 中枢**：fallback 最后笔/段方向（保留现有）
2. `_determine_trend()` 改为调用 `_determine_zs_trend()`
3. `_generate_result` 新增 `trend_basis` 字段（'中枢上移'/'中枢下移'/'价格突破上沿'/'价格跌破下沿'/'中枢内部'/'最后笔方向'/'最后段方向'/'无中枢'）
4. **D2 分级**：`analyze` 中 `bi_zs_mode=False` 时线段中枢优先，`len(segments) < 3` 自动回退笔中枢（`self.zhongshu_list = self.bi_zs_finder.find(self.strokes)`），不退化

**dim2（dim2_structure_engine.py）**：
1. `ChanlunAnalyzer({'bi_zs_mode': False})`（日线走线段中枢，D2）
2. `status_description` 补 `trend_basis` 键；`chanlun_direction` 语义保持（trend）
3. struct_state/light 消费不变（trend 语义即中枢关系，矛盾消除）

**影响面**（ChanlunAnalyzer 20 个调用点）：改默认仅影响无参调用；本方案**不改默认 bi_zs_mode**，仅 dim2 显式传 False；data_daemon:3275 保持现状（RAW 层缠论组只取 buy_sell_point，中枢模式属 444 A2 接线范畴，本号不动，关联项备注）。测试断言需更新。
