# 212 — 系统字体使用规范与标准体系

> **范围：** 本规范覆盖 `_ui-prototype/` 下所有原型页面（未来上线的 UI 基础）
> **约束条件：** 不改变任何原型页面结构和功能，仅规范字体（`font-size`、`font-weight`、`color`）

---

## 一、调研结论：主流证券软件的字体标准

### 1.1 行业基准

| 来源 | 基线字号 | 字号阶梯 | 特点 |
|:-----|:--------|:---------|:-----|
| **OakView (TradingView风格)** | 14px | XS 10px → SM 11px → Base 12px → MD 13px → LG 14px → XL 16px → 2XL 18px → 3XL 20px → 4XL 24px → 5XL 28px | 暗色背景，专业交易界面 |
| **Fintech Dashboard规范** | 14px | Display 36px / H1 24px / H2 20px / H3 16px / Body 14px / Small 12px | 数据密集型金融仪表盘 |
| **国信证券金太阳** | — | 移动端 28/24/22/20pt(标题) → 18/16/14pt(正文) → 12/11pt(注释) | 移动证券标准 |
| **B端通用规范** | 14px | 12px(说明) → 13px(正文) → 14px(导航) → 16px(大标题) → 20px(页面标题) | 企业级产品通用标准 |

### 1.2 暗色可读性关键发现

| 条件 | 要求 | 来源 |
|:-----|:-----|:-----|
| 中文最小字号 | **≥12px**（11px以下中文字体不可正常辨识） | WCAG 2.1 + B端规范一致结论 |
| 数字/英文最小字号 | 可到 **11px**（等宽字体/小量使用） | 金融界面设计指南 |
| 深色背景文字对比度 | 正文 ≥ **4.5:1**，大标题 ≥ **3:1** | WCAG 2.1 AA |
| 深色背景小字号策略 | 12px 以下需提升字重（Medium/SemiBold）并严格检查对比度 | B端设计规范 |
| 数据字体 | **推荐等宽字体**（Roboto Mono / JetBrains Mono）保证数字对齐 | 多来源一致结论 |

### 1.3 涨跌色与文字配合

| 色值 | 用途 | 字重建议 |
|:-----|:------|:--------|
| `#EF4444` (红) | 上涨 | Bold (加粗突出) |
| `#22C55E` (绿) | 下跌 | Bold (加粗突出) |
| `#F59E0B` (黄) | 预警/关注 | Medium |
| `#A3A3A3` (灰) | 中性/平盘 | Regular |

## 二、信息层级分类

基于全站 17 个页面的实际内容分析，定义 8 种信息层级：

### Level P0 — Hero 核心数值
- **定义：** 用户最关注、需要一眼获取的关键数字
- **页面分布：**
  | 页面 | 具体内容 |
  |:-----|:---------|
  | 仪表盘 | 四大指数值、成交流水、板块涨跌幅 |
  | 个股策略分析 | 最新股价、涨跌幅、MA值、筹码获利比例 |
  | 自选监控 | 最新价、涨跌幅、策略评分 |
  | 选股系统 | 评分/排名 |
  | 回测系统 | 总收益率、年化收益、最大回撤、夏普比率 |
  | 复盘中心 | 收益率、胜率 |
  | 策略沙箱 | 结论汇总数值 |
  | 账户管理 | 总资产、总盈亏 |
  | 监控通知 | 触发统计数 |
- **字号建议：** 24px / 20px
- **字重：** Bold (700)
- **颜色：** `--text-primary` 或涨跌色

### Level P1 — 页面/区块标题
- **定义：** 页面 H1、区块大标题、弹窗标题
- **字号建议：** 20px (H1) / 16px (区块/弹窗标题)
- **字重：** SemiBold (600)
- **颜色：** `--text-primary`

### Level P2 — 次级标题/卡片标题
- **定义：** 卡片区域的标题行、指标名、板块名
- **字号建议：** 14px
- **字重：** Medium (500)
- **颜色：** `--text-secondary`

### Level P3 — 正文/交互元素
- **定义：** 正文文字、按钮标签、输入框文字、导航项
- **字号建议：** 14px
- **字重：** Regular (400)
- **颜色：** `--text-primary`

### Level P4 — 表格数据/Tab文字
- **定义：** 表格单元格内容、Tab 标签、卡片描述
- **字号建议：** 13px
- **字重：** Regular (400)
- **颜色：** `--text-primary` (数据) / `--text-secondary` (描述)

### Level P5 — 标签/表头/元数据
- **定义：** 表格表头、Tag标签、数据字段名、时间戳、小图标文字
- **字号建议：** **12px**
- **字重：** Medium (500) — 因字号偏小，提升字重保证可读性
- **颜色：** `--text-muted`

### Level P6 — 次要标注
- **定义：** 侧栏分组标题、极小脚注、辅助分类文字
- **字号建议：** **11px**
- **字重：** Medium (500)
- **颜色：** `--text-muted`
- **约束：** ⚠️ 仅在深色背景上**少量使用**，且必须使用 Medium 字重

### Level P7 — 角标/徽标
- **定义：** NEW 标记、角标数字、极小标签
- **字号建议：** **10px**
- **字重：** Bold (700)
- **颜色：** white 或 `--text-muted`
- **约束：** ⚠️ 仅限英文/数字短内容，不得用于中文；全站≤5处

## 三、字体标准体系（7级 + 1Badge）

### 3.1 标准字号表

| 级别 | 尺寸 | 字重 | 行高 | 语义 | 对应当前 base.css |
|:----|:----|:-----|:-----|:-----|:------------------|
| **P0-s** | 20px | Bold 700 | 28px | 核心数值(小) | card-value 24px → ⚠️ 调整建议 |
| **P0-l** | 24px | Bold 700 | 32px | 核心数值(大) | card-value ✅ |
| **P1** | 20px | SemiBold 600 | 28px | 页面标题 | page-header h1 ✅ |
| **P2** | 16px | SemiBold 600 | 24px | 区块标题/弹窗标题 | modal-header h3 ✅ |
| **P3** | 14px | Medium 500 | 22px | 卡片标题/板块名 | — (建议新增 token) |
| **P4** | 14px | Regular 400 | 22px | 正文/按钮/输入/导航 | body/btn/input ✅ |
| **P5** | 13px | Regular 400 | 20px | 表格数据/Tab/描述 | table td / tab-item ✅ |
| **P6** | 12px | Medium 500 | 18px | 标签/表头/元数据 | tag/table th ✅ |
| **P7** | 11px | Medium 500 | 16px | 侧栏分组/次要标注 | sidebar-group-title ✅ |
| **Badge** | 10px | Bold 700 | 14px | 角标/徽标 | badge-new ✅ |

### 3.2 对于当前 base.css 的修正建议

| 当前定义 | 建议修改 | 理由 |
|:--------|:--------|:-----|
| `card-title: 14px / font-weight: 500 / color: text-secondary` | ✅ 保留（符合 P3 级别） |
| `sidebar-item: 13px / Regular / color: text-secondary` | ✅ 保留（符合 P5 级别，导航项用 13px 可接受） |
| `badge-new: 9px` | → **10px** Bold | 9px 在深色背景可读性差，且与行业标准 10px 徽标一致 |
| `sidebar-group-title: 11px` | ✅ 保留（符合 P7 级别） |
| `tag: 12px Medium` | ✅ 保留（符合 P6 级别） |

### 3.3 禁止使用的尺寸

| 尺寸 | 原因 | 当前出现位置 |
|:----|:-----|:------------|
| **8px** | 远低于中文可读阈值 | `indicator-ide` 副图标签、`playback` 日期小标、`backtest` 参数表 |
| **9px** | 中文字体不可辨认 | `badge-new`、多处次要标签 |
| **10px** | 中文字体勉强可读但需限制 | 6 个页面 50+ 处（account/indicator-ide/dashboard/screener/playback/backtest） |

> **注：** 10px 仅保留用于 Badge/角标（且仅限英文/数字）。全站所有 10px 中文字体须统一提升至 11px 或 12px。

## 五、设计 token 补充建议

在 base.css 的 `:root` 中，建议新增以下 CSS 变量，使字体体系可被全站统一引用：

```css
/* ===== 字体级别 Token（新增） ===== */
--fs-hero-lg: 24px;    /* P0-l: 大核心数值 */
--fs-hero-sm: 20px;    /* P0-s: 小核心数值 */
--fs-page-title: 20px; /* P1: 页面标题 */
--fs-section: 16px;    /* P2: 区块标题 */
--fs-card-title: 14px; /* P3: 卡片标题 */
--fs-body: 14px;       /* P4: 正文/按钮/输入 */
--fs-table: 13px;      /* P5: 表格数据/Tab */
--fs-label: 12px;      /* P6: 标签/表头 */
--fs-mini: 11px;       /* P7: 次要标注 */
--fs-badge: 10px;      /* Badge: 角标 */

/* 字重 Token（可选） */
--fw-bold: 700;
--fw-semibold: 600;
--fw-medium: 500;
--fw-regular: 400;
```

## 六、关键颜色对比度核查

### 6.1 深色背景上文字颜色对比度

| 文字色 | CSS 变量 | 十六进制 | 背景色 | 对比度 | WCAG AA | 适用级别 |
|:------|:---------|:---------|:-------|:------|:--------|:---------|
| 主要文字 | `--text-primary` | `#F1F5F9` | `--bg-canvas #0A0A0A` | **15.61:1** ✅ | 通过 | P0~P4 |
| 次要文字 | `--text-secondary` | `#94A3B8` | `--bg-canvas #0A0A0A` | **7.32:1** ✅ | 通过 | P4/P5 |
| 次次文字 | `--text-muted` | `#64748B` | `--bg-canvas #0A0A0A` | **4.36:1** ⚠️ | 通过(4.5:1临界) | P6/P7 |
| 禁用文字 | `--text-disabled` | `#404040` | `--bg-canvas #0A0A0A` | 2.23:1 ❌ | 不通过 | 仅禁用态 |

> **结论：** `--text-muted` (#64748B) 在 `--bg-canvas` (#0A0A0A) 上对比度为 4.36:1，**略低于 WCAG AA 标准 4.5:1**。在 P6 (11px) 和 P7 (12px) 级别使用时，建议将 `--text-muted` 调整为 `#6B7280`（对比度提升至 4.8:1），或在标签文字上使用 `--text-secondary` 替代。

### 6.2 标准色板推荐修正

| 变量名 | 当前值 | 建议值 | 对比度改善 |
|:-------|:-------|:-------|:----------|
| `--text-muted` | `#64748B` | `#6B7280` | 4.36:1 → **4.81:1** ✅ |
| `--text-disabled` | `#404040` | `#525252` | 2.23:1 → **3.01:1**（仍不如正文但改善） |
