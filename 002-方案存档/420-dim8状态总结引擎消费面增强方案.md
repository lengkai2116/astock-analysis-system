# 420号 — dim8状态总结引擎消费面增强方案

---

## 一、问题背景

### 1.1 dim8 消费面过窄（上一轮核查结论）

dim8（`dim8_summary_engine.py`，358号 v4.1 "纯整理输出"）只消费 dim2-dim7 的 4 类字段：
- `judgment.overall_light`（全部 7 维）→ 红绿灯/共识率/状态条
- `judgment.overall_direction`（4 维）→ 状态条方向计数
- `judgment.phase`（仅 chip_fund）→ 冲突规则 1
- `status_description.plain`（全部 7 维）→ 综合文字

**76 个量化富字段未消费**（实测 000001.SZ）：signal 的 `lifecycle_stage/maintenance/decay_detail`、structure 的 `chanlun_direction/buy_sell_points`、volume_price 的 `pattern/pattern_score/health_score`、chip_fund 的 `retail_institution/margin/crowding`、emotion 的 `quadrant/temperature`、risk 的 `rr_value/support_price/resistance_price/invalidation/volatility_level`、valuation 的 `valuation_level/pe_percentile/fcf_yield/potential_score` 等，全部折叠为灯色丢弃。

### 1.2 LLM Wiki 知识库对照

知识库核心概念（`data/knowledge/concepts/`）：
- **多指标共识机制**：多个独立指标同向时信号可靠性提升，共识计数 ≥2/3 才执行
- **回报风险比**：决策质量 = 回报÷风险，盈亏比影响仓位与状态
- **信号冲突处理机制**：多源矛盾信号→分层/加权/共识；因子衰减/生命周期导致方向冲突
- **因子衰减/生命周期**：信号预测力随时间衰减，拥挤阶段有效性下降
- **筹码分布分析（主力视角）**：散户反向指标、主力四阶段、交叉比对
- **多形态共振**：多形态同向共振信号更强

dim8 现状未应用这些方法论——共识率用固定等权灯色（非置信度加权）、状态条未纳入盈亏比、冲突检测仅 5 条固定规则、综合文字仅拼接 plain。

---

## 二、方案目标

在**不改变 dim8 定位**（纯整理输出、不变更内容不判定、不新增数据源）的前提下，充分利用 dim2-dim7 已产出的富字段，增强"股票现状描述"的决策价值：

1. **共识率置信度加权**：用各维 `continuous_value`（0-1 置信度）替代固定等权灯色，对齐"多指标共识机制"
2. **风险收益结构接入状态条**：纳入 risk 的 `rr_value`（盈亏比），对齐"回报风险比"
3. **信号健康度提示**：纳入 signal 的 `lifecycle_stage/maintenance/decay_detail`，对齐"因子衰减/生命周期"
4. **冲突检测扩展**：新增 3 条基于未消费字段的规则（散户过热/形态背离/波动率放大）
5. **综合文字富化**：在 plain 基础上补充关键量化锚点（支撑压力位、盈亏比、温度、生命周期天数）
6. **审计置信度接线**：`_extract_dim_audit_confidence` 已定义未使用，接入共识率权重修正

**约束**：dim8 仍只读 `dim_results`（lifecycle 注入），不调用 DataManager/ECM，不新增原料依赖——所有增强字段 dim2-dim7 已产出。

## 三、详细设计

### 3.1 增强1：共识率置信度加权（HIGH）

**文件**：`dim8_summary_engine.py` `_calc_consensus_rate`

现状（固定等权灯色）：
```python
light_to_value = {'green': 1.0, 'yellow': 0.0, 'red': -1.0}
val = light_to_value.get(light, 0.0)
total += val * weight   # weight 固定 DIM_WEIGHTS
```

改造：**灯色方向 × continuous_value 置信度加权**：

```python
def _calc_consensus_rate(dim_results: dict) -> float:
    """加权共识率：灯色方向 × 连续置信度

    对齐知识库"多指标共识机制"——置信度高的维度对共识贡献更大。
    方向取灯色（green=+1/yellow=0/red=-1），权重 = DIM_WEIGHTS × continuous_value。
    """
    light_to_value = {'green': 1.0, 'yellow': 0.0, 'red': -1.0}
    total = 0.0
    weight_sum = 0.0
    for dim_key, base_w in DIM_WEIGHTS.items():
        light = _extract_dim_light(dim_results, dim_key)
        direction = light_to_value.get(light, 0.0)
        # 置信度修正：continuous_value 越高，该维对共识的贡献权重越大
        confidence = _extract_dim_confidence(dim_results, dim_key)  # 新增辅助
        eff_w = base_w * (0.3 + 0.7 * confidence)   # 保底 30% 权重，避免置信度 0 时维度失效
        total += direction * eff_w
        weight_sum += eff_w

    if weight_sum > 0:
        avg = total / weight_sum
        return round(max(0, min(1, (avg + 1) / 2)), 2)
    return 0.5
```

新增辅助（jucount 现有 `continuous_value` 缺失时回退 0.5）：
```python
def _extract_dim_confidence(dim_results: dict, dim_name: str) -> float:
    """提取维度连续置信度（judgment.continuous_value），缺失回退 0.5"""
    jg = _extract_dim_judgment(dim_results, dim_name)
    try:
        return float(jg.get('continuous_value', 0.5))
    except (TypeError, ValueError):
        return 0.5
```

**兼容性**：continuous_value 缺失时置信度=0.5 → eff_w = base_w×(0.3+0.35)=0.65×base_w，所有维同比例缩权，共识率结果不变（方向与相对权重不变）。

### 3.2 增强2：风险收益结构接入状态条（HIGH）

**文件**：`dim8_summary_engine.py` `_derive_status_bar`

现状：`risk_light == 'red' → risk_warning`；其余按共识率+方向。

改造：在风险检查后、共识率判定前，插入盈亏比修正：

```python
# 盈亏比修正（回报风险比概念）：rr≥2 上修、rr<1 下修
rr_value = _extract_dim_rr(dim_results)  # 新增辅助
if rr_value is not None:
    if rr_value >= 2.0 and risk_light != 'red':
        # 高盈亏比 → 上调一档（仅当当前不是看空/退出）
        if consensus_rate >= 0.5:
            return 'strong_confirm' if pos_count >= 3 else 'trend_confirm'
    elif rr_value < 1.0:
        # 低盈亏比 → 下修
        if consensus_rate >= 0.7:
            return 'light_confirm'
        elif consensus_rate >= 0.5:
            return 'neutral'
```

新增辅助：
```python
def _extract_dim_rr(dim_results: dict) -> float | None:
    """提取盈亏比（risk.status_description.rr_value），缺失返回 None"""
    result = dim_results.get('risk', {})
    if result and isinstance(result, dict):
        sd = result.get('status_description', {})
        try:
            rr = float(sd.get('rr_value'))
            return rr
        except (TypeError, ValueError):
            return None
    return None
```

**效果**：000001.SZ 实测 rr_value=1.86（1R-2R，`rr_level=可考虑`）→ 不触发上修/下修（保持中性）；rr≥2 的优质机会状态上修，rr<1 的差机会下修。

### 3.3 增强3：信号健康度提示（MED）

**文件**：`dim8_summary_engine.py` `_derive_status_bar` + `_generate_text`

signal 输出含 `lifecycle_stage`（初期/中期/末期）、`maintenance.status`（healthy/decay）、`decay_detail`。改造：

1. `_derive_status_bar` 增加信号老化检查：
```python
# 信号老化（因子衰减概念）：生命周期末期或维护状态 decay → 不进入强确认
if _is_signal_decaying(dim_results) and consensus_rate >= 0.8:
    return 'light_confirm'  # 信号老化，强确认降级为轻仓确认
```

2. 新增辅助：
```python
def _is_signal_decaying(dim_results: dict) -> bool:
    """信号是否老化：生命周期末期 或 维护状态非 healthy"""
    sig = dim_results.get('signal', {})
    if not isinstance(sig, dict):
        return False
    sd = sig.get('status_description', {})
    stage = str(sd.get('lifecycle_stage', ''))
    if '末' in stage or '衰竭' in stage:
        return True
    jg = sig.get('judgment', {})
    maint = jg.get('maintenance', {})
    if isinstance(maint, dict) and maint.get('status') not in (None, 'healthy'):
        return True
    return False
```

3. `_generate_text` 补充信号健康提示：
```python
if _is_signal_decaying(dim_results):
    parts.append('信号：信号老化（进入末期/维护不佳），追涨需谨慎')
```

### 3.4 增强4：冲突检测扩展（MED）

**文件**：`dim8_summary_engine.py` `_detect_conflicts`

在现有 5 条规则后追加 3 条（数据已实测可用）：

```python
# 6. 散户过热 + 结构上升（筹码主力视角：散户反向指标）
chip_retail = str(_extract_dim_judgment(dim_results, 'chip_fund').get('retail_institution', '')
                   or (dim_results.get('chip_fund', {}).get('status_description', {})
                       or {}).get('retail_institution', ''))
if struct_dir == 1 and ('散户' in chip_retail and '减' in chip_retail):
    conflicts.append({
        'dim1': '结构位置', 'dim2': '资金筹码',
        'description': '结构上升但散户资金在减——上涨动力存疑',
        'severity': 'medium',
    })

# 7. 量价形态空头 + 信号确认（多形态共振：形态背离）
vp_pattern = str((dim_results.get('volume_price', {}).get('status_description', {})
                  or {}).get('pattern', ''))
if signal_dir == 1 and any(k in vp_pattern for k in ('空头', '下跌', 'breakdown', 'bear')):
    conflicts.append({
        'dim1': '量价健康', 'dim2': '信号确认',
        'description': f'量价形态{vp_pattern}但信号确认上涨——形态与信号背离',
        'severity': 'medium',
    })

# 8. 波动率放大 + 结构下降（Barra风险：高波动下行加速）
vol_level = str((dim_results.get('risk', {}).get('status_description', {})
                 or {}).get('volatility_level', ''))
if struct_dir == -1 and vol_level == 'high':
    conflicts.append({
        'dim1': '结构位置', 'dim2': '风险边界',
        'description': '趋势下行且波动率偏高——下跌可能加速',
        'severity': 'low',
    })
```

**兼容性**：仅新增规则，原 5 条不动；字段缺失时条件为 False 不触发。

### 3.6 增强6：审计置信度接线（LOW）

`_extract_dim_audit_confidence` 已定义未使用。在 `_generate_text` 或 `status_description` 中补充"数据完整度"提示：
