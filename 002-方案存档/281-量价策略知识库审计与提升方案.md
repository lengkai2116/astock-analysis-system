# 量价策略知识库审计与提升方案（v4）

## 一、概述

本文档基于 LLM Wiki 知识库 + 用户量价策略深度讨论内容，对系统现有量价策略实现进行审计，并提出从「静态形态规则匹配」升级为「动态量价状态感知与分类」的完整方案。

### 核心设计理念

```
不替换，而是归类。
50+ 种形态不是被扔掉，而是被组织起来。

顶层：8 种量价状态（互斥分类）         ← 快线+慢线状态机
        │
底层：每种状态下匹配的 N 种形态          ← 保留现有形态检测器，作为子集
```

### 设计原则（来自用户讨论总结）

1. **状态优先于形态**：策略信号由顶层状态决定，形态只做置信度增减
2. **快慢线双通道**：快线感知当日变化，慢线过滤噪声
3. **连续确认才切换**：至少连续 2 天处于相同状态才执行策略切换
4. **可调参数平原**：所有阈值非固定最优解，而是参数平原区间的可调值
5. **每季度 IC 重算**：失效状态自动剔除，新状态持续加入

## 二、层级架构设计

### 2.1 顶层：四类八种量价状态

| 大类 | 状态名称 | 量化定义 | 判定优先级 |
|:----|:---------|:---------|:----------:|
| **极端信号** | 天量天价 | 成交量创 **60日新高** 且 价格创 **20日新高** | **1（最高）** |
| **极端信号** | 地量地价 | 成交量创 **60日新低** 且 价格创 **20日新低** | **2** |
| **背离预警** | 价涨量缩(顶背离) | 收盘价创 **10日新高** 且 成交量 **连续3日低于5日均量** | **3** |
| **背离预警** | 价跌量增(底背离) | 收盘价创 **10日新低** 且 成交量 **连续3日高于5日均量×1.3** | **4** |
| **筹码转换** | 放量突破 | 股价站上MA5>MA20 且 成交量 > 5日均量×1.5 | **5** |
| **筹码转换** | 缩量回踩 | 股价在MA20附近(±3%) 且 成交量 < 5日均量×0.6 | **6** |
| **健康动量** | 价涨量增 | 上涨 且 成交量 > 20日均量×1.2 | **7** |
| **健康动量** | 价跌量缩 | 下跌 且 成交量 < 20日均量×0.8 | **8（最低）** |

**关键改进说明**：
- 极端信号从「固定倍数(量比>2.5/量比<0.4)」改为「历史极值(60日新高/新低)」，适应性更强
- 背离预警的成交量条件从「低于均量×0.8」改为「低于均量（无乘数）」，定义更宽松灵敏
- 判定优先级取代模糊匹配度计算，逻辑更确定

### 2.2 底层：形态到状态的映射

现有 50+ 形态检测器保留，为每个状态注册其子集形态。形态检测结果加权到状态置信度。

```
状态「价涨量增(强势)」的子形态（约 30 种）:
├── 量价齐升突破前高 (1-4)        ← 现有 _is_liangjia_qisheng()
├── 底部放量长阳 (1-5)           ← 现有 _is_dibu_fangliang_changyang()
├── 地量后倍量启动 (1-6)          ← 现有 _is_diliang_beiliang_yuzhang()
├── 平台放量突破 (1-7)           ← 现有 _is_pingtai_fangliang_tupo()
├── 放量站上60日线 (1-15)         ← 现有 _is_fangliang_zhan60()
├── 均线多头排列                   ← 现有 _is_ma_tuo_pailie()
├── 底部放量长阳黑马首板           ← 现有 _is_dibu_fangliang_changyang()
├── 红三兵/阳包阴/低位连阳         ← 现有各检测器
└── 锤子线/刺透/晨星/镊子底         ← 现有各K线反转检测器

状态「价涨量缩(顶背离预警)」的子形态（约 6 种）:
├── 量价背离(顶背离)              ← 现有 _calc_divergence()
├── 缩量冲高诱多                   ← 现有 _check_liangjia_relation()
├── 高位十字星/高位长上影线         ← 现有检测器
└── 格兰维尔卖点3-偏离卖           ← 现有 _is_granville_sell3()

...（其余 6 个状态均按此方式注册，完整映射见 volume_price_strategy.py STATE_PATTERN_REGISTRY）
```

### 2.3 三层状态机

```
第一层（快线）：8 种量价状态 → 每日计算，按优先级判定当日状态
第二层（慢线）：5 日状态分布 → 统计过去 5 天快线结果的频率
第三层（背景）：市场整体量价方向 → 基于指数的量价状态过滤个股信号
```

**慢线的用途**：
- 5 天中 4 天「价涨量增」→ 慢线「强势延续」，增强持仓信心
- 5 天中 3 天「价涨量缩」→ 慢线「顶部背离区域」，触发减仓
- **状态切换必须连续 2 天处于新状态才执行**，避免单日噪声触发切换

### 2.4 状态转换规则

| 当前状态 | 转换条件 | 新状态 | 确认机制 |
|:---------|:---------|:-------|:--------:|
| 价跌量缩（健康回调） | 成交量连续 3 日放大 + 价格跌破 MA60 | 价跌量增（底背离） | 连续 2 天 |
| 价涨量增（强势） | 成交量连续 3 日萎缩 + 价格涨幅 < 0.5%/日 | 价涨量缩（顶背离预警） | 连续 2 天 |
| 价跌量增（底背离） | 成交量放大至均量 1.5 倍以上 + 价格止跌 | 进入观察列表（等待确认入场） | 等放量阳线 |
