# 券商API

券商提供的应用程序编程接口，允许用户通过程序直接连接市场，实现行情获取、下单、查询账户信息等功能。在《Python：自動化股票網格交易實戰86個活用技巧》中，[[Shioaji API]]（永丰金证券）是核心使用的券商API，它是连接交易策略与市场的桥梁，是实现自动化交易的技术基础。
