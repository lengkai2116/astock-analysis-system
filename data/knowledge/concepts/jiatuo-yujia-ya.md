# 价托与价压

## 概述

价托与价压是由短期、中期、长期三条均线（通常为MA5、MA10、MA20）形成的三角形区域，是判断波段买卖点的重要技术工具。价托在低位形成，是买入信号；价压在高位形成，是卖出信号。

## 价托（买入信号）

### 形成原理

1. 个股经过长时间调整后，主力资金完成收集筹码过程，股价开始从底部启动
2. 近5天的市场平均买入成本开始高于近10天的平均买入成本，说明新进场的买家情愿以较高价买进，对筹码的需求大于供给
3. 首次反弹往往很急速，上涨到20日均线附近时，前期套牢盘和提前抄底的筹码开始抛出，导致短暂回撤
4. 回撤被称为“黄金坑”，之后更多资金开始觉察到进场时机，推动股价向高位攀升

### 图形特征

1. 股价从低位向上移动，带动短期均线向上拐头
2. MA5均线向上穿越MA10均线形成金叉
3. 股价站上MA20均线，MA20均线方向由向下转为逐渐走平
4. MA5、MA10向上穿越MA20均线，与MA20均线形成封闭空间，形成价托
5. 买入后放量突破前期高点是对该图形的确认

### 操作方法

1. 经过调整之后在低位形成的价托是进场时机
2. 上涨第一目标是前期高位，可作为首次止盈目标位
3. 买入之后成交量温和放大是对上涨趋势的确认
4. 可将止损位设在前低之下

### 应用要点

- 价托形成的位置很重要，重点把握波浪理论中的第1浪和第3浪的起始位置
- MACD指标长期运行在0轴之下，股价与指标发生底背离之后的价托是高效买点
- 在震荡市中，价托会多次出现，需要注意价托的方向
- 在价托中，MA5均线与MA10均线向上的夹角越大，说明动量越大
- 通常要等MA5均线向上穿越MA20均线之后才能确认价托的形成

## 价压（卖出信号）

### 形成原理

1. 个股经过长时间上涨后，主力资金开始逐步出清筹码，股价开始从顶部回落
2. 近5天的市场平均卖出成本开始低于近10天的平均卖出成本，说明近期的卖家宁愿以较低的价格抛出筹码，对筹码的供给大于需求
3. 下跌速度通常更快，回落到20日均线附近时，短线超卖导致短暂反弹
4. 反弹被视为出逃良机，之后更多卖家开始觉察到出场时机，卖盘涌出，打压股价向低位运行

### 图形特征

1. 股价从高位向下移动，带动短期均线向下拐头
2. MA5均线向下穿越MA10均线形成死叉
3. 股价跌破MA20均线，MA20均线方向由向上转为逐渐走平
4. MA5、MA10与MA20均线形成三角形封闭空间，形成价压
5. 卖出后放量跌破前期低点是对该图形的确认

### 操作方法

1. 经过上涨之后在高位形成的价压是离场时机
2. 下跌第一目标是前期低位或者是通道下轨
3. 卖出之后放量跌破前低是对下跌趋势的确认
4. 双向交易的期货品种可以在价压之内开空单

### 应用要点

- 价压形成的位置很重要，重点把握波浪理论中的a浪和c浪起始位置
- MACD指标长期运行在0轴之上，股价与指标发生顶背离之后的价压是高效卖点
- 在震荡市中，价压会多次出现，需要注意价压的方向
- 在价压中，MA5均线与MA10均线向下的夹角越大，说明下跌动量越大
- 通常要等MA5均线向下穿越MA20均线之后才能确认形成价压
- 在急速下跌时，即使产生价压，股价也难以回抽到价压之中，应以反弹一定幅度离场

## 价托与价压的配合运用

价托与多方炮配合使用可提高买入成功率：当多方炮正好形成在价托上方时，继续下跌的可能性较小，伴随着成交量明显放大，之后通常会产生向上跳空缺口。

价压与空方炮配合使用可提高卖出成功率：当空方炮正好形成在价压下方时，继续上涨的可能性已经很小，伴随着阴线成交量明显放大，之后通常会产生向下跳空缺口。
