# 多方炮与空方炮

## 概述

多方炮和空方炮是强烈的攻击性K线组合形态。多方炮由两根阳线夹一根阴线组成，是买入信号；空方炮由两根阴线夹一根阳线组成，是卖出信号。它们用于判断波段的启动或结束。

## 多方炮（买入信号）

### 标准形态

标准的多方炮由三根K线组成：第一根是放量长阳线，第二根是高开低走的阴线，第三根是对前面阴线破脚穿头的阳线，最强的形式是收盘创出新高。

### 强弱形态区分

根据三根K线的排列方式，多方炮可分为四种强弱形态：

1. **标准多方炮**：阴线高低点处于两侧阳线实体之中
2. **弱势多方炮**：三根K线的高低点是向下移动的，说明抢筹不活跃或抛压严重
3. **强势多方炮**：三根K线的高低点是向上移动的，阴线带有长下影的小实体，说明抢筹热情高涨
4. **超强多方炮**：第一根阳线是光头阳线或涨停，中间阴线是假阴线，跳空高开，说明多头占据明显优势

### 位置强弱区分

1. **弱势多方炮**：发生在均线空头排列时，各条均线都对股价起到压力作用
2. **强势多方炮**：处于MA20均线之上，较短周期的三条均线形成了价托
3. **超强势多方炮**：发生在MA60均线之上，所有均线都在向上移动

### 操作方法

1. 在多方炮的第三根K线的收盘前首次进场
2. 多方炮形成后的三个交易日之内，如果回调到MA10均线附近则再次进场
3. 短线止损可设在多方炮的阴线之下
4. 在上涨波段起始位置形成的强势上攻多方炮是高效买点

### 变形：两阳夹两阴

当调整时间比标准多方炮多一个交易日时，两根调整的阴线可以合并算作一根阴线，形成两阳夹两阴的变形。其中两根阴线的实体应该较小，可以有较长的下影线。

## 空方炮（卖出信号）

### 标准形态

标准的空方炮由三根K线组成：第一根是放量长阴线，第二根是低开高走的阳线，第三根是对前面阳线穿头破脚的阴线，最强的形式是收盘创出新低。

### 强弱形态区分

1. **标准空方炮**：阳线的高低点处于两侧阴线实体之中
2. **弱势空方炮**：三根K线的高低点是向上移动的，说明还有参与者抱有继续上涨的希望
3. **强势空方炮**：三根K线的高低点是向下移动的，阳线带有长上影的小实体，说明抛压严重
4. **超强空方炮**：第一根阴线是光头阴线或跌停，中间阳线是假阳线，跳空低开，说明空头占据明显优势

### 位置强弱区分

1. **弱势空方炮**：发生在均线多头排列时，各条均线都对股价起到支撑作用
2. **强势空方炮**：收在MA20均线之下，较短周期的三条均线形成了价压
3. **超强势空方炮**：发生在MA60均线之下，所有均线都在向下移动

### 操作方法

1. 在空方炮的第三根K线收盘前首次离场
2. 空方炮形成后的三个交易日之内，如果回抽到MA10均线附近则再次离场
3. 做空品种可在价压附近的空方炮开空单
4. 在下跌波段起始位置的空方炮和强势下跌空方炮是高效卖点

## 价托与多方炮的配合

当多方炮正好形成在价托上方时，继续下跌的可能性较小，伴随着成交量明显放大，之后通常会产生向上跳空缺口，打开上涨空间。

## 价压与空方炮的配合

当空方炮正好形成在价压下方时，继续上涨的可能性已经很小，伴随着阴线成交量明显放大，之后通常会产生向下跳空缺口，打开下跌空间。
