# 过拟合检测贯穿全流程

**过拟合检测贯穿全流程** 是 UIDF 中情绪与多因子整合的具体实现路径，也是构建稳健量化策略的核心原则。它强调在策略开发的每个阶段嵌入过拟合检测机制，防止策略在历史数据上表现优异但实盘失效。

## 核心原则
- **稳健优于激进**：一个样本内夏普 1.0 但衰减 50% 的策略，不如样本内夏普 0.8 但衰减 10% 的策略。
- **走步前推金标准**：能通过走步前推（一致性≥0.85）和 3-6 个月模拟实盘检验的策略，才有资格动用真金白银。
- **业务逻辑高于算法精度**：有金融逻辑的规则即使统计显著性边缘，也比没有业务逻辑但统计显著的规则更可靠。

## 实施步骤
1.  **数据层**：建立 PIT 数据库，确保数据在时间上的准确性，防止前视偏差。
2.  **模型层**：使用走步前推（Walk-Forward Analysis）验证模型，计算一致性指标。
3.  **流程层**：实施预注册和保留集分离，避免数据泄露。
4.  **融合层**：在融合多维度指标（如缠论 + 情绪 + 量价）时，警惕“组合型过拟合”，即多个独立验证过的概念组合后总自由度急剧膨胀。

## 关联研究
- **[[组合对称交叉验证 (CSCV)]]**：量化回测过拟合概率（PBO）的核心工具。
- **[[市值加权自适应 LASSO]]**：通过正则化控制模型复杂度。
- **[[UIDF]]**：UIDF 框架本身就是为了在融合过程中控制过拟合风险而设计的。
