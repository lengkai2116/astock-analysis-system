# 江恩轮

江恩轮（Square of Nine / Harmonic Wheel）是[[江恩理论]]的核心工具之一，是一个基于平方根的计算器，用于从关键价格点推导出支撑和阻力位。

## 基本结构

- 起始于图形中央的数字1
- 第一个正方形结束于数字9
- 数字沿着车轮顺时针增加
- 横向和纵向十字交叉的部分用双线显示

## 使用方法

从关键价格点出发，沿特定角度（45°、90°、120°、180°、240°、270°、315°、360°）寻找目标价格：
- **上行（阻力位）**：顺时针旋转
- **下行（支撑位）**：逆时针旋转

## Excel计算公式

**上行（阻力位）**：
```
45度 = ((SQRT(价格)) + 0.25) * (SQRT(价格) + 0.25)
90度 = ((SQRT(价格)) + 0.5) * (SQRT(价格) + 0.5)
180度 = ((SQRT(价格)) + 1) * (SQRT(价格) + 1)
360度 = ((SQRT(价格)) + 2) * (SQRT(价格) + 2)
```

**下行（支撑位）**：
```
45度 = ((SQRT(价格)) - 0.25) * (SQRT(价格) - 0.25)
90度 = ((SQRT(价格)) - 0.5) * (SQRT(价格) - 0.5)
180度 = ((SQRT(价格)) - 1) * (SQRT(价格) - 1)
360度 = ((SQRT(价格)) - 2) * (SQRT(价格) - 2)
```

## 重要角度

- 不同市场偏好不同角度：债券市场倾向于120度，外汇市场青睐90度
- 每个市场都具有前后一致的属性
- 最感兴趣的角度的选择取决于具体市场
