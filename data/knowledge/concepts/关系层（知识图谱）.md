# 关系层（知识图谱）

**关系层**是[[面向A股投资策略融合的金融领域本体建模三层结构]]中定义概念之间如何相互关联的层级，是连接"信息孤岛"的桥梁。其设计原则为**类型化**、**多样化**与**可量化**。

## 设计原则

- **类型化**：定义了明确的[[关联规则类型定义]]。例如：
    - **因果/推导关系**："[[beichi|背驰]]" → 导致 → "[[三类买卖点|第一类买点]]"
    - **实例/应用关系**："[[贵州茅台]]" → 是 → "[[价值投资四大核心理念|价值投资]]的案例"
    - **互补/冲突关系**："[[liangjia-fenxi|量价分析]]" → 互补 → "[[chanlun|缠论]]"；"[[价值投资]]" → 冲突于 → "[[短线交易认知|短线交易]]"
    - **组成/层级关系**："[[情绪周期四阶段模型]]" → 包含 → "[[赚钱效应与亏钱效应]]"
- **多样化**：使用不同类型的可视化提示（如不同颜色的箭头或标签），让用户在浏览Wiki时能直观感知链接的含义，类似于[[类型化与多样化链接]]的理念。
- **可量化**：对于某些关系，如"[[风格时变性|因子有效性]]与市场状态的相关性"，可以赋予一个量化权重或置信度。这在构建[[加权相似度度量]]或[[市场状态感知因子]]时至关重要。

## 实现方法

结合[[共引网络分析（投资知识库）]]和[[主题建模]]技术，自动发现概念之间的潜在关联。通过[[Bethe-Hessian矩阵谱聚类]]等[[社区检测]]算法，识别出紧密关联的概念集群。手动定义并维护核心"路径"关系。
