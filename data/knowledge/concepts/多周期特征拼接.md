# 多周期特征拼接

多周期特征拼接是AI量化中处理多周期数据的核心方法，将不同周期的特征拼接成统一的高维特征向量，让模型自动学习最优周期组合。

## 实现示例

```python
# 以LightGBM为例
features = {
    'ma20_daily': rolling_mean(close_daily, 20),
    'ma5_60min': rolling_mean(close_60min, 5),
    'rsi_14_daily': RSI(close_daily, 14),
    'kdj_j_30min': KDJ(close_30min).J,
    'macd_dif_weekly': MACD(close_weekly).DIF,
    'volume_ratio_60min': volume_60min / MA(volume_60min, 20),
}
X = pd.DataFrame(features)
model = LGBMClassifier().fit(X, y)
```

## 优势

- **自动筛选**：不需要人工指定哪个周期更重要——模型通过特征重要性自动筛选
- **非线性关系**：模型可以学习不同周期特征之间的非线性交互关系
- **端到端优化**：周期选择作为模型训练的一部分被隐式优化

## 关键注意事项

- **时间对齐**：必须确保[[PIT数据库]]的时间对齐——同一个特征向量中的所有特征必须来自同一时间点的数据
- **前视偏差**：周线特征必须使用截至当周的可用数据，而不是未来数据
- **过拟合风险**：特征维度增加会消耗[[研究员自由度]]，需要严格防控过拟合
