# 高维Alpha（HDA）检验

## 概述

高维Alpha（HDA）检验由Pesaran和Yamagata (2023)提出，用于解决传统GRS检验在高维测试资产下效力下降的问题。当测试资产数量远大于时间序列长度时，GRS检验的统计性质会退化，HDA检验通过引入高维统计方法克服了这一局限。

## 核心机制

HDA检验的核心思想是利用高维统计中的稀疏性假设，对大量测试资产的Alpha进行联合检验。它不要求所有资产的Alpha同时为零，而是检验是否存在系统性偏离零的Alpha模式。

## 应用场景

HDA检验被Feng等（2026）用作逐步选择因子模型的停止准则。在向前逐步选择过程中，每添加一个新因子后，使用HDA检验评估剩余候选因子是否仍能产生显著的Alpha。当HDA检验不再拒绝零假设时，停止添加因子，从而确定最优因子数量。

## 与GRS检验的对比

| 特征 | GRS检验 | HDA检验 |
| :--- | :--- | :--- |
| 适用场景 | 低维测试资产 | 高维测试资产 |
| 统计性质 | 经典F分布 | 高维渐近分布 |
| 对多重共线性 | 敏感 | 更稳健 |
| 计算复杂度 | 低 | 中等 |

## 实践意义

HDA检验为高维因子筛选提供了更可靠的统计工具，使得在大量候选因子中进行系统性选择成为可能，是稀疏派方法论的重要组成部分。
