# 凯利公式（仓位管理）

## 定义

凯利公式最早由AT&T贝尔实验室物理学家约翰·拉里·凯利提出，后被爱德华·索普应用于赌场21点游戏和股票市场。在概率论中，凯利公式是一个在期望净收益为正的独立重复赌局中，使本金的长期增长率最大化的投注策略。

## 简化版公式

```
f = (b × p - q) / b
```

其中：
- f = 投资最佳仓位（占可用资金的比例）
- b = 赔率（投资预期收益与最大承受亏损的比值）
- p = 投资成功概率
- q = 投资失败概率（q = 1 - p）

## 应用示例

**伊利股份案例**：
- 预期上涨概率(p) = 51%
- 预期下跌概率(q) = 49%
- 预期上涨回报 = 40%
- 预期下跌止损 = 20%
- 赔率(b) = 40% / 20% = 2
- 最佳仓位(f) = (2 × 51% - 49%) / 2 = 26.5%

**中证医疗指数案例**：
- 预期上涨概率(p) = 60%
- 预期下跌概率(q) = 40%
- 预期上涨回报 = 50%
- 预期下跌止损 = 25%
- 赔率(b) = 50% / 25% = 2
- 最佳仓位(f) = (2 × 60% - 40%) / 2 = 40%
- 受单个行业不超过30%的限制，实际配置30%

## 局限性

1. 公式依赖于投资者对胜率和赔率的主观判断，不同投资者计算结果不同。
2. 凯利公式假设赌局独立重复，但股市并非完全独立的随机过程。
3. 凯利公式给出的仓位可能过高，实际应用中常采用半凯利或分数凯利。
4. 需要结合[[标准普尔家庭资产象限图]]和[[资产配置权益仓位图]]等整体框架使用。
