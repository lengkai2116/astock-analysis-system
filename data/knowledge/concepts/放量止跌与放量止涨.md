# 放量止跌与放量止涨

放量止跌和放量止涨是[[安娜·库林]]在《量价分析》中介绍的重要反转信号，分别标志着市场下跌和上涨的动能衰竭。

## 放量止跌信号

### 特征
- 市场处于强势下跌趋势中
- 出现拥有长下影线的K线图
- K线图收于上半部分
- 成交量显著放大

### 原理
局内人进入市场开始买入，吸收了卖压，阻止了进一步下跌。这预示着买入高峰的到来，市场从熊市到牛市的潜在反转。

### 典型序列
1. 暴跌 + 高成交量（恐慌性抛售）
2. 长下影线 + 高成交量（局内人开始买入）
3. 低实体 + 高成交量（买盘开始吸收卖盘）
4. 锤头线（确认信号）

## 放量止涨信号

### 特征
- 市场处于强势上涨趋势中
- 出现拥有长上影线的K线图
- 成交量显著放大
- K线图实体逐渐变低

### 原理
局内人开始卖出，卖压逐渐显现，市场上涨动能衰竭。这预示着抛售高峰的到来，市场从牛市到熊市的潜在反转。

### 典型序列
1. 上涨 + 高成交量（局内人满足需求）
2. 长上影线 + 高成交量（卖压显现）
3. 低实体 + 高成交量（市场挣扎）
4. 射击十字星（确认信号）

## 实战意义

放量止跌和放量止涨是量价分析中最可靠的信号之一，因为它们直接反映了局内人的行为。交易者应结合多时间框架分析和支撑阻力位来确认这些信号的有效性。
