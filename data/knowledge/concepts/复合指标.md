# 复合指标

复合指标（Composite Index）是[[康斯坦丝·M·布朗]]发明的核心指标，由RSI的动量指标和快速RSI复合而成。它用于发现标准RSI无法发现的背离信号。

## 构建步骤

1. 用14周期的RSI数据创建一个9周期的动量指标（指标的指标）
2. 建立一个3周期的RSI指标，再用3周期平均线平滑
3. 将第1步和第2步加起来建立复合指标
4. 再建立复合指标13周期和33周期的平均线
5. 将复合指标和两条平均线画在价格数据下面的图表里

## TradeStation公式

```
Plot1(RSIMO9+RSI3, "Plot1");
Plot2(average((plot1), 13), "Plot2");
Plot3(average((plot1), 33), "Plot3");
```

其中：
- RSIMO9 = MOMENTUM(RSI(CLOSE, 14), 9)
- RSI3 = AVERAGE(RSI(CLOSE, 3), 3)

## 核心优势

- 能比标准RSI更早、更清晰地发现背离信号
- 在月线图等大周期上表现尤为突出
- 可以发现趋势的改变，而标准RSI却不能
- 不受0-100区间的限制，可以在零线上下任意移动

## 局限性

- 不能替代RSI，没有区间运行的那些特征
- 本质上仍是摆动指标，存在反趋势性
- 一旦趋势来临，可能站在市场的反面
