# 长上下影线分析法

## 定义

长上下影线分析法是[[吴国平]]在《私募老总的炒股干货：技术分析与实战技巧》中提出的一种K线分析方法。影线是K线中的重要组成部分，长上下影线往往带着某种预示的信号，其含义取决于所处的市场阶段（上升阶段或下跌阶段）。

## 核心原理

- **长上影线**：对未来都有比较大的向上牵引力，只不过在上涨阶段中，表现得更为激烈突出，下跌阶段中就演变成下跌浪中的反弹。
- **长下影线**：对未来都有比较大的向下牵引力，只不过在下跌阶段表现得更为激烈突出，上涨阶段则演变成上涨阶段的调整。

## 不同阶段的分析

### 上升阶段

- **长上影K线**：更多机会将是加速突破（看涨信号）。
- **长下影K线**：市场进入调整可能性大（下跌信号）。

### 下跌阶段

- **长下影K线**：市场更多将是加速下跌（看跌信号）。
- **长上影K线**：市场将有短线反弹空间（反弹信号）。

## 带长上下影的K线解读

### 带长上影的K线

| K线类型 | 含义 |
|---------|------|
| 小阳线 | 多方试探性上攻但被空方反扑，收获有限 |
| 中阳线 | 多方试探性上攻，虽然被空方反扑较为厉害，但多方整体依然取得一定优势 |
| 小阴线 | 多方试探上攻，但被空方反扑较为厉害，多方无功而返 |
| 中大阴线 | 多方试探上攻，但被空方猛烈反扑，多方节节败退 |
| 十字星 | 多空双方最终打成平手，但多方在这过程中上探的空间较大 |

### 带长下影的K线

| K线类型 | 含义 |
|---------|------|
| 小阴线 | 空方试探性出击但多方反攻收获有限 |
| 中阴线 | 空方试探性出击，虽然被多方反攻较为凶悍，但空方整体依然取得一定优势 |
| 小阳线 | 空方试探性出击，受到多方积极反攻，空方无功而返 |
| 中大阳线 | 空方试探性出击，受到多方猛烈反攻，空方节节败退 |
| 十字星 | 多空双方最终打成平手，但空方在这过程中下杀的空间较大 |

## 大盘长上下影线的运用

### 大盘长上影线

- 带长上影的K线，说明其空方能量巨大，后市调整不可避免，要注意风险。
- 但大多数情况下恰恰相反，长上影线出现后，后市上涨的概率极大。
- 关键在于看清当前的环境（上涨阶段还是下跌阶段）。

### 大盘长下影线

- 长下影线出现后，后市调整的概率极大。
- 如果出现在上升趋势中，该下影线的最低点具有一定的支撑作用。
- 如果出现在下跌趋势中，该长下影线的最低点往往将不是最低点，后市创出新低的概率大。
