# 假突破交易策略

## 概述

假突破（多头陷阱/空头陷阱）是指价格短暂突破关键支撑或阻力位后迅速反转的形态。识别和利用假突破进行反向交易是高级交易技巧，可以在市场中获取可观的利润。

## 假突破的形成原理

假突破发生在关键价位附近，当价格短暂突破前高或前低之后，价格却回撤到突破之前的区域。突破失败意味着原有行情的推动力量发生衰减。

- 假突破发生在前高附近：说明前期高位套牢的交易者终于等到了出逃机会，市场中对筹码的供给大于需求
- 假突破发生在前低附近：说明市场对该交易品种的需求大于供给

## 如何预测假突破

1. **背离信号**：RSI和MACD指标的背离可以指示出可能发生假突破的位置
2. **成交量特征**：突破时成交量不足，或突破后成交量迅速萎缩
3. **顶部/底部反转K线形态**：如射击之星、吞没形态、锤头线等
4. **位置判断**：在明显的顶部或底部形态之后，假突破的概率增加

## 如何识别假突破

1. **时间确认**：利用三日原则判断，如果三个交易日内回补缺口，则是假突破
2. **K线形态确认**：突破后出现顶部或底部反转K线形态
3. **成交量确认**：突破时成交量未能持续放大
4. **指标确认**：MACD、KDJ等指标出现背离

## 操作策略

### 做空假突破（多头陷阱）

1. 价格短暂突破前高后出现顶部反转K线形态（如射击之星、吞没形态）
2. 在跌破反转K线低点时进场做空
3. 止损设在假突破的高点上方
4. 止盈目标：假突破这波上涨的起点

### 做多假突破（空头陷阱）

1. 价格短暂跌破前低后出现底部反转K线形态（如锤头线、刺透形态）
2. 在突破反转K线高点时进场做多
3. 止损设在假突破的低点下方
4. 止盈目标：假突破这波下跌的起点

## 应用要点

- 假突破可以发生在任何时间周期，周期越大，可靠性越高
- 假突破交易者的利润来源于对手盘的失误
- 假突破之后通常会产生多个可能的进场点
- 通过变换周期，可以在更小的周期内建立长线仓位
- 假突破形态通常有着不平衡的风险回报比
