# 巨量高开标准

巨量高开标准是[[吴国平]]提出的集合竞价选涨停的核心量化标准，包含高开标准和巨量标准两个维度。

## 高开四档标准

### 第一档：寻常高开
- 高开幅度小于2%
- 高开回调不破当日开盘价，或者高开回调不破前日收盘价，至多只能稍稍击破前日收盘价
- 操作：个股波段涨幅小于25%，符合巨量标准，可待股价回调时跟进追涨

### 第二档：强势高开
- 高开幅度在2%～4%
- 股价回调不破当日开盘价、不破前日收盘价、不破均价线
- 操作：个股波段涨幅小于25%，结合巨量标准，待股价回调时可以跟进

### 第三档：超强高开
- 高开幅度4%～7%
- 股价回调不破前日收盘价、不破当日开盘价、不破分时均价线
- 操作：个股波段涨幅小于25%，符合巨量标准，开盘直接跟进或待股价回调时买入

### 第四档：极强高开
- 高开幅度7%以上
- 股价回调不破当日开盘价、不破分时均价线
- 操作：个股波段涨幅小于25%，符合巨量标准，开盘直接跟进或待股价回调时买入

## 巨量八档标准（集合竞价成交量）

| 流通盘 | 巨量标准（手） |
|--------|----------------|
| 小于3000万股 | 600手以上 |
| 3000万～6000万股 | 800手以上 |
| 6000万～1亿股 | 1000手以上 |
| 1亿～2亿股 | 1500手以上 |
| 2亿～4亿股 | 2000手以上 |
| 4亿～6亿股 | 2500手以上 |
| 6亿～10亿股 | 3000手以上 |
| 10亿股以上 | 6000手以上 |

## 核心原理

集合竞价时的巨额成交量，在波段涨幅较小的情况下，往往是主力在疯狂扫货，是股价启动或者加速上扬的标志。散户的力量分散，意志也不统一，集合竞价中的巨量成交绝不可能是散户所为。

## 注意要点

- 巨量高开标准来源于作者对数千只涨停个股的实战统计分析。
- 高开越多对后期趋势的影响越大，但必须有巨量的配合，否则可能会成为主力诱多的牺牲品。
- 与[[集合竞价选涨停]]战法密切相关。
