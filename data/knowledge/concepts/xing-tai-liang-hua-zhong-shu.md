# 形态量化中枢

## 概述

形态量化中枢是K线形态跨策略融合框架的核心执行组件。它将缠论、量价、情绪、筹码四个维度的信号通过加权公式合成，生成综合性的交易决策信号。该概念强调其作为**方法论框架**的价值，而非具体的权重常数。

## 核心公式

$$形态量化中枢 = \alpha \times \text{缠论中枢（结构性权重）} + \beta \times \text{量价形态评分} + \gamma \times \text{情绪状态因子} + \delta \times \text{筹码集中度因子}$$

### 各维度说明

- **缠论中枢（结构性权重）**：作为"位置"和"结构"的基础，决定形态的置信度。中枢上沿/下沿的突破、中枢内部的震荡、背驰段的位置，赋予形态不同的结构性意义。
- **量价形态评分**：对识别出的具体形态（如[[xu-ri-dong-sheng-zhan-fa|旭日东升]]、[[duo-fang-pao-kong-fang-pao|多方炮]]）进行量化打分，基于[[50-zhong-liangjia-xingtai-suchabiao|50种量价形态速查表]]。
- **情绪状态因子**：根据[[qingxu-zhouqi-si-jie-duan-mo-xing|情绪周期四阶段模型]]，给予不同周期阶段不同的动态权重。冰点期底部形态加分，高潮期顶部形态加分。
- **筹码集中度因子**：追踪[[ASR指标]]或主力持仓变化，判断主力控盘程度。筹码集中度高时，形态信号可靠性提升。

## 权重确定方法

**重要提示**：公式中的权重（α, β, γ, δ）是高度依赖具体市场和策略的参数，不应被视为普适常数。确定方法包括：

1. **经验法**：基于交易者的实战经验主观设定
2. **优化法**：通过回测数据使用网格搜索或贝叶斯优化确定最优权重
3. **自适应法**：根据市场状态（趋势/震荡）动态调整权重
4. **机器学习法**：将四个维度作为特征输入，用GBDT等模型端到端学习

## 信号生成逻辑

### 做多信号条件
- 确认层看多（多因子评分高）
- 执行层出现预涨形态
- 过滤层：情绪处于冰点/复苏期，筹码集中度高

### 做空信号条件
- 确认层看空（多因子评分低）
- 执行层出现预跌形态
- 过滤层：情绪处于高潮/退潮期，筹码发散

## 工程化实现

### 数据结构
在回测和实盘系统中，为K线数据增加三个标签字段：
- `structure_label`：缠论结构位置（中枢内/中枢上沿/背驰段等）
- `sentiment_label`：情绪周期阶段（冰点/复苏/高潮/退潮）
- `position_label`：筹码结构位置（筹码主峰上方/下方/内部）

### 计算流程
1. 实时计算缠论结构位置
2. 识别当前K线形态并打分
3. 获取当前情绪周期阶段
4. 计算筹码集中度
5. 加权合成综合信号

## 风险与局限

1. **过度融合风险**：四个维度的参数组合爆炸，极易导致过拟合
2. **权重敏感性**：权重微小变化可能导致信号完全反转，需进行参数平原分析
3. **维度冲突**：不同维度可能给出矛盾信号，需依赖[[k-xian-xing-tai-kua-ce-lve-rong-he-qiao-liang|冲突调和机制]]处理
4. **计算复杂度**：实时计算缠论结构和筹码分布需要较高计算资源
