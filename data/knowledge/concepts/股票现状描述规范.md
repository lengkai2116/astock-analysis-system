# 股票现状描述规范

## 概述

本文档定义了股票现状描述的标准框架和输出规范。适用于 DeepSeek 生成面向用户的股票现状描述文本时遵循的结构和约束。**规范即配置**——调整描述风格只需修改本文档，不碰代码。

**核心原则**：
- **结构先行，位置确认，时间验证**——先定结构级别，再定相对位置，最后给时间维度
- **有数据则显，无数据不占位**——只写有数据支撑的维度，不写空泛判断
- **时序过滤**——只展示当前有效的信号，历史信号降级或省略
- **不预测未来**——只基于已有数据进行现状描述

---

## 总体框架

描述应按以下三层结构组织，从宏观环境到个股本体再到辅助验证：

```
第一层：环境定位
  大盘状态 · 板块定位 · 个股相对强弱

第二层：个股全息（核心，7个维度）
  走势结构 → 筹码成本 → 价格位置 → 量价关系
  → 资金博弈 → 收益驱动 → 时间节奏

第三层：辅助验证
  情绪周期阶段 · 多因子评分 · 财务排雷结论
```

## 输出规范

### 第一层：环境定位

**大盘状态**：基准指数趋势方向 + 所处阶段。

示例：
> "上证处于日线级别震荡整理。"

**板块定位**（有则显）：所属板块当前主线/冷门 + 板块阶段。

示例：
> "所属半导体板块为当前主线（板块指数+8.2%）。"

**个股相对强弱**（有则显）：近20/60日跑赢/跑输大盘幅度。

示例：
> "个股近20日跑赢大盘4.3%，板块内强度排名前15%。"

---

### 第二层-①：走势结构

**缠论三要素**：

| 要素 | 描述内容 | 示例 |
|------|---------|------|
| **级别** | 界定走势的"规模"——日线级别还是周线级别 | "日线级别上升趋势" |
| **中枢** | 价格相对中枢的位置（上方/内部/下方） | "价格位于日线中枢(26.21-31.98)下方(-15.1%)" |
| **背驰** | 趋势是否衰竭，是否临近转折 | "周线无背驰，中期趋势尚未衰竭" |

**附加描述**：
- 当前笔状态：方向 + 是否延续
- 有效信号：时序筛选后只展示**最近一个有效买卖点**
- 远期中枢处理：距当前偏离超过±30%的中枢标记为"历史参考"并降级

示例：
> "日线级别上升趋势，当前笔向下延续。价格位于最近日线中枢(26.21-31.98)下方(-15.1%)。30分钟级别出现第三类买点(7/10确认)，为当前有效信号。周线无背驰，中期趋势尚未衰竭。"

---

### 第二层-②：筹码成本

**有数据则显**。描述顺序：

1. 筹码主峰位置 vs 当前价（上方/内部/下方）
2. 主力集中价 vs 当前价（偏离度）
3. ASR浮筹比例（适中/过高）
4. 筹码集中度变化趋势

示例：
> "当前价格22.34元处于筹码主峰(23.5-25.0)下方，偏离-7.7%，主力处于浮亏状态。浮筹比例45%适中，筹码集中度近20日提升，有主力吸筹迹象。"

---

### 第二层-③：价格位置

**三层次描述**：均线排列 → 乖离率 → 历史分位 → 关键支撑阻力

示例：
> "收盘价22.34跌破20日均线(-4.8%)，接近60日线(21.80)支撑。处于近250日区间25%分位（低位区域）。5/10/20日均线已形成空头排列。下方支撑21.50（前低），上方阻力24.80（筹码峰）。"

---

### 第二层-④：量价关系

**三层次递进描述**：

**层次一：八种基本量价形态**（确定大方向）

| 形态 | 含义 |
|------|------|
| 量增价涨 | 健康上涨，买方强劲 |
| 量缩价涨 | 上涨动能减弱，可能接近顶部 |
| 量增价跌 | 下跌加速，恐慌抛售 |
| 量缩价跌 | 下跌势能减弱，可能接近底部 |
| 量增价平 | 多空分歧加大，变盘前兆 |
| 量缩价平 | 观望浓厚，方向不明 |
| 天量天价 | 历史级别放量见顶信号 |
| 地量地价 | 历史级别缩量见底信号 |

**层次二：确认或异常**（判断信号真伪）

| 状态 | 含义 |
|------|------|
| 确认 | 成交量验证了价格变动，趋势可信 |
| 异常 | 量价背离，潜在反转信号 |
| 连续异常 | 多日背离，更强信号 |

**层次三：具体量价形态匹配**（如果匹配）

从知识库 `50种量价形态速查表` 中匹配具体形态名称：

- **预涨型**：放量突破筹码单峰区、缩量回踩筹码密集区、"红三兵"放量上涨、"出水芙蓉"放量穿越线等
- **预跌型**：递增式放量上涨、递减式放量回调、高台跳水放量破位线、缩量下滑圆弧形等
- **黑马型**：振荡区间的放量收窄、堆积式突破低位缩量区、涨停突破点放量振荡等

无对应形态匹配时只输出层次一+二，不强行套用形态名称。

示例：
> "当前处于**量缩价跌**状态，下跌动能减弱。近5日连续缩量（较前5日-25%），昨日收小阳线且成交量开始企稳，属**确认**信号。形态上识别出'缩量回踩筹码密集区'（预涨型形态），若后续放量企稳则可能是阶段性底部。"

---

### 第二层-⑤：资金博弈

**有数据则显**。描述顺序：

1. 大单净额方向（5日累积，正/负）
2. 超大单/大单/小单对比（资金结构健康度）
3. 龙虎榜机构占比（如有）
4. 换手率历史分位
5. 主力操盘阶段（建仓/洗盘/拉升/出货）

示例：
> "近5日大单净流入+1.2亿元，超大单净流入+0.5亿，小单净流出-0.8亿——机构在买入、散户在卖出，资金结构健康。龙虎榜显示机构专用席位净买入2300万，换手率3.2%处于历史中等水平。"

---

### 第二层-⑥：收益驱动

**有替代数据则显，无则跳过**。当前系统无收益分解管道，临时替代指标：

- 涨跌幅标准差（波动率代理）
- 换手率变化（情绪过热代理）
- 融资余额增速（散户情绪代理）

示例：
> "该股近20日波动率处于历史90%分位，融资余额同步暴增20%，换手率从5%飙升至20%——属于情绪驱动型行情，反转风险较高。"

---

### 第二层-⑦：时间节奏

**有数据则显**。描述顺序：

1. 当前中枢/趋势已持续多长时间
2. 接近/未接近级别经验性上限（日线1-6月、周线>6月）
3. 变盘条件检查：BOLL带宽是否收缩、均线是否粘合、成交量是否萎缩

示例：
> "该股在日线中枢内横盘已达5个月，接近日线级别经验性上限6个月。BOLL带宽已收缩至历史低位，均线开始粘合——变盘条件逐步成熟。"

---

### 第三层：辅助验证

**情绪周期阶段**（有数据则显）：
> "市场情绪处于冰点末期，涨停家数<20，空间龙头不足3板，慢线走平、快线底部钝化——情绪可能即将反转。"

**多因子评分**（有数据则显）：
> "多因子综合评分全市场前20%，价值因子优势明显(前15%)，动量因子偏弱(后40%)。"

**财务排雷**（有数据则显）：
> "已通过ROCE>15%、速动比率>0.8、经营现金流为正三道检查，基本面无硬伤。"

---

## 格式约束

1. **用客观事实描述，不预测未来**——每一句都有数据支撑
2. **有数据则写，无数据跳过，不要编造**
3. **先事实后判断，先主要后次要**
4. **遇到矛盾信号（如买点与卖点同时存在），说明矛盾原因而非隐藏**
5. **不写空泛判断**——不写"有望继续上涨"、"需注意风险"等没有数据支撑的结论性语句
6. **不并列展示历史信号**——只展示时序最新的有效信号
