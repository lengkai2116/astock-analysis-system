# RSI反转信号

RSI反转信号（RSI Reversal Signals）是[[康斯坦丝·M·布朗]]提出的RSI价格预测方法，分为向上反转（Positive Reversal）和向下反转（Negative Reversal）。

## 定义

- **向上反转**：RSI跟前面的低点相比创出了新低，而此时价格低点相比更高一些。指标形态预示着后市看涨，因为当市场价格正在一个较高的水平上交易时，摆动指标已经超卖。
- **向下反转**：RSI跟前面的高点相比创出了新高，而与该指标高点相应的价格高点仍位于较低的水平。当价格仍在较低水平，而摆动指标已经超买，这意味着市场被逐渐侵蚀，正在变得虚弱。

## 价格预测公式

**向上反转**（预测上涨目标）：
```
(X - W) + Y = 新的价格目标
```
其中W和X是RSI的两个低点，Y是W和X之间的RSI高点对应的收盘价。

**向下反转**（预测下跌目标）：
```
Y - (W - X) = 新的价格目标
```
其中W和X是RSI的两个高点，Y是W和X之间的RSI低点对应的收盘价。

## 重要特性

- 反转信号只使用收盘价计算，因此是分析工具而非交易工具
- 不能用于设置止损或精确择时
- 隐性信号（发生在摆动指标较大趋势中的反转）比有明显拐点的反转信号更有力
- 信号出现得越快，正确的概率越高
- RSI高点和低点之间的高度（垂直距离）会影响信号的精确性
