# 走步前推

走步前推（Walk-Forward Analysis）是模拟真实基金经理逐步积累经验过程的回测方法，是对抗[[过拟合检测|过拟合]]的核心武器。其基本思路是使用滚动时窗进行训练和测试：用固定长度的历史数据作为训练集，紧接着的固定长度数据作为测试集，不断向前滚动时窗并重复训练与测试，最后汇总所有测试集的表现以评估策略的稳健性。

## 核心原理

- **滚动时窗**：使用固定长度的历史数据作为训练集
- **前推测试**：使用训练集之后的固定长度数据作为测试集
- **重复滚动**：不断向前滚动时窗，重复训练和测试过程
- **汇总评估**：汇总所有测试集的表现，评估策略的稳健性

该方法模拟真实投资过程，避免使用未来信息，并提供策略表现的滚动评估。

## 四种变体

1. **固定窗口**：训练窗口长度固定，向前滚动
2. **扩张窗口**：累积所有历史数据
3. **滚动窗口**：固定长度，向前滚动
4. **锚定窗口**：训练期起点固定，终点滚动

## 优势

- 模拟真实投资过程，避免使用未来信息
- 提供策略表现的滚动评估，反映策略在不同市场环境下的表现
- 是过拟合检测的重要方法之一

## 核心输出指标——一致性

一致性 = 1 − |训练胜率 − 验证胜率| / 训练胜率

| 一致性 | 解读 |
|--------|------|
| ≥ 0.95 | 几乎完美（没有过拟合） |
| 0.85 ~ 0.95 | 轻微过拟合 |
| 0.75 ~ 0.85 | 明显过拟合 |
| < 0.75 | 严重过拟合 |

## 最低验证标准

- 夏普衰减 < 0.3
- 收益衰减比例 < 30%
- 回撤恶化 < 5%
- 模拟实盘夏普 > 0.5

## 应用

走步前推是[[量价形态打分系统]]从研究走向实战的必经之路，也是其回测验证的核心方法之一，用于评估策略在不同市场环境下的稳健性。
