# 三阶段渐进式连接方案

本方案是[[知识图谱构建方法论（个人维基版）]]的具体实施策略，针对投资分析知识库中大量松散页面的碎片化问题，提出分阶段、渐进式的内部连接整理方案。各阶段可独立启动，降低初始投入门槛。

## 第一阶段：快速连接（1-2天）

目标：解决最突出的问题——孤立节点和断裂链接。

**执行清单**：
1. 使用[[Keppi]]的`broken-links`命令扫描所有页面中指向不存在页面的[[wikilink]]，标记为待修复
2. 使用[[Keppi]]的`orphans`命令识别度=0的孤立页面，标记为待连接
3. 手动修复高优先级断裂链接
4. 为孤立页面添加至少1个面向已有聚类的[[wikilink]]

**输出**：断裂链接修复率>90%，孤立节点数降至0。

## 第二阶段：主题聚类与自动连接（3-7天）

目标：通过主题聚类建立群内强连接，通过LLM辅助发现跨群桥接。

**执行步骤**：
1. **页面向量化**：使用[[sage-wiki]]的embed功能或本地Ollama + nomic-embed-text，将每个页面转换为768维嵌入向量
2. **层次聚类**：计算所有页面对的余弦相似度，采用凝聚层次聚类，设定截止阈值
3. **LLM辅助推荐**：为每个聚类生成聚类摘要，调用LLM为聚类内每个页面推荐缺失连接
4. **桥接发现**：计算不同聚类之间的中心页面（betweenness centrality），标记桥接页面，自动添加指向对接聚类的[[wikilink]]

## 第三阶段：增量维护与持续进化（长期）

目标：建立知识库自动更新的闭环机制。

1. **自动检测**：部署文件监控，检测新页面创建、页面内容修改、页面删除
2. **增量更新**：只对变更的页面重新进行主题聚类和连接推荐
3. **自动维护**：使用[[Keppi]]的`drift`命令检测过时页面，使用[[lcwiki]]的`audit`命令检测幽灵节点和断裂链接
4. **人工审核**：LLM标记的高风险操作需人工确认

## 核心原则

- **降低初始门槛**：从"快速连接"阶段开始，避免因方案过于庞大而无法启动
- **机器推荐，人工确认**：平衡自动化效率与质量
- **工具链组合**：不依赖单一工具，根据阶段选择最合适的工具
