# 形态量化

形态量化是将技术分析中模糊的形态描述（如“冲高回落急速缩量”）转化为精确的、可编程的量化规则的过程。这是构建量化量价策略的基础步骤。

## 量化规则示例

| 形态名称 | 量化规则 |
| --- | --- |
| “冲高回落急速缩量”（预涨型） | 当日最高涨幅>3% → 收盘回落<最高价2% → 次日成交量<前日50% |
| “递增式放量下跌”（预跌型） | 连续3日成交量递增且每日收盘价均低于前日 |
| “堆量中跌回启动点”（黑马型） | 10日累计换手率>80%后价格跌回启动点且成交量缩至放量区间的30%以下 |

## 关键原则

- 优先选择逻辑最清晰、参数最少的形态开始建模
- 结合空间维度（涨跌幅目标位、筹码峰位置）定义止盈规则
- 关注成交额而非仅成交量，避免因送转股导致成交量失真
